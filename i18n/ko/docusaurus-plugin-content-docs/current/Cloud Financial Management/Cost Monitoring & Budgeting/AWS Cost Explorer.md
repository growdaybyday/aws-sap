# AWS Cost Explorer

## 1. 소개

AWS Cost Explorer는 클라우드 지출의 복잡함에 명확성을 가져다주는 강력한 도구입니다. 이 장에서는 Cost Explorer의 기능, 설정, 고급 기능을 깊이 살펴보며, AWS 비용을 이해하고 최적화하는 것에 대한 포괄적인 가이드를 제공합니다.

## 2. AWS Cost Explorer란 무엇인가?

핵심적으로 AWS Cost Explorer는 비용과 사용 패턴을 이해하는 데 도움을 주도록 설계된 시각화와 분석 도구입니다. 다음과 같은 몇 가지 핵심 기능을 제공합니다.

- **과거 데이터 분석:** 최대 13개월의 과거 데이터를 확인해 지출 추세를 식별할 수 있습니다.
- **예측:** 과거 추세를 기반으로 향후 12개월의 예상 비용을 추정합니다.
- **예약 권장 사항:** 어떤 예약 인스턴스나 Savings Plans가 조직에 도움이 될 수 있는지에 대한 안내를 받습니다.
- **커스텀 뷰:** 사전 구성된 대시보드에 접근하거나 가장 중요한 지표를 강조하도록 자체 보고서를 맞춤화합니다.

이러한 기능들은 지출을 추적할 뿐만 아니라 다가오는 비용을 예측하고 계획할 수 있도록 보장합니다.

## 3. Cost Explorer 활성화와 설정

Cost Explorer의 힘을 활용하려면 먼저 AWS Cost Management 콘솔을 통해 활성화해야 합니다. 초기 설정 프로세스는 여러 중요한 단계를 포함합니다.

1. **활성화:** Billing and Cost Management 콘솔을 열고 Cost Explorer 섹션으로 이동합니다. Cost Explorer를 처음 실행하면 AWS는 **현재 달과 이전 13개월**에 대한 데이터 준비를 시작합니다.
2. **데이터 가용성:** 현재 달의 데이터는 약 24시간 내에 사용 가능해지지만, 나머지 과거 데이터는 처리하는 데 며칠이 걸릴 수 있습니다. 활성화되면 Cost Explorer는 최소 24시간마다 한 번씩 데이터를 지속적으로 새로 고칩니다.
3. **비용 이상 탐지:** 활성화 과정의 일부로 AWS는 자동으로 Cost Anomaly Detection을 구성합니다. 이 기능은 머신 러닝을 사용해 지출 패턴을 모니터링하고 이상 징후를 알려줍니다 — 일반적으로 지출이 $100와 예상 비용의 40%라는 임계값을 초과할 때입니다.

Cost Explorer 사용자 인터페이스 사용은 무료이지만, API를 통한 프로그래밍 방식 접근은 요청당 소액의 요금이 발생한다는 점에 유의하는 것이 중요합니다. 또한 일단 활성화되면 Cost Explorer는 계정에 대해 계속 활성 상태로 유지됩니다.

## 4. Cost Explorer 대시보드 탐색하기

![cost-explorer-dash](@site/docs/Cloud%20Financial%20Management/_assets/cost-explorer-dash.png)

설정이 완료되면 Cost Explorer 대시보드는 한눈에 풍부한 정보를 제공합니다.
### 4.1. 핵심 대시보드 요소

- **월 누적 및 예측 비용:** 상단에 눈에 띄게 표시되며, 이 수치들은 현재 달의 예상 지출과 예측된 월말 비용을 보여주어 이전 기간과의 직접적인 비교를 제공합니다.
- **일일 비용 그래프:** 대시보드 중앙에는 일일 비혼합(unblended) 비용을 보여주는 그래프가 있어, 단기 지출 추세를 시각화하는 데 도움을 줍니다.
- **주요 비용 추세:** 전용 섹션이 가장 중요한 다섯 가지 비용 추세를 강조합니다. 이 추세들은 특정 AWS 서비스의 비용 상승이나 예약 인스턴스의 비용 증가 같은 패턴을 드러낼 수 있습니다.
- **최근 보고서:** 최근에 접근한 보고서 목록을 통해 서로 다른 뷰와 분석 간에 신속하게 전환할 수 있습니다.

### 4.2. 상세 보고 옵션

상위 수준 개요를 넘어 Cost Explorer는 더 깊이 파고들 수 있는 상세한 보고서를 제공합니다.

- **비혼합 비용과 순비용:** 총 요금과 해당하는 할인 적용 후 순지출을 모두 분석할 수 있습니다. 여기에는 월별 세분성으로 비혼합 비용을 보고 RI Volume Discount 같은 할인의 영향을 이해하는 것이 포함됩니다.
- **상각 비용 분석:** 장기 savings plan이나 예약 인스턴스에 약정하는 조직의 경우 Cost Explorer는 이 비용을 해당 사용 기간에 걸쳐 분산합니다. 이는 선불 약정과 시간에 따른 유효 비용률을 모두 볼 수 있게 해줍니다.
- **커스텀 보고서와 CSV 내보내기:** 모든 보고서는 필터와 파라미터를 조정함으로써 커스터마이징될 수 있습니다. 또한 추가 분석이 필요하면 다른 도구에서 사용하기 위해 데이터를 CSV 파일로 내보낼 수 있습니다.

## 5. 고급 기능과 고려 사항

### 5.1. 비용 이상 탐지

AWS Cost Explorer의 두드러진 기능은 통합된 Cost Anomaly Detection입니다. 머신 러닝 모델을 활용해 이 기능은 AWS 지출을 모니터링하고 비정상적인 패턴이 발생하면 알려줍니다. 자동 알림과 일일 요약을 설정함으로써 Cost Anomaly Detection은 지출의 예기치 않은 편차에 대해 신속하게 알림을 받도록 보장합니다.
### 5.2. 조직과 계정 고려 사항

AWS Cost Explorer는 AWS Organizations 내에서 원활하게 작동하도록 설계되었습니다. 그러나 유념해야 할 몇 가지 핵심 사항이 있습니다.

- **회원 계정 vs. 독립 계정:** 비용과 사용 데이터의 가시성은 계정이 독립 상태와 조직 상태 사이를 이동할 때 변경될 수 있습니다. 예를 들어 조직을 떠나는 회원 계정은 그 조직 내에서의 과거 데이터에 대한 접근 권한을 잃습니다.
- **접근 제어:** 조직에서는 관리 계정이 회원 계정에 대한 Cost Explorer 접근을 활성화하거나 제한할 권한을 가집니다. 이 중앙화된 제어는 조직 전반에서 비용 관리 관행이 일관되도록 보장합니다.

## 6. 결론

AWS Cost Explorer는 단순한 청구 도구 그 이상입니다 — AWS 지출을 이해하고, 예측하고, 최적화하기 위한 포괄적인 솔루션입니다. 커스터마이징 가능한 대시보드, 고급 이상 탐지, AWS Organizations 내에서의 원활한 통합을 통해 상세한 통찰을 제공함으로써, Cost Explorer는 운영 효율성과 비용 효과성에 상당한 영향을 미칠 수 있는 데이터 기반 결정을 내릴 수 있게 해줍니다.
