# Amazon Lex

## 1. 소개

Amazon Lex는 음성과 텍스트를 사용해 어떤 애플리케이션에도 대화형 인터페이스를 구축할 수 있게 해주는 AWS의 완전관리형 서비스입니다. Amazon Alexa를 구동하는 것과 동일한 딥러닝 기술을 활용해 고급 자연어 이해(NLU)와 자동 음성 인식(ASR) 기능을 제공합니다. 본질적으로 Lex를 사용하면 광범위한 머신 러닝 전문 지식 없이도 사용자 의도를 이해하고, 다중 턴 대화를 관리하고, 비즈니스 로직을 실행할 수 있는 챗봇과 음성 비서를 만들 수 있습니다.

## 2. 핵심 기능과 역량

![amazon-lex](@site/docs/Machine%20Learning/_assets/amazon-lex.png)

- **대화형 인터페이스:**
    텍스트나 음성을 통해 자연스럽게 상호 작용하는 챗봇을 만듭니다. Lex는 NLU와 ASR의 복잡함을 처리해, 대화 흐름 설계와 백엔드 서비스 통합에 집중할 수 있게 해줍니다.
    
- **의도(Intent)와 슬롯(Slot):**
    개발자는 _의도_(사용자 목표)를 정의하고 샘플 발화와 함께 _슬롯_(그 목표를 달성하는 데 필요한 파라미터)을 구성합니다. Lex는 이러한 정의를 사용해 사용자가 원하는 것을 판단하고 필요한 정보를 추출합니다.
    
- **다중 턴 대화 관리:**
    Amazon Lex는 슬롯 유도, 확인, 조건부 분기를 포함한 복잡한 대화 흐름을 지원합니다. 이는 봇이 여러 교환에 걸쳐 맥락을 유지하고 방해를 우아하게 처리할 수 있게 해줍니다.
     
- **AWS 서비스와의 통합:**
    커스텀 이행 로직을 실행하기 위한 AWS Lambda, 모니터링을 위한 Amazon CloudWatch, 옴니채널 콘택트 센터를 구축하기 위한 Amazon Connect와 원활하게 통합됩니다. Lex는 또한 보안과 확장성을 위해 다른 AWS 도구와 함께 작동하도록 설계되었습니다.
    
- **시각적 대화 빌더:**
    Lex V2의 경우 AWS는 코드를 작성하지 않고도 대화 흐름의 설계와 테스트를 단순화하는 시각적 빌더를 제공합니다.
    
- **생성형 AI와 향상된 기능:**
    최근 업데이트에는 대형 언어 모델과 생성형 AI 도구와 함께 작동하는 기능이 포함되어, 만들 수 있는 대화형 경험의 유형을 더욱 확장합니다.

## 4. 가격 정책

Amazon Lex는 사용한 만큼 지불하는 가격 정책 모델을 따릅니다. 봇이 처리하는 텍스트나 음성 요청에 대해서만 비용이 청구됩니다. 또한 AWS는 Lex에 대해 첫 12개월 동안 월 최대 10,000건의 텍스트 요청과 5,000건의 음성 요청에 대한 무료 티어를 제공합니다.
