# Amazon Polly
## 1. 소개

Amazon Polly는 텍스트를 실감 나는 음성으로 변환하는 AWS의 완전관리형 클라우드 서비스입니다. 고급 딥러닝 기법을 활용해 자연스럽게 들리는 오디오를 합성함으로써, 개발자가 빠르고 비용 효율적으로 애플리케이션에 음성 기능을 통합할 수 있게 해줍니다. Polly는 다양한 사용 사례를 충족하기 위해 수십 개 언어와 (표준, 뉴럴, 생성형, 장문 형식 변형을 포함한) 다양한 음성을 지원합니다. 사용한 만큼 지불하는 가격 정책 모델과 함께 Polly는 낮은 지연 시간과 확장성을 보장하면서 온프레미스 텍스트-음성 변환(TTS) 솔루션 배포의 복잡성을 없애줍니다. 또한 HIPAA와 PCI DSS 같은 규제 워크로드를 준수해 민감한 애플리케이션에 적합합니다.

## 2. 기능과 역량

**간단한 API 통합**
Amazon Polly는 개발자가 AWS SDK, CLI, 또는 Management Console을 통해 접근할 수 있는 간단한 API를 제공합니다. 이 단순함은 서비스에 텍스트를 보내고 MP3, OGG, 또는 원시 PCM 같은 표준 형식으로 오디오 스트림을 다시 받는 것을 쉽게 만들어줍니다.

**폭넓은 음성과 언어 선택**
Polly는 여러 언어와 변형에 걸쳐 다양한 음성 포트폴리오를 제공합니다. 표준 TTS 음성 외에도 Polly는 더욱 자연스럽고 표현력 있는 음성을 생성하는 고급 뉴럴 텍스트-음성 변환(NTTS) 옵션을 도입했습니다. 더 긴 텍스트에 걸쳐 더 높은 수준의 표현력과 일관성을 요구하는 전문화된 애플리케이션을 위한 생성형과 장문 형식 음성도 사용할 수 있습니다.

**고급 음성 커스터마이징**
Speech Synthesis Markup Language(SSML)를 사용해 개발자는 음성 출력을 세밀하게 제어할 수 있습니다. 여기에는 다음 조정이 포함됩니다.

- **음성 속도, 피치, 볼륨:** 음성이 얼마나 빠르고, 높고, 크게 들리는지 조정합니다.
- **발음:** 커스텀 사전을 사용해 기본 발음을 재정의합니다.
- **말하기 스타일:** 예를 들어 뉴럴 음성은 뉴스 내레이션을 위한 뉴스캐스터 스타일을 모방할 수 있습니다.
- **Speech Marks:** Polly는 (단어와 문장 경계, 비제임 데이터 같은) 메타데이터를 출력해 오디오를 시각적 요소와 동기화할 수 있습니다 — 립싱크나 말할 때 텍스트를 강조하는 애플리케이션에 이상적입니다.
- **속삭임:** 전용 SSML 태그를 통해 텍스트의 특정 구간을 속삭이는 어조로 렌더링할 수 있게 해주는 최근 기능입니다.

**커스터마이징과 브랜드 보이스**
조직은 Polly의 뉴럴 TTS 엔진을 사용해 커스텀 "브랜드 보이스"를 만들기 위해 AWS와 협력할 수 있습니다. 이 맞춤화된 음성은 제품을 차별화하고 플랫폼 전반에 걸쳐 일관된 음성 아이덴티티를 구축하는 데 도움이 될 수 있습니다.

**스트리밍과 낮은 지연 시간을 위해 최적화됨**
Amazon Polly는 실시간, 대화형 애플리케이션을 위해 설계되었습니다. 낮은 지연 시간의 응답 시간은 대화 시스템, 음성 지원 장치, 트래픽이 많은 콘택트 센터 솔루션에 적합하게 만들어줍니다.

## 3. 사용 사례

**접근성과 보조 기술**
서면 콘텐츠를 음성으로 변환함으로써 Polly는 시각 장애가 있는 사용자를 위한 접근성을 크게 향상시키고 읽기 애플리케이션을 지원합니다. 이는 디지털 콘텐츠를 장애가 있는 사용자에게 더 포용적으로 만들어줍니다.

**미디어와 엔터테인먼트**
콘텐츠 제작자와 출판사는 Polly를 사용해 책, 뉴스 기사, 멀티미디어 콘텐츠에 대한 오디오 내레이션을 생성합니다. SSML과 speech mark 같은 기능을 통해 개발자는 음성을 시각적 신호와 동기화할 수 있어, 디지털 미디어와 대화형 애플리케이션에서 스토리텔링을 향상시킵니다.

**고객 서비스와 대화형 음성 응답(IVR)**
Amazon Polly는 콘택트 센터와 IVR 시스템(종종 Amazon Connect 같은 서비스와 결합)의 핵심 구성 요소입니다. 자연스럽게 들리는 음성을 생성하는 능력은 매력적이고 효율적인 자동화된 고객 상호 작용을 만드는 데 도움을 줍니다.

**교육과 이러닝**
Polly의 실감 나는 음성은 언어 학습 앱, 이러닝 플랫폼, 디지털 교과서에서 사용됩니다. 이 서비스는 명확한 발음과 조정 가능한 음성 파라미터를 제공함으로써 학습자를 돕는데, 이는 효과적인 언어 습득에 중요할 수 있습니다.

**IoT와 임베디드 애플리케이션**
Polly의 낮은 리소스 요구 사항과 클라우드 기반 TTS 기능은 스마트 장치와 IoT 애플리케이션에서의 사용을 가능하게 합니다. 스마트 홈 기기부터 자동차 시스템까지 Polly는 강력한 온디바이스 처리 없이도 대화형 음성 인터페이스를 추가합니다.

**엔터프라이즈와 브랜딩 애플리케이션**
기업은 웹사이트, 앱, 대화형 키오스크에 음성을 내장해 사용자 경험을 향상시킬 수 있습니다. 커스텀 브랜드 보이스 솔루션은 회사의 브랜드에 맞는 고유하고 인식 가능한 청각적 아이덴티티를 만드는 데 도움을 줍니다.

## 4. 결론

Amazon Polly는 딥러닝 기술 위에 구축된 포괄적이고 다재다능한 텍스트-음성 변환 서비스로 두드러집니다. 다양한 음성과 언어 선택부터 SSML, speech mark, 속삭임을 사용한 고급 커스터마이징까지 풍부한 기능은 다양한 애플리케이션을 위한 강력한 도구가 되게 합니다. 접근성을 개선하고 싶든, 매력적인 미디어 콘텐츠를 만들고 싶든, 고객 상호 작용을 자동화하고 싶든, IoT 장치에 음성 기능을 불어넣고 싶든, Polly는 확장 가능하고, 낮은 지연 시간의, 비용 효율적인 솔루션을 제공합니다. AWS의 견고한 보안과 규정 준수 프레임워크로 뒷받침되는 Amazon Polly는 텍스트에 음성이라는 선물을 부여하고자 하는 개발자와 기업을 위한 신뢰할 수 있는 서비스입니다.
