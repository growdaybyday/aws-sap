# Amazon Kendra

## 1. 소개

Amazon Kendra는 고도로 정확하고 맥락적으로 관련성 있는 검색 결과를 전달하기 위해 고급 머신 러닝과 자연어 처리 기법을 활용하는 완전관리형 지능형 검색 서비스입니다. 전통적인 키워드 기반 검색 시스템과 달리 Kendra는 의미론적 이해를 사용해 자연어 쿼리를 해석하고 정확한 답변을 반환합니다. 조직이 온프레미스 파일 시스템부터 Amazon S3, SharePoint, Box, 데이터베이스 같은 클라우드 데이터 소스까지 여러 저장소에 걸쳐 통합된 검색 경험을 구축할 수 있게 해주어, 사용자가 필요한 정보를 빠르게 찾을 수 있게 도와줍니다. 또한 최근 개선 사항에는 검색 증강 생성(RAG)과 엔터프라이즈 검색 솔루션을 위한 생성형 AI 기능과의 통합이 포함됩니다.

## 2. 기능과 역량

Amazon Kendra는 엔터프라이즈 검색 솔루션의 구축과 배포 프로세스를 단순화하도록 설계된 광범위한 기능을 제공합니다.

- **자연어와 의미론적 검색:**
    Kendra는 대화형 쿼리를 이해합니다. 즉 사용자는 자연어로 질문할 수 있고 직접적인 답변이나 관련 구절을 얻을 수 있습니다. 딥러닝 모델은 의미론적, 맥락적 관련성을 기반으로 검색 결과의 순위를 매깁니다.
    
- **풍부한 데이터 소스 연결성:**
    Kendra는 인기 있는 데이터 저장소(예: Amazon S3, Microsoft SharePoint, Box, 데이터베이스 등)를 위한 사전 구축된 커넥터 모음을 포함해, 문서, FAQ, 심지어 멀티미디어 파일까지 원활하게 인덱싱할 수 있습니다.
    
- **커스터마이징 가능한 관련성 튜닝:**
    커스텀 인덱스 필드 매핑, 구성 가능한 속성을 사용해 검색 관련성을 세밀하게 조정할 수 있으며, 특정 문서나 콘텐츠 유형을 부스트하기 위해 기본 순위를 재정의할 수도 있습니다.
    
- **접근 제어와 보안:**
    토큰 기반 접근과 AWS Identity and Access Management(IAM)와의 통합에 대한 내장 지원을 통해 Kendra는 검색 결과가 조직의 보안과 규정 준수 정책을 존중하도록 보장합니다. 이를 통해 사용자는 권한이 부여된 콘텐츠만 볼 수 있습니다.
    
- **생성형 AI와 향상된 사용자 경험:**
    최근 개선 사항에는 (Amazon Bedrock으로 구동되는 것 같은) 생성형 AI 솔루션과의 통합을 가능하게 하는 Kendra GenAI 인덱스 지원이 포함되어, 더욱 풍부하고 증강된 검색 경험을 제공합니다.
    
- **확장성과 엔터프라이즈급 성능:**
    수만 개든 수백만 개의 문서든 Kendra는 높은 쿼리 성능과 낮은 지연 시간을 유지하면서 자동으로 확장됩니다.

## 3. 사용 사례

Amazon Kendra는 서로 다른 산업 전반의 다양한 검색 애플리케이션에 적합합니다. 다음은 몇 가지 핵심 사용 사례입니다.

- **내부 엔터프라이즈 검색:**
    여러 내부 데이터 소스에 걸친 단일 검색 인터페이스를 만들어 직원 생산성을 향상시킵니다. 직원은 정책 문서, 기술 매뉴얼, 프로젝트 문서, 다른 중요한 지식 자산을 빠르게 찾을 수 있습니다.
    
- **고객 지원과 셀프 서비스:**
    Kendra를 지원 포털이나 챗봇에 통합해 고객 경험을 향상시킵니다. 사용자는 자연어로 질문하고 간결한 답변이나 관련 문서를 받을 수 있어, 지원 티켓 양을 줄여줍니다.
    
- **SaaS 애플리케이션 검색:**
    SaaS 제공자의 경우 Kendra 기반 검색을 애플리케이션에 임베드하면 고객에게 직관적이고 맥락을 인식하는 검색 기능을 제공합니다. 이는 FAQ, 제품 문서, 사용자 생성 콘텐츠 같은 방대한 저장소에서 정보를 원활하게 검색하는 데 도움을 줍니다.
    
- **규정 준수와 문서 검색:**
    고도로 규제된 산업에서 조직은 Kendra를 사용해 규정 준수 문서와 법적 기록을 인덱싱하고 안전하게 검색할 수 있어, 민감한 정보가 승인된 인력에게만 접근 가능하도록 보장합니다.
    
- **산업별 검색:**
    헬스케어든, 법률이든, 금융 서비스든, 교육이든 Kendra는 도메인별 검색 과제를 다루기 위해 커스텀 관련성 튜닝과 데이터 소스 커넥터로 맞춤화될 수 있습니다.

## 4. 결론

Amazon Kendra는 배포와 관리가 간단한 지능적이고 맥락을 인식하는 검색 솔루션을 제공함으로써 전통적인 검색 패러다임을 혁신합니다. 자연어를 이해하는 능력과 견고한 데이터 소스 통합, 엔터프라이즈급 보안이 결합되어, 직원과 고객 모두에게 정보에 대한 빠르고 정확한 접근 권한을 부여하고자 하는 조직에게 이상적인 솔루션이 되게 합니다. 내부 문서 검색이든, 고객 지원이든, SaaS 애플리케이션에 검색 기능을 임베드하든, Kendra는 확장 가능하고, 비용 효율적이고, 규정을 준수하는 검색 기능을 제공합니다.
