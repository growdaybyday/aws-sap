# Amazon Managed Blockchain
## 1. 소개

Amazon Managed Blockchain은 블록체인 네트워크를 생성, 관리, 확장하기 쉽게 만들어주는 완전관리형 서비스입니다. (Ethereum, Bitcoin, Polygon 같은 네트워크를 위한) 퍼블릭 블록체인 노드와 Hyperledger Fabric 프레임워크로 구축된 프라이빗, 허가형 블록체인 네트워크를 모두 지원합니다. 기본 인프라를 추상화함으로써 AMB는 하드웨어를 프로비저닝하거나, 소프트웨어를 설치하거나, 네트워크 확장과 보안을 수동으로 관리할 필요 없이 블록체인 애플리케이션을 구축하고 배포하는 데 집중할 수 있게 해줍니다.

## 2. 기능과 역량

- **완전관리형 인프라:**
    AMB는 블록체인 인프라의 프로비저닝, 확장, 패치 같은 작업을 자동화합니다. 이는 운영 오버헤드를 줄이고 네트워크 관리를 단순화하는 데 도움을 줍니다.
    
- **다중 프로토콜 지원:**
    퍼블릭 블록체인 네트워크(Ethereum, Bitcoin, Polygon) 중에서 선택하거나 Hyperledger Fabric으로 프라이빗 네트워크를 구축할 수 있습니다. 이 유연성은 사용 사례에 가장 적합한 프로토콜을 선택할 수 있게 해줍니다.
    
- **확장성과 성능:**
    자동 확장을 위한 내장 메커니즘을 통해 AMB는 높은 성능과 신뢰성을 유지하면서 증가하는 트랜잭션 양과 네트워크 복잡성을 처리하도록 설계되었습니다.
    
- **보안과 거버넌스:**
    AWS KMS와 IAM 같은 AWS 보안 서비스와 통합되어 Managed Blockchain은 저장 중과 전송 중 암호화, 인증서 관리, 견고한 접근 제어를 제공합니다. 회원 제안과 투표 정책 같은 거버넌스 기능은 컨소시엄 회원이 협업해 네트워크 변경 사항을 관리할 수 있게 해줍니다.
    
- **원활한 AWS 통합:**
	AMB는 종단 간 가시성과 향상된 운영 제어를 제공하기 위해 (모니터링을 위한 CloudWatch와 로깅을 위한 CloudTrail 같은) 다른 AWS 서비스와 쉽게 통합됩니다.

## 3. 사용 사례

- **엔터프라이즈 컨소시엄:**
    금융, 공급망, 헬스케어 같은 산업을 위한 안전한 다자간 트랜잭션을 가능하게 하는 허가형 블록체인 네트워크를 생성합니다.
    
- **디지털 자산 관리:**
    기본 노드 인프라를 관리하지 않고도 디지털 자산 지갑, NFT 마켓플레이스, 또는 토큰 게이트 애플리케이션 같은 토큰화된 시스템을 구축하기 위해 퍼블릭 블록체인 노드를 활용합니다.
    
- **안전한 데이터 공유:**
    합의와 암호학적 증명을 통해 불변성과 신뢰를 보장하면서 여러 조직 간에 민감한 데이터를 공유하기 위해 프라이빗 블록체인 네트워크를 사용합니다.
    
- **분산 애플리케이션(dApp):**
	예측 가능한 성능과 확장 가능한 인프라로 실시간 블록체인 데이터가 필요한 분산 애플리케이션을 신속하게 개발하고 배포합니다.

## 4. 결론

Amazon Managed Blockchain은 블록체인 네트워크를 배포하고 운영하는 복잡함을 단순화합니다. 여러 블록체인 프로토콜 지원, 높은 확장성, 통합된 보안, 원활한 AWS 서비스 통합과 결합된 완전관리형 접근 방식은 조직이 신속하게 혁신하고 안전한 분산 애플리케이션을 구축할 수 있게 해줍니다. 프라이빗 컨소시엄 네트워크를 만들든 퍼블릭 블록체인에 연결하든, AMB는 블록체인 이니셔티브를 가속화하기 위한 견고하고 확장 가능한 플랫폼을 제공합니다.
