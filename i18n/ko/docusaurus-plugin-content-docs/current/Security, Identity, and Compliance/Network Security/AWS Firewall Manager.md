# AWS Firewall Manager

## 1. 소개

AWS Firewall Manager는 조직 내 여러 AWS 계정에 걸쳐 방화벽 규칙의 관리와 강제를 단순화하도록 설계된 중앙화된 보안 관리 서비스입니다. 보안 팀이 공통 보안 정책 집합을 정의하고 전파할 수 있게 함으로써 Firewall Manager는 다양한 리소스와 계정에 걸쳐 일관된 보안 태세를 보장해, 규정 준수를 간소화하고 운영 오버헤드를 줄여줍니다.
## 2. AWS Firewall Manager 개요

![AWS Firewall Manager](@site/docs/Security,%20Identity,%20and%20Compliance/_assets/aws_firewall_manager.png)

AWS Firewall Manager는 전체 AWS Organization 전반에서 방화벽 규칙을 관리하기 위한 단일 창을 제공하도록 엔지니어링되어 있습니다. 주요 기능은 다음을 포함합니다.

- **중앙화된 규칙 관리:**
	중앙 관리자 계정에서 보안 정책을 만들고 관리합니다. 이 정책들은 AWS WAF 규칙, Shield Advanced 보호, VPC 보안 그룹, AWS Network Firewall 규칙, Route 53 Resolver DNS Firewall 규칙을 포함한 다양한 보호를 포함합니다.

- **리전 정책 강제:**
	보안 정책은 리전 수준에서 생성됩니다. 정의되면 해당 리전의 AWS Organization 내 모든 관련 계정에 자동으로 배포되어, 모든 적격 리소스가 일관되게 보호되도록 보장합니다.

- **통합된 대시보드:**
	중앙화된 대시보드는 관리되는 모든 계정 전반의 규정 준수에 대한 가시성을 제공합니다. 규정을 준수하지 않는 리소스를 강조하고 편차가 발생할 때 신속한 개선을 위한 인사이트를 제공합니다.

관리 작업을 중앙화함으로써 AWS Firewall Manager는 관리 복잡성을 줄일 뿐만 아니라 보안 취약점으로 이어질 수 있는 잘못된 구성의 위험도 최소화합니다.

## 3. 보안 정책과 계정 간 관리

AWS Firewall Manager의 핵심에는 보안 정책이라는 개념이 있습니다 — 리소스가 어떻게 보호되어야 하는지 정의하는 공통 규칙 집합입니다. 이 정책들은 다음을 포함할 수 있습니다.

- **웹 애플리케이션 방화벽(WAF) 규칙:**
    HTTP/HTTPS 트래픽을 필터링해 애플리케이션을 보호하는 ACL(접근 제어 목록) 규칙의 모음을 지정하는 정책입니다. 이 규칙들은 ALB, API Gateway, CloudFront 배포 같은 리소스에 적용할 수 있습니다.

- **Shield Advanced 보호:**
    강화된 DDoS 완화, 고급 보고, Shield Response Team의 전담 지원을 제공하기 위해 Shield Advanced를 활용하는 정책입니다. 이 보호들은 빈번하거나 정교한 DDoS 공격에 노출된 조직에 매우 중요합니다.

- **표준화된 보안 그룹:**
    Virtual Private Cloud(VPC) 내의 EC2 인스턴스, 로드 밸런서, ENI(Elastic Network Interface) 리소스 전반에서 일관된 보안 그룹 설정을 강제하는 것을 목표로 하는 정책입니다.

- **Network Firewall과 DNS Firewall 규칙:**
    VPC 수준에서 보호를 확장하는 정책으로, 네트워크 트래픽이 적절하게 필터링되고 DNS 쿼리가 악성 도메인으로부터 보호되도록 보장합니다.

AWS Firewall Manager의 결정적인 장점은 AWS Organizations와의 긴밀한 통합입니다. 이 통합은 여러 계정에 걸친 보안 정책의 중앙화된 배포를 가능하게 합니다. 새 계정이나 리소스가 조직에 추가되면 정책이 자동으로 적용되어, 수동 개입의 필요를 없애고 생성 순간부터 보안 표준이 유지되도록 보장합니다.

## 4. 자동화된 정책 강제

AWS Firewall Manager의 가장 강력한 기능 중 하나는 보안 정책 강제를 자동화하는 능력입니다. 이 기능은 동적인 클라우드 환경에서 견고하고 규정을 준수하는 보안 태세를 유지하는 데 매우 중요합니다. 주요 요소는 다음을 포함합니다.

- **자동 탐지와 개선:**
    Application Load Balancer나 API Gateway 같은 새 리소스가 AWS Organization 내에서 생성되면 Firewall Manager는 그 존재를 탐지하고 관련 보안 정책을 자동으로 적용합니다. 이는 모든 새 리소스가 첫날부터 조직의 보안 요구 사항을 준수하도록 보장합니다.

- **지속적인 모니터링:**
    Firewall Manager는 리소스의 규정 준수 상태를 지속적으로 모니터링합니다. 정의된 정책과의 편차는 중앙화된 대시보드에서 플래그되어, 보안 팀이 신속하게 문제를 해결하고 개선할 수 있게 합니다.

- **확장 가능한 정책 관리:**
    소수의 계정을 관리하든 수천 개를 관리하든, Firewall Manager는 조직과 함께 확장됩니다. 이 확장성은 빠르게 성장하는 AWS 환경을 가진 엔터프라이즈에 필수적이며, 보안 정책이 리소스의 수나 지리적 분산과 관계없이 모든 리소스에 걸쳐 일관되게 강제되도록 보장합니다.


정책 강제의 자동화는 보안 조치의 배포를 가속화할 뿐만 아니라 인간 오류의 가능성도 줄여줍니다 — 이는 효과적인 보안 태세를 유지하는 데 있어 중요한 요소입니다.

## 5. 결론

AWS Firewall Manager는 멀티 계정 보안 관리의 복잡성을 간소화되고 자동화된 프로세스로 전환합니다. 보안 정책의 생성, 배포, 모니터링을 중앙화함으로써 조직이 다양한 AWS 리소스와 계정 전반에서 일관된 보안 태세를 유지할 수 있게 합니다. AWS Organizations와의 긴밀한 통합은 모든 새 리소스가 확립된 보안 표준을 자동으로 준수하도록 보장하며, 자동화된 강제와 지속적인 모니터링 기능은 관리 오버헤드를 줄이고 보안 격차의 위험을 최소화합니다.

게다가 AWS WAF의 세밀한 트래픽 필터링 기능과 AWS Shield Advanced의 견고한 DDoS 보호를 보완함으로써 Firewall Manager는 포괄적이고 복원력 있는 보안 프레임워크를 구축하는 데 중요한 역할을 합니다. 대규모로 AWS 환경을 보호하려는 조직을 위해 AWS Firewall Manager는 보안 정책이 정의될 뿐만 아니라 전체 인프라 전반에서 일관되게 강제되도록 보장하는 필수 불가결한 도구를 제공합니다.

AWS Firewall Manager를 도입하는 것은 클라우드 보안에 대한 선제적이고 자동화된 중앙화된 접근 방식으로 나아가는 길을 열어줍니다 — 조직이 규정 준수 요구 사항을 충족하고, 새로운 위협에 신속하게 대응하고, 모든 AWS 계정에서 높은 수준의 운영 보안을 유지할 수 있게 합니다.
