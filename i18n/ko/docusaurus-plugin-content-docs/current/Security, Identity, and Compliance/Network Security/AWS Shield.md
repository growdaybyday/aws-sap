# AWS Shields
## 1. 소개

AWS Shields는 클라우드 인프라를 DDoS 공격으로부터 보호하는 보안 서비스입니다. DDoS 공격은 전 세계에 분산된 여러 소스로부터의 요청 홍수로 서비스를 압도함으로써 정상적인 운영을 방해하도록 설계되었습니다. AWS Shields는 일상적인 공격과 정교한 공격 모두를 효과적으로 완화할 수 있도록 보장하는 내장 및 고급 보호 조치를 제공함으로써 이러한 위협을 해결합니다.

## 2. DDoS 공격 이해하기

DDoS, 즉 Distributed Denial of Service는 공격자가 여러 침해된 시스템을 활용해 대상의 인프라에 과도한 요청을 홍수처럼 보내는 공격 벡터입니다. 목표는 대상의 리소스(대역폭, 처리 능력, 네트워크 용량 등)를 포화시켜 정당한 사용자가 저하된 서비스나 완전한 사용 불가를 경험하게 만드는 것입니다.

DDoS 공격의 주요 특성은 다음을 포함합니다.

- **대규모 요청 볼륨:** 갑작스러운 요청 급증이 대상을 압도합니다.
- **분산된 소스:** 공격은 다양한 지리적 위치에 있는 수많은 컴퓨터에서 시작됩니다.
- **공격 방법:** 일반적인 기법으로는 SYN 플러드, UDP 플러드, 반사 공격이 있습니다. 각 방법은 서비스를 방해하기 위해 네트워크 스택의 서로 다른 계층, 특히 레이어 3과 4를 악용합니다.

DDoS 공격이 어떻게 작동하는지 이해하는 것은 AWS Shields가 채택하는 계층화된 방어 전략을 이해하는 데 필수적입니다.

## 3. AWS Shield Standard

AWS Shield Standard는 DDoS 공격에 대한 기본 보호를 제공합니다. 모든 AWS 고객에게 자동으로 제공되며 일반적인 네트워크와 전송 계층 공격에 대한 필수적인 방어를 제공합니다.

### 3.1. 무료이고 자동적인 보호

AWS Shield Standard의 핵심 이점 중 하나는 추가 비용 없이 제공된다는 것입니다. 이 서비스는 모든 AWS 고객에 대해 자동으로 활성화되어, 수동 구성이나 추가 요금 없이 즉각적인 보호를 제공합니다. 다양한 일반적인 DDoS 공격 기법을 완화하도록 설계되어, 최소한의 보안 구성을 가진 고객도 기초적인 수준의 방어를 받도록 보장합니다.

### 3.2. Layer 3/4 공격 완화

AWS Shield Standard는 OSI 모델의 하위 계층을 겨냥한 공격을 방어하도록 엔지니어링되어 있습니다.

- **Layer 3(네트워크 계층):** IP 스푸핑이나 기타 네트워크 수준 전술처럼 IP 계층을 조작하는 공격을 포함합니다.
- **Layer 4(전송 계층):** 서버 리소스를 압도하기 위해 전송 프로토콜을 겨냥하는 SYN 플러드와 UDP 플러드 같은 기법을 포함합니다.

이 계층들에 초점을 맞춤으로써 AWS Shield Standard는 네트워크와 전송 리소스를 고갈시키는 데 의존하는 많은 유형의 DDoS 공격을 효과적으로 무력화합니다.

## 4. AWS Shield Advanced

더 높은 수준의 보안이 필요한 조직을 위해 AWS Shield Advanced는 강화된 DDoS 보호를 제공합니다. 이 서비스는 더 정교한 DDoS 공격을 방어하고 공격 완화와 운영 연속성 모두를 지원하는 추가 도구와 리소스를 제공하도록 설계되었습니다.

### 4.1. 강화된 DDoS 방어 기능

AWS Shield Advanced는 복잡한 공격 벡터에 대응하도록 설계된 고급 기능을 통합함으로써 Standard 서비스의 기능을 기반으로 구축됩니다. 추가적인 AWS 서비스로 보호를 확장하고 대규모이고 표적화된 공격의 영향을 줄이기 위한 선제적인 전략을 사용합니다. 이 서비스는 기존 조치가 공격의 규모와 복잡성을 관리하는 데 충분하지 않을 수 있는 시나리오에서 특히 유용합니다.

### 4.2. 보호되는 서비스(EC2, CloudFront, Route 53 등)

Shield Advanced는 다음을 포함한 주요 AWS 리소스를 보호하도록 맞춤화되어 있습니다.

- **Amazon EC2:** 광범위한 애플리케이션을 구동하는 가상 서버입니다.
- **Elastic Load Balancing:** 여러 타겟에 걸쳐 수신되는 애플리케이션 트래픽을 분산합니다.
- **Amazon CloudFront:** 웹 콘텐츠 전달을 가속화하는 전역 콘텐츠 전송 네트워크(CDN)입니다.
- **AWS Global Accelerator:** 지능적인 라우팅을 통해 애플리케이션 가용성과 성능을 개선합니다.
- **Amazon Route 53:** 사용자 요청을 엔드포인트로 지시하는 확장 가능한 DNS 웹 서비스입니다.

이 서비스들에 대한 보호를 제공함으로써 AWS Shield Advanced는 DDoS 이벤트 동안 기반이 되는 컴퓨팅 인프라와 애플리케이션 전달 메커니즘 모두가 안전하게 유지되도록 보장합니다.

### 4.3. Layer 7 완화를 위한 자동 WAF 통합

네트워크와 전송 계층 보호를 넘어 AWS Shield Advanced는 AWS Web Application Firewall(WAF)과 자동으로 통합되어 Layer 7(애플리케이션 계층) 공격을 방어합니다. 공격이 발생하면 이 서비스는 동적으로 WAF 규칙을 생성, 평가, 배포할 수 있습니다. 이 자동화된 대응은 웹 애플리케이션의 취약점을 악용하려는 HTTP 플러드나 다른 정교한 공격 같은 애플리케이션 계층을 겨냥한 위협을 완화하는 데 도움을 줍니다.

### 4.4. CloudWatch 지표를 사용한 실시간 공격 모니터링

실시간 모니터링은 AWS Shield Advanced의 중요한 측면입니다. 이 서비스는 Amazon CloudWatch를 활용해 공격 중 네트워크의 진행 상태에 대한 인사이트를 제공하는 상세한 지표를 제공합니다. 주요 지표 중 일부는 다음을 포함합니다.

- **DDoSDetected:** DDoS 이벤트가 현재 진행 중인지 여부를 나타내는 이진 지표입니다.
- **DDoSAttackBitsPerSecond:** 초당 비트 단위로 공격 트래픽의 볼륨을 측정합니다.
- **DDoSAttackPacketsPerSecond:** 공격에 사용되는 초당 패킷 수를 추적합니다.
- **DDoSAttackRequestsPerSecond:** 리소스를 겨냥한 요청 트래픽의 비율에 대한 데이터를 제공합니다.

이 지표들은 보안 팀이 상황을 신속하게 평가하고 방어 전략을 실시간으로 조정할 수 있게 하여, 대응이 시기적절하고 효과적이도록 보장합니다.

### 4.5. 공격 비용에 대한 재정적 보호

DDoS 공격은 증가된 트래픽 부하와 네트워크 사용에 대한 잠재적인 초과 요금으로 인해 상당한 운영 비용을 초래할 수 있습니다. AWS Shield Advanced는 공격 중 발생할 수 있는 예상치 못한 비용으로부터 조직을 보호하는 재정적 보호 장치를 포함합니다. 이 서비스의 측면은 지속적인 공격이 발생하더라도 재정적 영향이 완화될 것이라는 확신을 제공합니다.

### 4.6. AWS DDoS Response Team에 대한 24/7 접근

자동화된 방어 외에도 AWS Shield Advanced는 하루 24시간 AWS DDoS Response Team(DRT)에 대한 직접 접근을 제공합니다. 이 전담 전문가 팀은 진행 중인 공격의 완화를 돕기 위해 24/7 사용 가능합니다. 그들의 전문성은 조직이 중요한 순간에 즉각적인 지침과 지원을 받아 정상적인 서비스 운영을 가능한 한 빠르게 복원할 수 있도록 보장합니다.

## 5. 결론

요약하면, AWS Shields를 통해 적절한 수준의 DDoS 보호를 이해하고 활용하는 것은 서비스 가용성을 유지하고, 운영 연속성을 보장하고, DDoS 공격과 관련된 재정적 영향을 관리하는 데 매우 중요합니다.
