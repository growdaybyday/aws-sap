# Amazon Detective

## 1. 소개

Amazon Detective는 보안 발견 사항과 사고의 조사를 간소화하기 위해 특별히 구축된 AWS 서비스입니다. 고급 머신 러닝과 그래프 분석을 활용함으로써 Amazon Detective는 근본 원인 분석을 가속화해, 보안 팀이 복잡하고 분산된 환경 전반에서 위협을 신속하게 식별, 이해, 개선할 수 있게 합니다. 이 장에서는 Amazon Detective, 그 운영 원칙, 다른 AWS 보안 서비스와의 통합, 보안 조사 수행에서의 실용적인 적용을 심층적으로 살펴봅니다.

## 2. Amazon Detective의 동작 방식

Amazon Detective는 다양한 AWS 소스로부터 데이터를 자동으로 수집, 처리, 분석함으로써 작동합니다. 이 서비스의 아키텍처는 머신 러닝과 그래프 분석이라는 두 가지 핵심 기술을 중심으로 구축되어 있습니다.

![Amazon Detective-arch](@site/docs/Security,%20Identity,%20and%20Compliance/_assets/amazon_detective-arch.png)

### 데이터 수집과 처리

Amazon Detective는 여러 AWS 데이터 소스와 통합해 환경에 대한 포괄적인 시각을 만듭니다. 다음을 수집합니다.

- **VPC Flow Logs:** 이 로그들은 리소스 간 데이터 흐름을 추적하는 데 도움을 주는 네트워크 트래픽에 대한 상세한 기록을 제공합니다.
- **CloudTrail 로그:** 이 로그들은 계정 활동과 API 호출을 캡처해, 사용자 작업과 시스템 이벤트에 대한 맥락을 제공합니다.
- **GuardDuty 발견 사항:** GuardDuty가 생성한 알림은 Detective로 전달되어, 더 깊은 분석의 진입점으로 작동합니다.
- **Amazon EKS 감사 로그**
- **AWS Security Hub 발견 사항**

이 소스들의 데이터를 통합함으로써 Amazon Detective는 맥락 정보가 풍부한 통합된 데이터셋을 구성합니다.

### 머신 러닝과 그래프 분석

Amazon Detective의 핵심에는 수집된 데이터를 처리해 즉시 명백하지 않을 수 있는 패턴, 이상, 상관 관계를 식별하는 머신 러닝 엔진이 있습니다. 그래프 분석은 사용자, 리소스, 네트워크 흐름 같은 서로 다른 엔티티 사이의 관계를 환경 전반에서 시각적으로 매핑함으로써 이 프로세스를 더욱 강화합니다.

![Amazon-Detective-Machine Learning and Graph Analytics](@site/docs/Security,%20Identity,%20and%20Compliance/_assets/amazon-detective-machine_learning_and_graph_analytics.png)

이 이중 접근 방식은 Amazon Detective가 다음을 할 수 있게 합니다.

- **이벤트 자동 연관:** 서로 다른 데이터 소스로부터의 관련 이벤트를 연결해 일관된 서술을 구축합니다.
- **복잡한 상호작용 시각화:** 다양한 요소가 상호작용하는 방식을 강조하는 직관적인 그래프 형식으로 데이터를 제시해, 보안 문제의 근원을 더 쉽게 파악할 수 있게 합니다.
- **조사 가속화:** 방대한 로그 데이터를 정밀 조사하는 데 필요한 수동 작업을 줄임으로써 보안 팀은 탐지에서 개선으로 신속하게 전환할 수 있습니다.

## 3. AWS 보안 서비스와의 통합

Amazon Detective는 다른 AWS 보안 서비스와 협력해 작동하도록 설계되어, 통합된 방어와 조사 프레임워크를 형성합니다.

### 보안 발견 사항의 매끄러운 수집

GuardDuty, Macie, Security Hub 같은 보안 서비스는 잠재적인 보안 문제를 플래그하는 데 필수적입니다. 이 서비스들이 이상(비정상적인 네트워크 트래픽, 무단 접근 시도, 데이터 이상 등)을 탐지하면 자동으로 Amazon Detective로 전송되는 발견 사항을 생성합니다. 이 매끄러운 통합은 모든 알림에 효과적인 문제 해결에 필요한 상세한 맥락 분석이 함께 제공되도록 보장합니다.

### 데이터 기반 아키텍처

VPC Flow Logs, CloudTrail, GuardDuty의 데이터를 활용함으로써 Amazon Detective는 보안 이벤트에 대한 통합된 시각을 만듭니다. 이 통합은 다음에 매우 중요합니다.

- **알림에 맥락 부여:** 무슨 일이 일어났는지뿐만 아니라 전체 이벤트 체인을 검토함으로써 그것이 어떻게 일어났는지도 이해합니다.
- **탐지 정확도 강화:** 여러 데이터 포인트를 상호 참조함으로써 거짓 양성을 걸러내고 진짜 위협에 집중하는 데 도움이 됩니다.
- **규정 준수와 감사 추적 지원:** 보안 이벤트에 대한 상세한 기록을 유지하는 것은 내부 조사와 외부 규제 준수 모두에 도움이 됩니다.

한 예시 시나리오는 CloudTrail을 의도적으로 또는 의도치 않게 비활성화하는 것을 포함합니다. GuardDuty는 이러한 이벤트에 대한 응답으로 발견 사항을 생성할 수 있습니다. Amazon Detective는 그런 다음 이 발견 사항을 수집하고, 머신 러닝 능력을 사용해 기반이 되는 데이터를 분석하고, 그 작업이 악의적이었는지 무해했는지 명확하게 하는 시각화를 제공할 수 있습니다.

## 4. 보안 조사 수행하기

Amazon Detective의 진정한 힘은 조사 과정에서 실현됩니다. 잠재적인 보안 문제가 플래그되면 보안 팀은 Detective의 포괄적인 분석을 활용해 철저한 조사를 수행할 수 있습니다.

### 조사 시작하기

조사는 일반적으로 GuardDuty에 의해 보안 발견 사항이 생성될 때 시작됩니다. 발견 사항이 탐지되면 Amazon Detective의 자동화된 프로세스가 관련 데이터를 집계하기 시작합니다.

- **이벤트 상관 관계:** 시스템은 VPC Flow Logs, CloudTrail, GuardDuty의 이벤트를 자동으로 연결해, 이벤트 순서를 이해하는 데 필수적인 활동의 타임라인을 만듭니다.
- **알림 분류:** 머신 러닝을 사용해 Detective는 알림이 진양성인지 거짓 양성인지 판단하는 데 도움을 주어, 진짜 위협에 초점을 맞추도록 간소화합니다.

### 범위 지정과 분석

초기 분류 후 보안 분석가는 Detective의 시각적 도구를 사용해 조사의 범위를 정할 수 있습니다. 이 프로세스의 주요 단계는 다음을 포함합니다.

- **영향받은 시스템 식별:** 어떤 시스템, 사용자, 또는 네트워크 세그먼트가 침해되었을 수 있는지 판단합니다.
- **공격 벡터 매핑:** CloudTrail 같은 중요한 서비스의 비활성화를 통한 것처럼 침입이 어떻게 발생했는지 확립하기 위해 의심스러운 활동의 출처를 추적합니다.
- **영향 평가:** 의심스러운 활동이 얼마나 오래 지속되었는지, 어떤 데이터나 서비스가 영향을 받았는지를 포함해 침해의 범위를 이해합니다.

이 기능들은 신속한 개선이 필요한 시나리오에서 특히 가치가 있습니다. 예를 들어 CloudTrail이 비활성화된 경우 Detective는 누가 변경을 했는지, 어디서 변경이 시작되었는지, 그 결과 어떤 다른 시스템이 침해되었을 수 있는지 식별하는 데 도움을 줄 수 있습니다. 이 상세한 인사이트는 CloudTrail을 다시 활성화하고 향후 발생을 방지하기 위한 추가적인 안전장치를 구현하는 것 같은 타겟 대응을 가능하게 합니다.

### 대응과 개선

조사가 완료되면 Amazon Detective가 수집한 정보는 견고한 대응 전략의 개발을 지원합니다. 명확한 시각화와 포괄적인 데이터는 보안 팀이 다음을 할 수 있게 합니다.

- 근본 원인을 해결함으로써 정상적인 운영을 신속하게 재수립합니다.
- 침해된 시스템을 보안하기 위한 교정 조치를 구현합니다.
- 사고로부터 학습해 향후 보안 태세를 강화합니다.

## 5. 결론

Amazon Detective는 보안 사고를 신속하고 효과적으로 처리해야 하는 조직에게 필수적인 도구입니다. 대응의 속도와 정확성이 소규모 침해와 주요 보안 재난 사이의 차이를 만들 수 있는 시대에, Amazon Detective는 견고하고 안전한 클라우드 환경을 유지하는 데 필요한 기술적 우위를 제공합니다.
