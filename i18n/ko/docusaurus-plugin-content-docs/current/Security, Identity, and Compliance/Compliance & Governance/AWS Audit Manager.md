# AWS Audit Manager

## 1. 소개

오늘날의 클라우드 환경에서 조직은 계속 증가하는 규정 준수 요구 사항과 빈번한 감사에 직면합니다. AWS Audit Manager는 AWS 사용량을 지속적으로 감사하는 서비스를 제공함으로써 이 과제를 해결해, 외부와 내부 감사에 대한 준비 상태를 유지할 수 있게 합니다. 회사가 GDPR, HIPAA, PCI 같은 프레임워크를 준수해야 하는지 여부와 관계없이 Audit Manager는 증거의 수집과 조직화를 자동화함으로써 프로세스를 단순화합니다. 이 서비스는 AWS 워크로드 전반의 위험과 규정 준수를 평가할 수 있게 하여, 정책, 절차, 활동(통틀어 통제라고 함)이 얼마나 잘 작동하고 있는지에 대한 명확한 시각을 제공합니다.

규정 준수 보고서와 증거 폴더를 자동으로 수집함으로써 AWS Audit Manager는 감사 준비에 관련된 수동 작업 부담을 줄여줍니다. 조직이 발전함에 따라 이 서비스는 리소스가 선택한 규제 표준을 계속 준수하는지 지속적으로 검증해, 감사 태세가 견고하게 유지되도록 보장합니다.

## 2. 핵심 기능

AWS Audit Manager는 위험 평가와 규정 준수 활동을 간소화하는 여러 핵심 기능을 제공합니다.

### 2.1. 지속적인 규정 준수와 위험 평가

Audit Manager는 AWS 리소스를 지속적으로 모니터링해 선택한 프레임워크에 정의된 규정 준수 요구 사항을 준수하는지 판단합니다. 각 리소스와 관련된 위험을 자동으로 평가하고 통제 격차를 식별합니다. 리소스가 준수하지 않는 경우 이 서비스는 알림을 보내고 규정을 준수하지 않는 문제를 해결하기 위한 실행 가능한 항목을 제공합니다. 이 지속적인 평가는 인프라가 성장하더라도 항상 규정 준수 태세를 인식할 수 있도록 보장합니다.

### 2.2. 자동화된 증거 수집

AWS Audit Manager의 주요 강점 중 하나는 증거 수집을 자동화하는 능력입니다. 평가가 시작되면 이 서비스는 정의된 AWS 계정, 리전, 서비스 전반에서 증거 수집을 시작합니다. 증거에는 리소스 구성 스냅샷, 변경 활동 로그, 규정 준수 확인 결과가 포함될 수 있으며, 각각은 평가의 특정 통제 요구 사항에 매핑됩니다. 이러한 작업을 자동화함으로써 Audit Manager는 전통적으로 수동 증거 수집과 관련된 노동 집약적인 노력을 줄여줍니다.

### 2.3. 멀티 계정/리전 지원

복잡하고 분산된 AWS 환경을 가진 조직을 위해 Audit Manager는 멀티 계정과 멀티 리전 배포에 대한 강력한 지원을 제공합니다. AWS Organizations와의 통합을 통해 이 서비스는 수많은 계정에 걸쳐 평가를 수행하고 증거를 하나의 중앙화된 위임된 관리자 계정으로 통합할 수 있습니다. 이 기능은 리소스가 어디에 있든 규정 준수 상태에 대한 일관되고 포괄적인 시각을 유지할 수 있도록 보장합니다.

## 3. AWS 서비스 통합

AWS Audit Manager는 독립적으로 작동하지 않습니다. 보안과 규정 준수 환경에 대한 전체적인 시각을 제공하기 위해 여러 다른 AWS 서비스와 긴밀하게 통합됩니다.

- **AWS Security Hub:** Audit Manager는 Security Hub의 결과를 활용해 규정 준수 증거를 수집합니다 — AWS 리소스에 대해 실행된 보안 점검과 규정 준수 평가의 결과를 캡처합니다.
- **AWS Config:** AWS Config와 통합함으로써 Audit Manager는 리소스가 정의된 표준을 준수하는지 판단하는 데 필수적인 구성 스냅샷과 규칙 평가를 수집합니다.
- **AWS CloudTrail:** CloudTrail 로그는 계정 내 API 호출과 변경 사항에 대한 상세한 감사 추적을 제공합니다. Audit Manager는 이 정보를 사용해 리소스 변경과 사용자 활동에 대한 증거를 뒷받침합니다.
- **AWS Control Tower:** 여러 계정을 관리하는 조직을 위해 Control Tower는 거버넌스와 모범 사례를 강제하는 데 도움을 줍니다. Audit Manager는 Control Tower와 함께 작동해 가드레일과 규정 준수 점검을 전체 감사 프로세스에 통합합니다.
- **AWS License Manager:** 소프트웨어 라이선싱 감사를 지원하기 위해 Audit Manager는 License Manager와 통합해 — 라이선스 사용 정보를 집계하고 정의된 라이선싱 통제에 매핑합니다.

이러한 통합은 광범위하고 자동화되고 효율적인 증거 수집을 가능하게 해, 감사 준비 시 AWS 사용량의 모든 측면이 다뤄지도록 보장합니다.

## 4. 감사 워크플로 설정

AWS Audit Manager의 감사 워크플로는 지속적인 규정 준수를 위한 종단 간 솔루션을 제공하도록 설계되었습니다.

![AWS Audit Manager](@site/docs/Security,%20Identity,%20and%20Compliance/_assets/aws_audit_manager.png)

1. **프레임워크 선택:** 조직이 충족해야 하는 규제나 산업 표준과 일치하는 하나 이상의 미리 구축된 프레임워크를 선택하는 것부터 시작합니다. 프레임워크는 각각 상세한 테스트 절차와 요구 사항을 가진 구조화된 통제 집합을 제공합니다.
2. **범위 정의:** 포함할 AWS 계정, 리전, 서비스를 지정해 평가 범위를 정의합니다. 이 단계는 Audit Manager가 올바른 리소스로부터 증거를 수집하고 불필요한 노이즈를 제거하도록 보장합니다.
3. **자동화된 증거 수집:** 평가가 시작되면 Audit Manager는 통합된 데이터 소스(AWS Config, CloudTrail, Security Hub 등)로부터 자동으로 증거를 수집합니다. 이 증거는 통제별로 조직화되어 안전하게 저장됩니다.
4. **통제 검토와 위임:** 각 통제에 대해 수집된 증거를 검토합니다. 필요한 경우 증거를 검증하거나 수동 입력으로 보완할 수 있는 담당자에게 특정 통제를 위임합니다.
5. **근본 원인 분석과 개선:** 어떤 통제가 규정을 준수하지 않는 것으로 확인되면 Audit Manager는 근본 원인을 식별하고 문제를 신속하게 개선할 수 있는 실행 가능한 인사이트를 제공합니다.
6. **보고서 생성:** 마지막으로 평가가 완료되면 감사 준비가 된 보고서를 생성합니다. 이 보고서에는 요약 문서와 정리된 증거 폴더가 포함되어 있어, 공식 감사 중 규정 준수를 더 쉽게 입증할 수 있습니다.

이 워크플로는 수동 작업을 줄일 뿐만 아니라 감사와 규정 준수 팀이 새로운 위험과 규정 준수 격차에 신속하게 대응할 수 있도록 보장합니다.

## 5. 결론

AWS Audit Manager는 전통적이고 노동 집약적인 감사 프로세스를 간소화되고 자동화된 워크플로로 전환하는 강력한 서비스입니다. AWS 환경을 지속적으로 모니터링하고, 증거 수집을 자동화하고, 핵심 AWS 서비스와 통합함으로써 Audit Manager는 조직이 위험을 평가하고 규정 준수를 유지하는 방식을 단순화합니다. 여러 계정과 리전에 걸쳐 확장할 수 있는 능력은 복잡한 규제 요구 사항에 직면한 현대 기업에게 필수적인 도구가 되게 합니다.
