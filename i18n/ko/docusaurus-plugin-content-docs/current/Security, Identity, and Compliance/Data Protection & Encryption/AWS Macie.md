# AWS Macie

## 1. 소개

AWS Macie는 Amazon S3 버킷을 지속적으로 모니터링해 민감한 정보를 탐지함으로써 조직이 데이터를 보호하도록 돕도록 설계되었습니다. 그 핵심에서 Macie는 머신 러닝 알고리즘을 활용해 비민감 데이터와 민감 데이터를 구별하며, 이름, 주소, 기타 개인 정보 같은 PII를 탐지하는 데 강하게 초점을 맞춥니다. 이 서비스는 발견 프로세스를 자동화하고 AWS EventBridge를 통해 알림을 전송함으로써 데이터 보안을 단순화하며, 이는 AWS SNS, Lambda 함수, 기타 서비스와 더 통합할 수 있습니다. 이 원클릭 활성화 프로세스는 관리자가 분석할 S3 버킷을 지정할 수 있게 하여, 민감한 데이터가 눈에 띄지 않게 지나가는 일이 없도록 보장합니다.

## 2. 핵심 기능과 설정

### 기능 개요

AWS Macie는 다음을 통해 민감한 데이터 보호를 자동화합니다.

![AWS Macie](@site/docs/Security,%20Identity,%20and%20Compliance/_assets/aws_macie.png)

- **머신 러닝과 패턴 매칭:** Macie는 S3 버킷을 지속적으로 스캔하며, 정교한 알고리즘을 사용해 PII로 분류될 수 있는 데이터를 식별합니다.
- **자동화된 알림:** 민감한 데이터가 감지되면 Macie는 EventBridge를 통해 알림을 생성합니다. 이 알림은 자동화된 개선이나 추가 분석을 가능하게 하기 위해 SNS나 Lambda 같은 다른 AWS 서비스로 라우팅될 수 있습니다.
- **간소화된 배포:** Macie를 활성화하는 것은 간단합니다. 한 번의 클릭으로 관리자는 서비스를 활성화하고 광범위한 구성 없이도 모니터링하고자 하는 S3 버킷을 선택할 수 있습니다.

### Macie 설정하기

AWS Macie의 설정 프로세스는 빠르고 사용자 친화적으로 설계되었습니다.

- **원클릭 활성화:** 관리자는 대상 S3 버킷을 지정하는 것만으로 최소한의 구성으로 서비스를 시작합니다.
- **AWS 생태계와의 통합:** 활성화되면 Macie는 다른 AWS 서비스(EventBridge, SNS 등)와 매끄럽게 통합되어 포괄적인 보안 태세를 제공합니다.
- **운영 투명성:** Macie는 AWS 콘솔을 통해 중앙화된 뷰를 제공해, 보안 팀이 조직 전체에서 민감한 데이터 발견 사항의 상태를 모니터링하고 검토할 수 있게 합니다.

## 3. 데이터 식별자: 관리형과 커스텀

### 관리형 데이터 식별자

AWS는 일반적인 유형의 민감한 정보를 인식하도록 특별히 설계된 사전 구성된 관리형 데이터 식별자 집합을 제공합니다. 여기에는 다음이 포함됩니다.

- **신용카드 번호:** 다양한 신용카드 형식을 감지하는 패턴.
- **AWS 자격 증명:** AWS 액세스 키와 시크릿 키의 식별.
- **은행 계좌 정보:** 확립된 숫자 및 텍스트 패턴을 통한 은행 정보 인식.

이 내장 식별자들은 표준적인 민감 데이터 유형이 자동으로 플래그되도록 보장해, 탐지 규칙을 수동으로 구성해야 하는 보안 팀의 부담을 줄여줍니다.

### 커스텀 데이터 식별자

관리형 식별자 외에도 Macie는 특정 조직의 필요에 맞춘 커스텀 데이터 식별자를 만들 수 있게 합니다.

- **정규식 지원:** 관리자는 내부 직원 ID나 고객 계정 번호 같은 고유한 데이터 형식을 대상으로 하기 위해 정규식을 사용해 패턴을 정의할 수 있습니다.
- **키워드와 근접성 규칙:** 커스텀 식별자는 특정 키워드나 근접성 규칙을 사용해 구성할 수도 있어, 표준 패턴을 따르지 않을 수 있는 민감한 데이터의 탐지를 가능하게 합니다.
- **허용 목록 기능:** 거짓 양성을 줄이기 위해 Macie는 허용 목록 사용을 지원합니다. 이 기능은 알려진 비민감 패턴(예: 퍼블릭 전화번호)이 알림을 트리거하지 않도록 제외할 수 있게 합니다.

관리형과 커스텀 식별자를 결합함으로써 AWS Macie는 어떤 조직의 다양한 보안 요구 사항도 정확하게 맞춤화할 수 있는 유연한 프레임워크를 제공합니다.

## 4. 발견 사항, 보고, 억제

### 민감 데이터 발견 사항

Macie가 잠재적인 민감 데이터를 탐지하면 다음을 포함하는 상세한 발견 사항을 생성합니다.

- **심각도 등급:** 각 발견 사항에는 감지된 데이터와 관련된 잠재적 위험에 기반한 심각도 수준이 할당됩니다.
- **영향받는 리소스:** 민감한 데이터가 존재하는 특정 S3 오브젝트와 관련 리소스가 명확하게 식별됩니다.
- **타임스탬프:** 각 발견 사항에는 타임스탬프가 찍혀, 데이터가 감지된 시점에 대한 명확한 감사 추적을 제공합니다.

이 발견 사항들은 민감 데이터 발견 프로세스에 대한 포괄적인 기록으로 작용해, 시기적절하고 정보에 기반한 의사 결정을 가능하게 합니다.

### 보고와 데이터 저장

- **민감 데이터 발견 결과:** Macie는 S3 오브젝트에 대해 수행된 모든 분석의 상세한 보고서를 편집합니다. 이 보고서는 장기 보존과 과거 분석을 위해 Amazon S3에 저장할 수 있습니다.
- **Athena를 사용한 대량 쿼리:** 저장된 보고서는 Amazon Athena를 사용해 대량으로 쿼리할 수 있어, 조직이 복잡한 분석을 수행하고 온디맨드로 커스텀 보고서를 생성할 수 있게 합니다.

### 억제 규칙

발견 사항을 관리하고 간소화하기 위해:

- **자동화된 억제:** 관리자는 특정 필터에 기반해 발견 사항을 자동으로 아카이빙하는 억제 규칙을 정의할 수 있습니다. 이는 우선순위가 낮거나 이미 해결된 것으로 간주되는 발견 사항을 필터링해 노이즈를 줄이는 데 도움을 줍니다.
- **보존 기간:** 모든 발견 사항은 90일간 보존되며, 그 이후에는 아카이빙되거나 삭제될 수 있습니다. 이 기간 동안 발견 사항은 AWS 콘솔을 사용해 검토하거나, EventBridge를 통해 모니터링하거나, AWS Security Hub로 직접 전달할 수 있습니다.

### 정책 관련 발견 사항

Macie는 모범 사례에 따라 S3 버킷 구성도 평가합니다.

- **정책 평가 발견 사항:** 이 발견 사항은 기본 암호화 비활성화나 퍼블릭하게 접근 가능한 버킷 같은 구성 문제를 강조합니다. 이러한 정책 관련 발견 사항은 S3 환경의 전체적인 보안 태세가 유지되도록 보장하는 데 중요합니다.
- **민감 데이터 발견 사항:** 정책 문제 외에도 Macie는 민감한 데이터(자격 증명, 프라이빗 키, 금융 정보 등)가 노출되는 사례를 식별하는 데 초점을 맞춥니다. 커스텀 데이터 식별자는 이 발견 사항에서 명확하게 표시되어, 감지된 이상 사항에 대한 맥락을 제공합니다.

## 5. AWS Organizations를 사용한 멀티 계정 관리

AWS Macie는 조직 내 여러 AWS 계정에 걸쳐 확장되도록 설계되었습니다. 이 멀티 계정 관리 기능은 분산되거나 멀티 테넌트 환경에서 운영되는 엔터프라이즈에 필수적입니다.

### 위임된 관리

- **중앙화된 통제:** 위임된 관리 기능을 통해 지정된 관리자 계정이 여러 회원 계정을 관리할 수 있습니다. 이 중앙화된 관리는 조직 전체에 걸쳐 일관된 보안 정책을 유지하는 데 매우 중요합니다.
- **계정 관리:** 관리자 계정은 회원 계정을 추가하거나 제거할 수 있는 능력을 가져, 민감 데이터 모니터링과 보호가 일관되게 적용되도록 보장합니다.
- **포괄적인 접근:** 관리자 계정은 관리되는 모든 계정의 S3 민감 데이터와 보안 설정에 접근할 수 있는 권한이 부여되어, 조직의 보안 태세에 대한 전체적인 시각을 가능하게 합니다.

### 확장 가능한 데이터 발견

- **자동화된 민감 데이터 발견:** 멀티 계정 설정은 모든 계정에 걸친 자동화된 민감 데이터 발견 작업의 조율을 허용합니다. 이는 조직 내 모든 S3 버킷이 지속적으로 모니터링되도록 보장합니다.
- **대규모 데이터 식별자:** 관리형과 커스텀 데이터 식별자 모두 계정 전반에 배포하고 관리할 수 있어, 민감한 데이터의 일관된 탐지를 촉진합니다.
- **중앙화된 발견 사항 관리:** 모든 회원 계정의 발견 사항을 중앙에서 집계, 저장, 분석할 수 있어, 전사적인 데이터 보안에 대한 통합된 관점을 제공합니다.

이러한 멀티 계정 관리 기능을 활용함으로써 조직은 확장 가능하고 효율적인 민감 데이터 보호를 달성할 수 있어, AWS 환경의 모든 측면이 견고한 보안 표준을 준수하도록 보장합니다.

## 6. 결론

AWS Macie는 특히 Amazon S3 내에서 AWS 환경 내 민감한 데이터를 보호하기 위한 강력하고 완전관리형 솔루션을 제공합니다. 정확한 데이터 식별을 위해 머신 러닝을 활용하는 능력과 유연한 관리형 및 커스텀 데이터 식별자가 결합되어, 데이터 보안과 개인정보 보호에 필수 불가결한 도구가 됩니다.

Amazon Athena와 AWS Security Hub 같은 도구와의 통합을 포함한 이 서비스의 상세한 발견 사항과 보고 기능은 조직에게 잠재적인 보안 문제에 신속하게 대응하는 데 필요한 인사이트를 제공합니다. 게다가 AWS Organizations를 통한 멀티 계정 관리에 대한 Macie의 지원은 크고 복잡한 인프라조차 일관되고 견고한 보안 태세를 유지할 수 있도록 보장합니다.

요약하면, AWS Macie는 민감한 데이터 발견 프로세스를 단순화할 뿐만 아니라 현대적이고 분산된 클라우드 환경 전반에서 데이터를 보호하는 데 필요한 확장성과 통합도 제공하는 포괄적인 솔루션으로 돋보입니다.
