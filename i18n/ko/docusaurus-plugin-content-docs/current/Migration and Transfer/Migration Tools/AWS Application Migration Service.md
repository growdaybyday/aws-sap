# AWS Application Migration Service(MGN)
## 1. 소개

AWS Application Migration Service(AWS MGN)는 애플리케이션을 AWS로 마이그레이션하는 것을 단순화하고, 신속하게 하고, 비용을 줄이도록 설계된 포괄적이고 자동화된 솔루션입니다. 최소한의 다운타임으로, 광범위한 재아키텍처링 없이 애플리케이션을 이전하는 것이 목표인 "lift-and-shift" 마이그레이션에 특히 효과적입니다.

![AWS Application Migration Service (MGN)](@site/docs/Migration%20and%20Transfer/_assets/aws_application_migration_service_(mgn).png)

AWS MGN을 사용하면 온프레미스, 가상화, 클라우드 기반 애플리케이션을 AWS로 빠르게 마이그레이션할 수 있습니다. 물리적 하드웨어, VMware, Hyper-V, 다른 환경에서 실행되든 상관없이 소스 서버를 네이티브 AWS 인스턴스로 변환하는 것을 자동화합니다. 이 자동화는 마이그레이션 중 수동적이고 오류가 발생하기 쉬운 프로세스를 최소화합니다.

이 서비스는 소스 서버를 AWS 계정으로 지속적으로 복제합니다. 준비가 되면 AWS MGN은 자동으로 이 서버들을 AWS에서 변환하고 시작해, 다운타임을 줄이고 마이그레이션 프로세스를 가속화합니다.

## 2. 핵심 기능과 이점

- **자동화된 마이그레이션 프로세스:**
    AWS MGN은 복제, 변환, 테스트, 전환 프로세스를 자동으로 처리합니다. 이는 수동 개입을 최소화하고 오류 가능성을 줄여줍니다.
    
- **최소한의 다운타임:**
    소스 데이터를 지속적으로 복제하고 테스트 시작을 가능하게 함으로써 프로덕션 운영을 중단시키지 않고 마이그레이션을 검증할 수 있습니다.
    
- **비용 절감:**
    다양한 애플리케이션을 마이그레이션하기 위해 단일 도구를 사용하면 여러 애플리케이션 특화 마이그레이션 도구나 전문화된 기술에 투자할 필요가 없습니다.
    
- **현대화 지원:**
    마이그레이션 중 상당한 중단 없이 운영체제 업그레이드나 라이선스 변환 같은 애플리케이션 현대화 옵션을 사용할 수 있습니다.
    
- **광범위한 사용 사례:**
    (SAP, Oracle, SQL Server 같은) 레거시 온프레미스 애플리케이션을 마이그레이션하든 AWS 리전과 계정 간에 워크로드를 이전하든, AWS MGN은 다양한 시나리오를 처리하도록 설계되었습니다.
    
- **AWS 서비스와의 통합:**
    애플리케이션이 AWS에서 실행되면 다른 AWS 서비스를 활용해 환경을 더욱 최적화, 보안, 확장할 수 있습니다.

## 3. 마이그레이션 워크플로

1. **복제:**
    소스 서버에 AWS 복제 에이전트를 설치해 AWS로 데이터를 지속적으로 전송합니다.
    
2. **변환:**
    서비스가 소스 서버 이미지를 자동으로 변환해 AWS에서 네이티브로 실행할 수 있게 합니다.
    
3. **테스트:**
    AWS에서 테스트 인스턴스를 시작해 마이그레이션된 애플리케이션이 예상대로 작동하는지 검증합니다 — 이는 실제 프로덕션 환경에 영향을 주지 않고 수행됩니다.
    
4. **전환(Cutover):**
    준비가 되면 최소한의 다운타임으로 프로덕션 워크로드를 AWS로 전환합니다.
    
5. **마이그레이션 후 작업:**
    마이그레이션 후에는 더 폭넓은 현대화를 위해 광범위한 AWS 서비스를 활용해 애플리케이션을 리플랫폼하거나 리팩토링할 수 있습니다.

## 4. 특화된 사용 사례와 고려 사항

- **온프레미스에서 AWS로:**
    물리적 서버, 가상 머신(예: VMware, Hyper-V), 다른 온프레미스 인프라에서 실행되는 애플리케이션을 마이그레이션합니다.
    
- **클라우드 간 마이그레이션:**
    다른 클라우드 제공자에서 AWS로 애플리케이션을 이전해 AWS의 광범위한 서비스에 접근합니다.
    
- **리전 간 마이그레이션:**
    규제, 복원력, 성능 요구 사항을 충족하기 위해 AWS 리전, 가용 영역, 계정 간에 워크로드를 마이그레이션합니다.
    
- **AWS GovCloud(US):**
    정부나 규제 대상 워크로드의 경우 AWS MGN은 서드파티 통합이나 특정 리플랫폼 도구 같은 시작 후 작업에 일부 제한이 있는 상태로 AWS GovCloud(US)에서 사용할 수 있습니다.
    
- **확장성과 제한:**
    이 서비스는 기본적으로 AWS 리전당 최대 20대의 서버가 동시에 복제되는 것을 지원하며(60대까지 확장 가능), 마이그레이션 작업당 최대 200대의 소스 서버를 처리할 수 있습니다. 이러한 할당량은 균형 잡힌 복제 프로세스와 시스템 안정성을 보장하는 데 도움을 줍니다.

## 5. 시작하기와 자료

- **콘솔과 API 접근:**
    AWS Management Console을 통해 또는 API를 통해 프로그래밍 방식으로 마이그레이션을 시작할 수 있어, 운영 요구에 따라 유연성을 제공합니다.
    
- **교육과 문서:**
    AWS는 초기 계획부터 마이그레이션 후 최적화까지 마이그레이션 프로세스를 탐색하는 데 도움이 되는 광범위한 온라인 교육, 상세한 사용자 가이드, 모범 사례 문서를 제공합니다.
    
- **커뮤니티와 지원:**
    AWS는 포럼, 고객 사례 연구, 다양한 마이그레이션 시나리오에 맞춘 권장 사항을 포함하는 AWS Prescriptive Guidance를 통해 커뮤니티 지원을 제공합니다.

## 6. 결론

AWS Application Migration Service는 애플리케이션을 AWS로 이전하는 프로세스를 자동화하고 간소화하는 견고한 도구입니다. 주요 이점으로는 다운타임 감소, 비용 효율성, 마이그레이션 중 애플리케이션을 현대화할 수 있는 능력이 있습니다. 온프레미스 환경에서, 클라우드 제공자 간에, 또는 AWS 리전 전반에서 마이그레이션하든, AWS MGN은 기업이 클라우드에서 민첩성과 운영 효율성을 달성하는 데 도움을 주는 통합되고 자동화된 솔루션을 제공합니다.
