# AWS Application Discovery Service
## 1. 소개

AWS Application Discovery Service는 조직이 AWS 클라우드로의 마이그레이션을 준비하면서 온프레미스 인프라에 대한 가시성을 확보하도록 돕기 위해 설계된 포괄적인 도구 모음입니다. 아래는 목적, 핵심 기능, 작동 모드, 사용 사례, 가격 정책, 다른 AWS 서비스와의 통합을 다루는 심층적인 개요입니다.

AWS Application Discovery Service는 온프레미스 서버와 데이터베이스에서 구성, 성능, 종속성 데이터 수집을 자동화합니다. 이 정보는 클라우드 마이그레이션 계획에 매우 중요하며, 기업이 워크로드를 AWS로 옮기기 전에 총 소유 비용(TCO) 평가, 종속성 매핑, 리소스 적정 크기 조정 같은 상세한 분석을 수행할 수 있게 해줍니다. 이 서비스는 수집된 데이터를 AWS Migration Hub 홈 리전에 중앙화해, 전체 포트폴리오에 걸쳐 마이그레이션 계획과 추적이 간소화되도록 보장합니다.

## 2. 작동 방식

### 2.1. 검색 모드

AWS Application Discovery Service는 데이터 수집을 위한 여러 접근 방식을 지원합니다.

- **에이전트리스 검색**
    Agentless Collector(OVA 파일로 제공)는 VMware vCenter 환경에 배포됩니다. 각 가상 머신에 에이전트를 설치하지 않고도 호스트 이름, IP 주소, 리소스 할당, 과거 활용 지표 같은 정적 구성 데이터를 수집합니다. 이 방법은 가상화된 환경의 개요를 신속하게 파악하는 데 이상적이지만, 실행 중인 프로세스나 내부 네트워크 연결 같은 심층적인 세부 사항은 캡처하지 않습니다.
    
- **에이전트 기반 검색**
    더 깊은 통찰이 필요한 경우 물리적 서버, 가상 머신, 심지어 EC2 인스턴스에 AWS Application Discovery Agent를 설치할 수 있습니다. 이 에이전트는 시스템 성능, 실행 중인 프로세스, 인바운드와 아웃바운드 네트워크 연결에 대한 상세한 시계열 데이터를 수집하며, 이는 애플리케이션 종속성을 정확하게 매핑하는 데 유용합니다.
    
- **파일 기반 가져오기와 서드파티 통합**
    CSV 템플릿을 사용해 기존 구성 관리 데이터베이스(CMDB)에서 데이터를 가져오는 옵션도 있습니다. 또한 AWS 파트너 네트워크(APN) 솔루션은 공개 API를 통해 Application Discovery Service와 통합해 데이터를 Migration Hub로 직접 가져오고 상호 연관시킬 수 있습니다.

### 2.2. 데이터 흐름과 분석

1. **데이터 수집:**
    - 선택한 검색 방법이 시스템 구성, 성능 지표(CPU, 메모리, 디스크, 네트워크 사용량), 애플리케이션 종속성을 포함한 정적 및 동적 데이터를 수집합니다.
    - 에이전트 기반 검색의 경우 데이터가 지속적으로 수집되어 시간에 따른 추세를 분석할 수 있습니다.

2. **데이터 저장과 분석:**
    - 수집된 모든 정보는 AWS Migration Hub 홈 리전에 저장됩니다. 이 데이터를 Amazon Athena와 Amazon QuickSight 같은 도구에서 추가 분석을 위해 내보낼 수 있습니다.
    - 상세한 성능 기준선이 설정되며, 클라우드 마이그레이션의 성공을 평가하기 위해 마이그레이션 후 지표와 비교할 수 있습니다.

3. **마이그레이션 계획:**
    - 서버 종속성과 리소스 활용에 대한 명확한 통찰을 바탕으로 서버를 애플리케이션으로 그룹화하고, 마이그레이션 비용을 추정하고, AWS Migration Hub와 AWS Server Migration Service 같은 통합 도구를 사용해 마이그레이션 웨이브를 계획할 수 있습니다.

## 3. 핵심 기능

- **포괄적인 인프라 가시성:**
    IP 주소, MAC 주소, 리소스 할당, 활용 지표를 포함한 상세한 서버와 데이터베이스 구성을 수집합니다.
    
- **종속성 매핑:**
    (에이전트 사용 시) 네트워크 연결과 프로세스 수준 세부 사항을 캡처해 서버와 애플리케이션 간 상호 종속성을 매핑하는 데 도움을 줍니다.
    
- **성능 지표:**
    CPU, 메모리, 디스크 I/O, 네트워크 처리량 같은 지표를 통해 시스템 성능을 측정해 성능 기준선을 수립합니다.
    
- **데이터 탐색:**
    Amazon Athena와 통합해 더 깊은 분석을 가능하게 하여, 시계열 데이터에 쿼리를 실행하고 Amazon QuickSight에서 성능 추세를 시각화할 수 있습니다.
    
- **원활한 통합:**
    AWS Migration Hub, AWS Database Migration Service Fleet Advisor, 다른 AWS 마이그레이션 서비스와 함께 작동해 통합된 마이그레이션 계획 경험을 제공합니다.
    
- **보안과 데이터 보호:**
    모든 데이터가 전송 중(HTTPS/TLS 사용)과 AWS 클라우드 내 저장 중 모두 암호화되며, 검색 데이터가 저장되는 위치(즉 Migration Hub 홈 리전)에 대한 엄격한 통제를 보장합니다.

## 4. 사용 사례

- **마이그레이션 계획:**
    온프레미스 구성과 성능 데이터를 분석해 포괄적인 마이그레이션 계획을 만듭니다. 여기에는 서버를 애플리케이션으로 그룹화하고 마이그레이션 웨이브를 설정하는 것이 포함됩니다.
    
- **종속성 분석:**
    서버 종속성을 식별하고 시각화해 마이그레이션의 최적 순서를 결정하고 다운타임을 최소화합니다.
    
- **비용 최적화:**
    상세한 리소스 활용 데이터를 사용해 AWS 리소스를 적정 크기로 조정하고 마이그레이션 비용을 정확하게 추정합니다.
    
- **성능 벤치마킹:**
    온프레미스 성능 기준선을 마이그레이션 후 지표와 비교해 마이그레이션의 성공을 검증합니다.
    
- **서드파티 도구와의 통합:**
    CMDB에서 데이터를 가져오거나 APN 파트너 솔루션을 활용해 마이그레이션 전략을 강화합니다.

## 5. 가격 정책

AWS Application Discovery Service 자체는 온프레미스 자산 검색에 대해 추가 요금을 부과하지 않습니다. 사용하는 기본 AWS 리소스(예: 데이터 저장을 위한 Amazon S3, 쿼리를 위한 Amazon Athena, 데이터 스트리밍을 위한 Amazon Kinesis Data Firehose)에 대해서만 비용을 지불합니다. 이 사용한 만큼 지불하는 가격 정책 모델은 최소 요금이나 선불 약정 없이 실제 사용량을 기반으로만 비용이 발생하도록 보장합니다.

## 6. AWS 생태계와의 통합

- **AWS Migration Hub:**
    마이그레이션 진행 상황을 통합하고 단일 콘솔에서 검색된 자산과 마이그레이션 활동을 추적할 수 있게 해줍니다.
    
- **AWS Database Migration Service(DMS):**
    검색 데이터를 사용해 데이터베이스 워크로드의 마이그레이션을 평가하고 계획하는 데 도움을 줍니다.
    
- **Amazon Athena와 QuickSight:**
    수집된 데이터의 심층 분석과 시각화를 용이하게 하여 더 정보에 입각한 마이그레이션 결정을 지원합니다.
    
- **서드파티 도구:**
    APN 파트너 솔루션은 공개 API를 통해 검색 데이터에 접근할 수 있어, 전문화된 도구를 마이그레이션 프로세스에 통합할 수 있습니다.

## 7. 결론

AWS Application Discovery Service는 AWS 클라우드로의 이전을 계획하는 모든 조직에게 필수적인 도구입니다. 상세한 구성, 성능, 종속성 데이터 수집을 자동화함으로써 더 전략적이고 데이터 기반의 마이그레이션 접근 방식을 가능하게 합니다. 에이전트리스 검색을 통한 신속하고 상위 수준의 통찰이 필요하든, 에이전트 기반 검색을 통한 더 깊은 프로세스 수준의 세부 사항이 필요하든, AWS ADS는 다른 AWS 마이그레이션 서비스와 원활하게 통합되면서 광범위한 마이그레이션 시나리오를 지원하는 유연성과 확장성을 제공합니다.
