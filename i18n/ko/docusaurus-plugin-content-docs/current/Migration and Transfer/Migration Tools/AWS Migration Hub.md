# AWS Migration Hub

## 1. 소개

AWS Migration Hub는 AWS 클라우드로의 여정을 간소화하고 단순화하도록 설계된 중앙화된 서비스입니다. 온프레미스 서버, 데이터베이스, 애플리케이션의 마이그레이션을 검색, 계획, 실행, 추적하기 위한 단일 통합 창구 역할을 합니다. 아래는 핵심 측면에 대한 포괄적인 개요입니다.

## 2. 개요와 목적

- **중앙화된 마이그레이션 관리:**
    AWS Migration Hub는 사용하는 마이그레이션 도구와 관계없이 여러 AWS 리전과 계정에 걸쳐 마이그레이션 프로젝트의 진행 상황을 모니터링할 수 있는 하나의 위치를 제공합니다. 검색부터 전환, 마이그레이션 후 검증까지 전체 마이그레이션 라이프사이클을 관리하는 데 도움을 줍니다.
    
- **통합된 도구 모음:**
    AWS Application Migration Service, AWS Server Migration Service, AWS Database Migration Service 같은 네이티브 AWS 서비스와 파트너 도구를 통합합니다. 이 통합은 각 도구의 상태 업데이트가 통합된 대시보드에 나타나도록 보장합니다.
    
- **검색과 평가:**
    마이그레이션을 시작하기도 전에 AWS Migration Hub는 에이전트나 에이전트리스 수집기를 사용해 온프레미스 자산을 검색할 수 있게 해줍니다. 이 데이터는 서버를 애플리케이션으로 그룹화하고, 종속성을 식별하고, (EC2 인스턴스 권장 사항 같은) 크기 조정과 구성에 대한 권장 사항을 생성하는 데 사용됩니다.

## 3. 핵심 기능

- **중앙화된 대시보드:**
    한 곳에서 모든 애플리케이션과 자산의 마이그레이션 상태를 확인합니다. 대시보드는 다양한 마이그레이션 도구의 데이터를 집계하고 상세한 상태 지표를 표시해, 실시간으로 진행 상황을 추적하고 문제를 해결하는 데 도움을 줍니다.
    
- **애플리케이션 검색과 그룹화:**
    AWS Discovery Agent 같은 검색 도구를 사용해 성능 지표와 네트워크 종속성을 포함한 서버에 대한 상세한 정보를 수집하고, 더 효과적인 계획을 위해 논리적으로 애플리케이션으로 그룹화할 수 있습니다.
    
- **마이그레이션 추적:**
    리소스를 AWS로 옮기면서 AWS Migration Hub는 주요 단계("복제 시작", "복제 완료", "AMI 생성" 등)를 추적해 진행 상황을 계속 알려줍니다. 이 추적은 재호스팅과 리플랫폼 마이그레이션 모두에 적용됩니다.
    
- **EC2 인스턴스 권장 사항:**
    수집된 성능 데이터(CPU, 메모리 등)를 분석해 서비스는 워크로드를 실행하기 위한 가장 비용 효율적인 EC2 인스턴스 유형을 권장해, 정보에 입각한 적정 크기 조정 결정을 내릴 수 있게 합니다.
    
- **전략 권장 사항과 현대화:**
    단순한 마이그레이션 추적을 넘어 Hub는 애플리케이션을 재호스팅, 리플랫폼, 또는 리팩토링할지 결정하는 데 도움이 되는 안내와 템플릿을 제공합니다. 예를 들어 Refactor Spaces 기능은 레거시 애플리케이션을 현대화하면서 위험을 최소화하는, 마이크로서비스로의 점진적인 리팩토링을 지원합니다.
    
- **오케스트레이션:**
    AWS Migration Hub Orchestrator는 사전 정의된 템플릿을 사용해 마이그레이션 워크플로를 자동화하며, 이는 수동 단계를 줄이고 태스크와 도구 간 종속성이 효율적으로 관리되도록 보장합니다. 이 오케스트레이션은 전체 마이그레이션 프로세스를 가속화합니다.

## 4. 작동 방식

다음 다이어그램은 AWS Migration Hub로 평가부터 마이그레이션까지 클라우드 여정을 관리하는 방법을 보여줍니다.

![AWS Migration Hub](@site/docs/Migration%20and%20Transfer/_assets/aws_migration_hub.png)

첫 워크로드를 마이그레이션하는 데 필요한 세 가지 단계는 다음과 같습니다.

1. AWS Application Discovery Service를 사용해 워크로드 환경을 검색하고, 성능 데이터와 네트워크 연결 세부 사항을 수집합니다. 이 데이터는 Migration Hub로 전송됩니다.
2. Migration Hub를 사용해 수집된 데이터를 분석하고, 종속성을 식별하고 태그를 지정하고, 서버를 애플리케이션으로 그룹화하고, 공유 및 전용 Amazon Elastic Compute Cloud(Amazon EC2) 환경에 대한 권장 사항을 생성합니다.
3. AWS Application Migration Service를 사용해 온프레미스 서버를 복제하고 AWS Database Migration Service(AWS DMS)를 사용해 데이터베이스 데이터를 복제해 워크로드를 AWS로 이동시킵니다. Migration Hub를 사용해 전체 마이그레이션의 진행 상황을 추적할 수 있습니다.

## 5. 사용 사례와 이점

- **포괄적인 가시성:**
    모든 온프레미스 자산과 그 마이그레이션 상태를 포함해 전체 애플리케이션 포트폴리오에 대한 전체적인 뷰를 하나의 통합된 인터페이스에서 확인합니다.
    
- **간소화된 마이그레이션 프로세스:**
    AWS Migration Hub를 사용함으로써 여러 마이그레이션 도구와 수동 프로세스를 관리하는 복잡함을 줄여 마이그레이션 일정을 가속화합니다.
    
- **비용 효율성:**
    AWS Migration Hub는 검색과 추적에 무료로 사용할 수 있습니다. 마이그레이션 중 프로비저닝된 기본 마이그레이션 서비스와 AWS 리소스에 대해서만 비용이 발생합니다.
    
- **향상된 협업:**
    중앙화된 추적 시스템을 통해 조직 내 서로 다른 팀이 효과적으로 협업할 수 있어, 마이그레이션 태스크와 책임이 명확하게 보이고 관리되도록 보장합니다.

## 6. 결론

AWS Migration Hub는 마이그레이션 여정의 모든 단계를 중앙화하는 강력한 서비스입니다. 단일 인터페이스에서 검색, 평가, 실행, 마이그레이션 후 현대화를 결합함으로써 클라우드 마이그레이션의 복잡함을 최소화하면서도 전체 프로세스에 걸쳐 투명성과 효율성을 극대화합니다.

AWS로의 마이그레이션을 계획하고 있거나 진행 중인 마이그레이션을 관리하는 더 간소화된 방법이 필요하다면, AWS Migration Hub는 클라우드로의 성공적인 전환을 보장하는 데 필요한 도구, 안내, 통합을 제공합니다.
