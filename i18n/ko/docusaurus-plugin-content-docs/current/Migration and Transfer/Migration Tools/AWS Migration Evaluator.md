# AWS Migration Evaluator

## 1. 소개

워크로드를 클라우드로 마이그레이션하는 것은 온프레미스 환경에 대한 정량화할 수 있는 통찰을 확보하는 것에 달려 있습니다. AWS Migration Evaluator는 조직이 서버 구성, 사용 패턴, 종속성을 포함한 현재 인프라의 상세한 기준선을 파악해 AWS로의 이전을 위한 설득력 있고 데이터 기반의 비즈니스 사례를 구축하도록 돕기 위해 설계되었습니다. 이 접근 방식은 비용 최적화와 성능 개선을 지원할 뿐만 아니라 성공적인 마이그레이션을 위한 대상 아키텍처 설계도 안내합니다.

## 2. AWS Migration Evaluator 개요

AWS Migration Evaluator는 온프레미스 하드웨어, 소프트웨어, 활용 지표에 대한 상세한 정보를 수집하는 클라우드 기반 서비스입니다. 그런 다음 고급 분석과 머신 러닝을 활용해 다음을 포함한 실행 가능한 통찰을 생성합니다.

- **중앙화된 인벤토리:** 현재 온프레미스 발자국의 통합된 뷰.
- **사용량과 종속성 분석:** 리소스 활용, 서버 간 상호 종속성, 성능 추세에 대한 통찰.
- **비용 모델링:** 다양한 AWS 가격 정책 모델(예: 온디맨드, 예약 인스턴스, Savings Plan)과 비교한 온프레미스 운영의 상세한 비용 추정치와 적정 크기 조정에 대한 권장 사항.
- **최적화된 마이그레이션 계획:** 위험을 완화하고 비용을 줄이면서 워크로드를 효율적으로 마이그레이션하기 위한 실행 가능한 단계와 로드맵.

이러한 결과는 조직이 여러 마이그레이션 시나리오를 모델링하고 AWS로 이전하는 것의 경제성을 예측할 수 있게 해줍니다.

### 2.1. 핵심 이점

- **신속한 의사 결정:**
    현재 환경을 신속하게 평가하고 계획과 의사 결정을 가속화하는 데이터 기반의 뷰를 확보합니다.
    
- **비용 최적화:**
    과도하게 프로비저닝된 리소스를 식별하고 (예: BYOL vs. LI 옵션) 온프레미스 운영과 AWS 서비스의 비용을 비교해 지출을 최적화합니다.
    
- **향상된 가시성:**
    마이그레이션 위험을 완화하기 위해 인프라의 사용 패턴과 종속성에 대한 상세한 이해를 얻습니다.
    
- **개선된 성능:**
    워크로드를 적정 크기로 조정하고 AWS 클라우드에서 성능을 최적화하기 위한 권장 사항을 받습니다.
    
- **포괄적인 보고:**
    상세하고 시각적인 보고서가 견고한 마이그레이션 전략과 비즈니스 사례 개발을 지원합니다.

### 2.2. 사용 사례

- **마이그레이션 계획:**
    초기 검색부터 상세한 마이그레이션 계획까지 어느 단계에서든 서비스를 사용해 현재 인프라와 그 종속성을 이해합니다.
    
- **비즈니스 사례 개발:**
    명확한 비용 모델과 성능 통찰로 마이그레이션에 대한 재무적, 운영적 정당성을 구축합니다.
    
- **리소스 최적화:**
    리소스를 적정 크기로 조정하고 낭비를 제거할 기회를 식별해 비용과 운영 오버헤드를 모두 줄입니다.
    
- **위험 완화:**
    잠재적인 병목 현상과 호환성 문제를 조기에 식별해 실제 마이그레이션 프로세스 중 위험을 줄입니다.

## 3. 기준선 데이터 수집하기

AWS Migration Evaluator의 핵심 측면은 현재 환경의 정확한 실시간 스냅샷을 제공하는 능력입니다. 이 기준선 데이터를 수집하는 두 가지 주요 방법이 있습니다.

### 3.1. Agentless Collector

Agentless Collector는 모든 서버에 소프트웨어 에이전트를 설치할 필요 없이 광범위한 검색을 제공합니다. (종종 가상 어플라이언스로) 배포되면 다음과 같은 텔레메트리를 주기적으로 수집합니다.

- 서버 구성(OS, CPU, 메모리)
- 소프트웨어 인벤토리
- 리소스 활용과 성능 지표
- 네트워크 종속성

이 방법은 인프라의 거의 실시간에 가까운 스냅샷을 제공해 평가가 현재 사용 패턴을 반영하도록 보장합니다.

### 3.2. 데이터 가져오기 기능

이미 인벤토리나 활용 데이터를 유지 관리하고 있는 조직(예: CMDB나 IT 자산 관리 시스템을 통해)의 경우 AWS Migration Evaluator는 데이터 가져오기 기능을 지원합니다. 특별히 형식화된 템플릿을 사용해 분석을 위한 리소스 지표(CPU 사용량과 스토리지 용량 등)의 스냅샷을 업로드할 수 있습니다. 이 대안은 이미 다른 도구에서 포괄적인 검색 데이터를 가지고 있는 경우 특히 유용합니다.

## 4. 작동 방식

AWS Migration Evaluator는 세 가지 주요 단계로 작동합니다.

1. **검색(Discover):**
    - Agentless Collector를 사용하거나 가져온 CSV 파일을 처리해 온프레미스 환경에서 상세한 데이터를 자동으로 수집합니다.
    - 하드웨어, 소프트웨어, 성능 지표, 서버 종속성에 대한 정보를 수집합니다.
2. **평가(Assess):**
    - 내장된 규칙, 모범 사례, 머신 러닝 알고리즘을 사용해 수집된 데이터를 분석합니다.
    - 잠재적인 마이그레이션 문제(예: 성능 병목 현상이나 라이선싱 과제)를 식별하면서 각 자산의 AWS 서비스와의 호환성을 평가합니다.
    - 현재 온프레미스 지출과 예상 AWS 비용을 비교하는 비용 추정치를 생성합니다.
3. **보고(Report):**
    - 시각화, 비용 예측, 실행 가능한 권장 사항이 완비된 상세한 보고서를 생성합니다.
    - 어떤 워크로드가 마이그레이션에 가장 적합한지, AWS에서 어떻게 최적화할지 결정하는 데 도움을 줍니다.

## 5. 마이그레이션 계획 분석 및 개발하기

AWS Migration Evaluator가 기준선 데이터를 컴파일하면 다음을 통해 명확한 로드맵을 제공합니다.

- **종속성 식별:** 서버와 애플리케이션 간 관계를 정확히 짚어내 마이그레이션 위험을 더 잘 이해합니다.
- **성능 추세 정의:** 최고 사용 기간과 필수 리소스 구성을 강조합니다.
- **적정 크기 조정 권장 사항:** 워크로드의 요구에 맞춘 적절한 AWS 서비스 옵션을 제안합니다.
- **비용 비교:** 온프레미스 비용을 다양한 AWS 가격 정책 시나리오와 대조하는 상세한 모델을 생성합니다.
- **로드맵 작성:** 최적화된 전환을 위한 일정, 권장 서비스, 마이그레이션 단계를 개괄합니다.

이 체계적인 접근 방식은 추측을 없애 AWS 마이그레이션을 위한 견고한 비즈니스 사례를 구축할 수 있게 해줍니다.

## 6. 비용 통찰과 AWS 안내 활용하기

AWS Migration Evaluator의 두드러진 기능 중 하나는 워크로드를 AWS 가격 정책 모델에 맞춤으로써 잠재적인 비용 절감을 정확히 짚어내는 능력입니다. 상세한 비용 예측은 즉각적인 마이그레이션 비용을 이해하는 데 도움이 될 뿐만 아니라 장기적인 비용 효율성을 계획하는 데도 도움이 됩니다. 또한 조직은 특히 대규모나 복잡한 환경을 다룰 때 마이그레이션 전략을 개선하기 위해 AWS 전문가로부터 추가적인 안내를 구할 수 있습니다.

## 7. 통합과 기술적 세부 사항

- **Collector 설치와 구성:**
    더 깊은 통찰이 필요한 환경의 경우 AWS는 VMware, Hyper-V, SQL Server 등을 위한 시스템 요구 사항과 연결성을 다루는 포괄적인 설치 가이드와 함께 전용 Migration Evaluator Collector(Windows 서비스와 IIS 애플리케이션)를 제공합니다.
    
- **AWS Migration Hub와 MAP:**
    AWS Migration Evaluator는 전체 마이그레이션 여정에 걸쳐 진행 상황을 추적하기 위해 AWS Migration Hub와 원활하게 통합됩니다. 또한 클라우드 마이그레이션을 가속화하기 위해 체계적인 3단계 접근 방식(평가, 동원, 마이그레이션 및 현대화)을 따르는 AWS Migration Acceleration Program(MAP)의 핵심 도구이기도 합니다.

## 8. 결론

AWS Migration Evaluator는 현재 환경에 대한 사실적이고 데이터 기반의 기준선을 제공함으로써 온프레미스 분석과 클라우드로 향하는 미래 사이의 격차를 해소합니다. Agentless Collector를 사용하든 기존 데이터를 가져오든, 이 도구는 리소스 사용량, 서버 종속성, 비용 영향에 대한 깊은 통찰을 제공합니다. 이러한 통찰은 최적화된 AWS 서비스 권장 사항과 비용 모델로 명확한 마이그레이션 로드맵을 개발할 수 있게 해주어 — 추측을 없애고 자신감을 가지고 클라우드로의 여정을 가속화합니다.
