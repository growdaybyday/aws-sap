## AWS DataSync

## 1. 소개

AWS DataSync는 온프레미스 시스템, 서드파티 클라우드, Amazon S3·Amazon EFS·Amazon FSx 같은 AWS 서비스 간에 대량의 데이터를 전송하는 간소화된 솔루션을 제공합니다. 중요한 파일 메타데이터(권한, 소유권, 타임스탬프)를 보존하고 데이터 무결성을 보장하는 에이전트 기반 아키텍처를 사용해 성능, 보안, 스케줄링 요구를 해결합니다.

주요 목적은 다음을 포함합니다.

- **데이터 마이그레이션:** (NFS, SMB, HDFS 같은 프로토콜을 사용해) 온프레미스 시스템에서 활성 데이터셋을 AWS 스토리지로 효율적으로 이동합니다.
- **데이터 복제와 아카이빙:** 비즈니스 연속성을 위한 주기적 복제, 콜드 데이터를 비용 효율적인 스토리지 클래스(예: S3 Glacier)로 아카이빙, 견고한 데이터 레이크 구축을 가능하게 합니다.
- **하이브리드 클라우드 워크플로:** 규정 준수와 보안 설정을 유지하면서 AWS와 온프레미스 환경 간 동기화를 지원합니다.

AWS DataSync는 현대적인 데이터 전송 워크플로를 설계하고 유지 관리하는 데 필수적인 역할을 하기 때문에 프로페셔널 클라우드 자격증 시나리오에서 널리 인정받고 테스트됩니다.

## 2. 핵심 기능

AWS DataSync는 여러 엔터프라이즈급 기능을 제공합니다.

- **높은 처리량:**
    각 DataSync 에이전트는 최대 10Gbps의 고속 복제가 가능해, 대용량 데이터셋에서도 신속한 전송을 보장합니다.
    
- **예약된 전송:**
    지속적인 복제를 제공하는 대신 DataSync는 예약된 배치 지향 전송(시간별, 일별, 주별)을 위해 설계되었습니다. 이는 백업 윈도우와 주기적인 동기화에 이상적입니다.
    
- **메타데이터 보존:**
    DataSync는 파일 권한, 소유권, 타임스탬프, (NFS의 경우 POSIX, SMB의 경우 NTFS 모두의) 보안 컨텍스트를 포함한 중요한 파일 메타데이터를 보존하며, 이는 규정 준수를 유지하고 마이그레이션 후 원활한 운영을 보장하는 데 필수적입니다.
    
- **유연한 스토리지 대상:**
    모든 Amazon S3 스토리지 클래스, Amazon EFS, Amazon FSx 변형을 포함한 다양한 스토리지 시스템과의 전송을 지원합니다.
    
- **대역폭 제한:**
    대용량 데이터 전송이 네트워크를 포화시키고 프로덕션 워크로드에 영향을 미치지 않도록 대역폭 한도를 구성할 수 있습니다.
    
- **에이전트 기반과 에이전트리스 옵션:**
    (NFS, SMB, HDFS를 통해) 비 AWS 환경에서 데이터를 전송할 때는 온프레미스나 퍼블릭 클라우드에 DataSync 에이전트를 배포합니다. AWS 스토리지 서비스 간의 전송만 하는 경우에는 네이티브 통합이 사용되어 에이전트가 필요 없습니다.
    

추가 기능으로는 내장된 데이터 무결성 검사, (TLS를 통한) 전송 중 암호화, 향상된 보안을 위한 (AWS PrivateLink를 사용하는) VPC 엔드포인트 지원이 있습니다.

## 3. 사용 사례와 시나리오

AWS DataSync는 다재다능하며 여러 일반적인 시나리오를 지원합니다.

1. **온프레미스 데이터를 AWS로 마이그레이션:**
    기업들은 로컬 파일 공유나 레거시 시스템을 AWS로 이동하는 데 DataSync를 사용합니다 — S3의 아카이빙 목적이든 Amazon EFS나 FSx를 사용한 운영 목적이든.
    
2. **AWS 스토리지 서비스 간 데이터 전송:**
    DataSync는 (예를 들어 S3에서 FSx로, 또는 EFS에서 S3로) AWS 서비스 전반에서 데이터를 복제하거나 동기화하면서 프로세스 중 메타데이터를 보존할 수 있습니다.
    
3. **하이브리드 환경에서의 양방향 동기화:**
    조직은 온프레미스 시스템에서 AWS로, 또는 그 반대로 변경 사항을 주기적으로 동기화해 클라우드 기반 처리와 함께 로컬 운영을 지원할 수 있습니다.
    
4. **아카이빙과 백업:**
    예약된 전송은 콜드 데이터를 비용 효율적인 스토리지 클래스로 정기적으로 백업하거나 아카이빙할 수 있게 해주어 온프레미스 스토리지 제약을 완화합니다.
    
5. **휴대용 장치와의 통합:**
    연결이 제한적이거나 원격인 환경의 경우, (사전 설치된 DataSync 에이전트를 포함하는) AWS Snowcone 장치는 오프라인 데이터 수집과 연결이 복구된 후의 동기화를 가능하게 합니다.

## 4. 스케줄링, 성능, 운영 고려 사항

- **스케줄링:**
    DataSync 작업은 지속적으로 실행되는 서비스가 아니라 예약된 작업으로 구성됩니다. 이 유연성은 백업 윈도우나 기업 정책에 맞는 전송 빈도를 선택할 수 있게 해줍니다.
    
- **증분 전송:**
    각 예약된 실행은 소스와 대상 모두를 스캔해 새로운 데이터나 변경된 데이터만 전송합니다. 이는 네트워크 사용을 최소화하고 전송 속도를 높입니다.
    
- **성능:**
    단일 DataSync 에이전트는 전체 10Gbps 링크를 활용할 수 있어 대규모 마이그레이션에 매우 적합합니다. 사용자는 중요한 네트워크 리소스가 과도하게 사용되지 않도록 대역폭을 제한하는 옵션도 가지고 있습니다.
    
- **운영상의 특성:**
    예약된 특성상 DataSync는 주기적인 동기화로 충분한 환경에 이상적입니다. 지속적이고 실시간인 복제를 위한 것이 아니라 배치 전송과 주기적인 백업에서 뛰어납니다.

## 5. 보안과 규정 준수

AWS DataSync는 전송 프로세스 전반에서 데이터가 보호되도록 보장합니다.

- **암호화와 무결성:**
    모든 데이터는 TLS를 사용해 전송 중 암호화됩니다. 또한 DataSync는 (체크섬과 메타데이터 비교를 사용해) 종단 간 무결성 검증을 수행해 전송된 데이터가 소스와 정확히 일치하는지 확인합니다.
    
- **메타데이터 보존:**
    권한, 소유권, 타임스탬프를 포함한 중요한 파일 메타데이터가 전송 중 보존됩니다. 이는 규정 준수 요구 사항이 있거나 감사 가능성이 중요한 워크로드에 필수적입니다.
    
- **보안 네트워크 옵션:**
    AWS PrivateLink를 통해 VPC 엔드포인트를 사용하도록 DataSync를 구성할 수 있어, 데이터가 퍼블릭 인터넷을 거치지 않고 안전한 AWS 네트워크 내에 머물도록 보장합니다.
    
- **규정 준수:**
    DataSync는 PCI DSS, HIPAA, FedRAMP Moderate/High, ISO 표준, SOC 보고서를 포함한 주요 규제 표준을 충족합니다.

## 6. 에이전트 배포와 사용

- **온프레미스 통합:**
    (NFS, SMB, HDFS 같은 프로토콜을 사용해) 온프레미스 소스에서 데이터를 전송할 때는 로컬 하이퍼바이저(예: VMware, KVM, Hyper-V)에 DataSync 에이전트를 배포해야 합니다. 에이전트는 전송 중 암호화와 메타데이터 보존을 처리합니다.
    
- **AWS 간 전송:**
    (예를 들어 S3에서 EFS로) AWS 스토리지 서비스 간 전송의 경우 DataSync가 AWS 내에서 네이티브로 통합되므로 온프레미스 에이전트가 필요하지 않습니다.
    
- **휴대용 장치와의 통합:**
    연결이 제한적인 환경에서는 사전 설치된 DataSync 에이전트를 갖춘 AWS Snowcone 장치를 사용해 로컬에서 데이터를 수집하고, 장치를 배송하고, 이후 AWS 스토리지와 그 콘텐츠를 동기화할 수 있습니다.

## 7. 가격 정책과 비용 고려 사항

AWS DataSync는 사용한 만큼 지불하는 가격 정책 모델을 따릅니다.

- **데이터 전송 요금:**
    전송된 데이터 양을 기반으로 비용을 지불하며, 리전 간 전송에는 추가 요금이 부과됩니다.
- **선불 비용이나 라이선스 요금 없음:**
    완전관리형이므로 DataSync는 커스텀 데이터 전송 솔루션 구축과 관련된 자본 지출과 운영 오버헤드를 없애줍니다.

이 모델은 전통적인 마이그레이션 도구에 비해 총 소유 비용을 상당히 줄일 수 있습니다.
## 8. 결론

데이터 레이크를 구축하든, 레거시 시스템을 클라우드로 마이그레이션하든, 비즈니스 연속성을 위해 데이터를 복제하든, 규정 준수가 중요한 백업을 수행하든, AWS DataSync는 현대적인 데이터 전송 워크플로를 위한 견고하고, 안전하고, 효율적인 솔루션을 제공합니다.
