# AWS Snow Family

## 1. 소개

AWS Snow Family는 네트워크 연결이 제한적이거나 사용할 수 없을 때에도 온프레미스 환경과 AWS 클라우드 간에 대량의 데이터를 전송, 마이그레이션, 처리하는 것을 단순화하고 보호하도록 설계된 물리적 장치 모음입니다. 데이터가 생성되는 바로 그 위치에서 컴퓨팅 워크로드를 실행할 수 있도록 엣지 컴퓨팅도 염두에 두고 만들어졌습니다.

## 2. AWS Snow Family 개요

![AWS Snow Family](@site/docs/Migration%20and%20Transfer/_assets/aws_snow_family.png)

Snow Family는 각각 다른 규모와 시나리오에 맞춰진 세 가지 주요 제품으로 구성됩니다.

- **AWS Snowcone:**
    엣지 컴퓨팅, 로컬 데이터 수집, 원격지나 열악한 환경에서의 처리에 완벽한 작고, 견고하고, 휴대 가능한 장치입니다. 백팩에 넣고 다닐 수 있을 만큼 가벼우며 일반적으로 약 8TB의 사용 가능한 스토리지와 적당한 컴퓨팅 기능을 갖추고 있고, HDD와 SSD 버전으로 제공됩니다.
    
- **AWS Snowball:**
    두 가지 변형으로 제공되는 중간 크기의 어플라이언스입니다 — **스토리지 최적화**(일반적으로 최대 80TB의 HDD 스토리지와 블록 볼륨을 위한 추가 SSD 제공)와 **컴퓨팅 최적화**(더 낮은 스토리지 용량으로 더 컴퓨팅 집약적인 워크로드를 지향). Snowball 장치는 테라바이트에서 페타바이트 규모의 데이터를 신속하게 이동하는 데 사용되며, 로컬 처리가 필요한 엣지 애플리케이션을 실행하는 데도 사용됩니다.
    
- **AWS Snowmobile:**
    가장 방대한 데이터 마이그레이션을 위해 Snowmobile은 본질적으로 트럭에 실린 45피트 길이의 화물 컨테이너입니다. 전체 데이터 센터에서 AWS로 엑사바이트 규모의 데이터(트럭당 최대 100PB)를 전송하도록 설계되어, 거대한 데이터셋을 가진 조직에게 이상적입니다.

## 3. 핵심 기능과 이점

- **안전하고 견고한 설계:**
    모든 Snow Family 장치는 열악한 조건을 견디도록 만들어졌으며 변조 방지 인클로저를 갖추고 있습니다. 전송 중과 저장 중인 데이터를 보호하기 위해 256비트 AES 암호화, Trusted Platform Module(TPM), 안전한 삭제 프로토콜 같은 견고한 보안 조치를 사용합니다.
    
- **엣지 컴퓨팅 기능:**
    Snowcone와 Snowball Edge 같은 장치는 로컬 컴퓨팅 워크로드를 지원합니다. AWS IoT Greengrass 함수나 EC2 인스턴스 같은 애플리케이션을 장치에서 직접 실행할 수 있어, 연결이 끊긴 시나리오에서도 실시간 데이터 처리가 가능합니다.
    
- **효율적인 데이터 전송:**
    데이터 마이그레이션을 위한 오프라인 방법을 제공합니다. 장치에 데이터를 로드한 후 AWS로 다시 배송하면 데이터가 Amazon S3 같은 서비스로 수집됩니다. 이 접근 방식은 매우 큰 데이터셋에 대한 느리거나 신뢰할 수 없는 네트워크 전송의 제약을 피할 수 있게 해줍니다.
    
- **유연한 서비스 모델:**
    프로젝트 규모와 요구 사항에 따라 다음 중에서 선택할 수 있습니다.
    - **Snowcone:** 소규모, 휴대 가능, 원격 운영에 가장 적합합니다.
    - **Snowball:** 대규모 마이그레이션과 추가 컴퓨팅 파워가 필요한 워크로드에 이상적입니다.
    - **Snowmobile:** 대규모, 데이터 센터 수준의 마이그레이션에 적합합니다.

## 4. 사용 사례

- **클라우드 마이그레이션:**
    고속 인터넷에 의존하지 않고 (백업, 아카이브, 또는 전체 데이터 센터로부터) 대용량 데이터셋을 AWS 클라우드로 이동합니다.
    
- **재해 복구:**
    비즈니스 연속성을 보장하기 위해 격리된 환경에서 중요한 데이터를 신속하게 복제하고 엣지 애플리케이션을 실행합니다.
    
- **엣지 데이터 처리:**
    클라우드로 전송하기 전에 데이터를 로컬에서 처리하기 위해 산업 현장, 유전, 군사 작전 같은 원격지에 컴퓨팅 리소스를 배포합니다.
    
- **콘텐츠 배포와 미디어:**
    네트워크 상태가 시기적절한 업로드를 방해할 수 있는 곳에서 고해상도 미디어 파일을 수집하고 처리합니다.

## 5. 작동 방식

1. **주문과 설정:**
    AWS Management Console에서 작업을 생성하고 필요에 맞는 적절한 장치를 선택하는 것으로 시작합니다. AWS는 장치를 여러분의 위치로 배송합니다.
    
2. **로컬 데이터 로딩:**
    장치를 받으면 로컬 네트워크에 연결합니다. AWS OpsHub나 다른 제공된 도구를 사용해 데이터를 장치로 전송합니다.
    
3. **AWS로 데이터 전송:**
    데이터가 로드된 후 장치를 AWS로 다시 배송합니다. 도착하면 AWS는 지정된 스토리지 서비스(예: S3)로 데이터를 수집하고 향후 재사용을 위해 장치를 안전하게 삭제합니다.
    
4. **엣지 운영(해당하는 경우):**
    엣지 워크로드의 경우 장치는 로컬에서 컴퓨팅 태스크를 실행할 수 있으며, 연결이 가능해지면 나중에 결과를 클라우드와 동기화합니다.

## 6. 결론

AWS Snow Family는 대규모 데이터 마이그레이션과 엣지 컴퓨팅 워크로드를 관리해야 하는 조직을 위한 다재다능한 솔루션을 제공합니다. 원격지 데이터 수집을 다루든, 전체 데이터 센터를 마이그레이션하든, 연결이 제한된 곳에서 컴퓨팅 워크로드를 실행하든, 이러한 요구를 충족하도록 설계된 Snow 장치가 있습니다. 보안, 견고한 설계, AWS 생태계와의 원활한 통합에 초점을 맞춘 Snow Family는 현대적인 데이터 중심 기업을 위한 필수적인 도구가 되었습니다.

이러한 장치를 활용함으로써 기업은 대역폭이 많이 필요한 인터넷 전송에 대한 의존을 줄이고, 마이그레이션 프로세스를 가속화하고, 견고한 보안 표준을 유지하면서 엣지에서의 운영 능력을 강화할 수 있습니다.
