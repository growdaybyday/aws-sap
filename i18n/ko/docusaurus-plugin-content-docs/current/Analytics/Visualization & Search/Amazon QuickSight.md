# Amazon QuickSight

## 1. 소개
Amazon QuickSight는 조직이 고도로 확장 가능하고 서버리스인 방식으로 데이터에서 통찰을 얻을 수 있게 해주는 완전관리형이고 시각적으로 풍부한 분석 솔루션입니다. 강력한 인메모리 기능과 수많은 데이터 소스와의 원활한 통합을 활용함으로써, QuickSight는 대화형 대시보드와 분석 보고서를 만드는 것을 간단하게 만들어줍니다.

## 2. 핵심 기능과 역량

![quicksight](@site/docs/Analytics/_assets/quicksight.png)

* **서버리스와 머신 러닝 기반:**
	**QuickSight는 완전관리형**이므로 기본 인프라를 프로비저닝하거나 유지 관리할 필요가 없습니다. 서버리스 특성은 데이터셋의 크기와 복잡성에 따라 자동으로 용량을 확장할 수 있게 해줍니다. 또한 QuickSight는 데이터 뒤에 있는 추세, 이상값, 핵심 동인을 식별하기 위해 머신 러닝 기반 통찰을 사용합니다.
	
* **대화형 대시보드:**
	QuickSight의 핵심 이점은 시각적으로 매력적인 대시보드를 만드는 능력입니다. 이 대시보드는 최종 사용자가 의미 있는 정보를 신속하게 파악할 수 있게 해주는 차트, 테이블, KPI, 다른 시각적 요소를 포함할 수 있습니다. 대시보드는 웹사이트나 애플리케이션에 임베드될 수도 있어, 외부 이해관계자에게 분석을 전달하기 쉽게 만들어줍니다.

* **SPICE 엔진:**
	QuickSight의 SPICE(Super-fast, Parallel, In-memory Calculation Engine)는 고속 데이터 분석을 위해 설계되었습니다. 데이터가 QuickSight로 직접 가져와지면 SPICE는 대규모로 인메모리 계산을 수행할 수 있어, 반응성 있는 보고와 고급 계산을 가능하게 합니다. QuickSight가 원격 소스에 단순히 연결하는 경우에는 이 인메모리 엔진이 적용되지 않습니다 — SPICE의 성능 이점을 얻으려면 데이터셋을 가져와야 합니다.

## 3. 아키텍처와 통합

QuickSight는 광범위한 네이티브 AWS 서비스와 서드파티 제공자와 통합됩니다.

- **AWS 데이터베이스:** RDS, Aurora, Redshift, Athena, Timestream, 또는 S3에 직접 연결합니다.
- **서드파티 소스:** Salesforce와 Jira 같은 SaaS 플랫폼이나 JDBC를 통한 온프레미스 데이터베이스에서 데이터에 접근합니다.
- **파일 가져오기:** SPICE로 인메모리 성능을 활용하기 위해 Excel, CSV, JSON, 또는 TSV 형식의 파일을 수집합니다.

## 4. 사용자, 그룹, 대시보드, 분석

QuickSight는 AWS Identity and Access Management(IAM) 사용자와는 별개인 자체 내부 사용자 관리 시스템을 유지합니다. IAM 자격 증명이 관리 작업에 사용될 수 있지만, 대시보드를 소비하거나 분석에서 협업하는 최종 사용자는 QuickSight 내에서 정의됩니다.

- **사용자와 그룹:**
  – Standard 에디션은 개별 사용자를 지원합니다.
  – Enterprise 에디션은 더 세밀한 접근 제어를 위한 그룹도 제공합니다.

- **분석과 대시보드:**
  – "분석"은 데이터 탐색을 수행하고, 시각화를 구축하고, 필터나 파라미터를 구성하는 곳입니다.
  – "대시보드"는 분석의 읽기 전용, 공유 가능한 버전입니다. 대시보드를 게시하면 서로 다른 사용자 전반에서 데이터의 일관된 뷰를 보장합니다.
## 5. 결론

Amazon QuickSight는 AWS의 클라우드 인프라와 고급 머신 러닝 기능을 활용하는 견고하고, 확장 가능하고, 안전한 BI 서비스로 두드러집니다. 실시간 대시보드로 비즈니스에 힘을 실어주고 싶든, 심층적인 데이터 분석을 수행하고 싶든, 애플리케이션에 대화형 분석을 임베드하고 싶든, QuickSight는 보안, 성능, 혁신에 대한 AWS의 헌신으로부터 이점을 누리면서 원시 데이터를 실행 가능한 통찰로 변환하는 데 필요한 도구와 통합을 제공합니다.
