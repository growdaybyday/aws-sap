# AWS Lake Formation

## 1. 소개

AWS Lake Formation은 데이터 레이크를 관리하고 구축하기 위한 **완전관리형 서비스**입니다. 데이터 수집, 정리, 전송, 카탈로그화 같은 복잡하고 수동적인 작업 상당수를 자동화한 다음 그 데이터를 분석과 머신 러닝을 위해 안전하게 전달함으로써 **데이터 레이크의 생성, 보안, 관리**를 단순화합니다.

Lake Formation의 핵심 측면은 AWS IAM 권한 모델과 협력해 작동하는 **세밀한 권한 모델**입니다. 관계형 데이터베이스 관리 시스템(RDBMS)을 연상시키는 이 중앙 집중식으로 확립된 권한 아키텍처는 간단한 명령으로 접근을 부여하거나 취소할 수 있게 해줍니다. 권한은 열, 행, 셀 수준에서 적용되어, 올바른 사용자와 애플리케이션만 민감한 데이터에 접근할 수 있도록 보장합니다.

## 2. Lake Formation 개요
### 2.1. 데이터 레이크란 무엇이며 왜 필요한가

**데이터 레이크**는 정형과 비정형, 원시 데이터와 변환된 데이터 모두를 어떤 규모로든 저장하는 중앙화된 저장소입니다. 혼란스러워 보일 수 있지만 잘 설계된 데이터 레이크는:

- 관련 없는 데이터를 걸러내면서 가치 있는 정보를 보존합니다.
- 기업 성장을 이끄는 테스트, 분석, 통찰을 위한 환경을 제공합니다.
- 의사 결정과 고객 만족도를 향상시키기 위해 (고객 구매 이력과 소셜 미디어 입력 같은) 서로 다른 데이터 소스의 병합을 가능하게 합니다.

데이터 레이크는 단일 진실 공급원과 고급 분석 및 머신 러닝을 위한 견고한 기반을 제공함으로써 팀에 권한을 부여합니다.

### 2.2. 핵심 개념과 구성 요소

이 섹션은 AWS Lake Formation에 고유한 기본 구성 요소를 다룹니다.

* **데이터 레이크:**
	- **정의:** 정형과 비정형, 원시와 변환된 데이터를 저장하는 Amazon S3의 영구 저장소.
	- **등록:** Amazon S3 위치를 등록하면 S3 경로와 그 아래의 모든 폴더가 포함됩니다.

- **Data Catalog:**
	- **목적:** 데이터 소스, 변환, 대상을 추적하는 영구적인 메타데이터 저장소 역할을 합니다.
	- **구조:** 메타데이터를 데이터베이스(테이블 모음)와 테이블(데이터에 대한 설명 정보)로 유지 관리합니다.
	- **접근 제어:** 카탈로그의 데이터베이스와 테이블에 권한을 적용할 수 있습니다. 각 AWS 계정은 AWS 리전당 하나의 Data Catalog를 가집니다.

* **거버넌스 테이블(Governed Tables):**
	- **기능:** Lake Formation에 고유한 거버넌스 테이블은 다음을 지원합니다.
	    - ACID 트랜잭션
	    - 자동 데이터 압축
	    - 타임 트래블 쿼리
	    - 외부 계정의 공유 데이터베이스와 테이블에 대한 리소스 링크
	- **사용:** 주로 데이터 레이크의 데이터에 대한 크로스 계정 접근에 사용됩니다.

* **블루프린트:**
	- **정의:** 데이터 레이크로의 데이터 수집을 간소화하는 데이터 관리 템플릿.
	- **구성:** 데이터 소스, 데이터 대상, 일정 같은 입력을 지정할 수 있게 합니다.
	- **유형:** 데이터베이스 스냅샷, 증분 데이터베이스, 로그 파일 블루프린트 등이 있습니다.

* **워크플로:**
	- **정의:** 데이터 가져오기의 데이터 소스와 일정을 정의하는 AWS Glue 작업, 크롤러, 트리거 모음을 위한 컨테이너.
	- **오케스트레이션:** AWS Glue 방향성 비순환 그래프(DAG)를 사용해 데이터 로딩과 업데이트를 오케스트레이션하고 모니터링합니다.
	- **실행:** 워크플로는 온디맨드로 또는 사전 정의된 일정에 따라 실행될 수 있습니다.

### 2.3. 핵심 기능과 특징

AWS Lake Formation은 그렇지 않으면 상당한 수동 작업이 필요할 태스크를 간소화합니다.

1. **데이터 가져오기와 수집:**
    - 연결 세부 사항과 자격 증명을 사용해 기존 데이터베이스에서 데이터를 스캔하고 가져옵니다.
    - 대량 데이터 로드와 증분 업데이트를 모두 지원합니다.

2. **메타데이터 관리:**
    - 데이터 소스에서 기술적 메타데이터를 추출해 데이터를 구성하고 레이블을 지정합니다.
    - AWS Glue Data Catalog를 중앙화된 메타데이터 저장소로 사용합니다.

3. **데이터 변환:**
    - 구성 가능한 변환 템플릿을 통해 (날짜 형식 표준화 같은) 변환을 자동화합니다.

4. **암호화와 데이터 보호:**
    - Amazon S3 암호화를 사용해 데이터 레이크를 자동으로 암호화합니다.
    - AWS KMS를 사용한 복호화를 지원하고 전송 중인 데이터를 보호합니다.

5. **접근 제어와 감사 로깅:**
    - 데이터베이스, 테이블, 열, 행, 셀에 걸친 정책으로 접근 관리를 중앙화합니다.
    - 데이터 접근과 변경 사항을 추적하기 위한 견고한 감사 로깅(CloudTrail을 통해)을 제공합니다.

6. **셀프 서비스 데이터 접근과 검색:**
    - 사용자가 중앙화된 데이터 카탈로그를 통해 데이터셋을 탐색하고 검색할 수 있게 하여 생산성을 향상시킵니다.

7. **규제 테이블과 ACID 트랜잭션:**
    - ACID 트랜잭션, 자동 데이터 압축, 타임 트래블 쿼리, 크로스 계정 공유를 위한 리소스 링크를 제공하는 Lake Formation에 고유한 거버넌스 테이블을 지원합니다.

## 3. AWS Lake Formation 작동 방식

![Lake-formation-Components](@site/docs/Analytics/_assets/lake-formation-components.png)

AWS Lake Formation은 **안전하고, 중앙화되고, 큐레이팅된 데이터 레이크**의 생성을 극적으로 단순화합니다. 프로세스는 다음을 포함합니다.

1. **데이터 수집과 온보딩:**
    - **데이터 식별과 수집:** (Amazon S3, 관계형 데이터베이스, 또는 NoSQL 데이터베이스 같은) 기존 데이터 저장소를 찾아 새 데이터 레이크로 데이터를 이동시킵니다.
    - **정리와 변환:** 데이터가 수집되면서 머신 러닝 알고리즘을 사용해 데이터를 정리하고 분류합니다.
    - **카탈로그화:** 자동으로 크롤링하고 메타데이터를 추출해 AWS Glue Data Catalog를 채워, 데이터 자산을 검색할 수 있도록 보장합니다.

2. **접근과 보안 정책 정의:**
    - **정책 설정:** 관리자는 어떤 사용자나 서비스가 특정 데이터셋에 접근할 수 있는지 제어하는 보안 정책을 정의합니다.
    - **세밀한 제어:** 데이터베이스, 테이블, 열, 행, 심지어 셀 수준까지 권한을 설정합니다.

3. **쿼리 실행과 안전한 데이터 전달:**
    - **자격 증명 발급:** 분석 쿼리가 (Amazon Athena, Redshift Spectrum, EMR 등을 통해) 제출되면 Lake Formation은 권한을 검증하고 임시 자격 증명을 발급합니다.
    - **데이터 접근:** 쿼리 엔진은 필요에 따라 필터가 적용된 상태로 Amazon S3 데이터 레이크에서 허용된 데이터만 직접 검색합니다.

4. **감사와 규정 준수:**
    - 모든 작업은 AWS CloudTrail을 통해 로깅되어 포괄적인 감사 가능성과 규정 준수 표준 준수를 보장합니다.

## 4. 세밀한 권한과 보안

![Lake-formation-Fine-Grained Permissions](@site/docs/Analytics/_assets/lake-formation-fine-grained_permissions.png)

Lake Formation의 보안 모델은 핵심적인 차별화 요소입니다.

- **RDBMS와 유사한 권한:** 간단한 부여 또는 취소 작업을 가능하게 하는 관계형 데이터베이스의 접근 제어를 모방합니다.
- **세밀한 시행:** 민감한 데이터를 보호하는 데 이상적인 열, 행, 셀 수준에서 권한을 적용합니다.
- **하이브리드 접근 모드:** 기존 IAM 정책을 계속 사용하면서 Lake Formation 권한을 점진적으로 채택할 수 있게 해주어 원활한 전환을 보장합니다.
- **분석과 ML 서비스와의 통합:** 세밀한 제어는 Amazon Athena, Redshift Spectrum, EMR 같은 서비스 전반에서 시행됩니다.
- **자격 증명 발급과 쿼리 API:** 자격 증명 발급 API를 사용해 유효한 권한을 기반으로 등록된 S3 위치에 접근하기 위한 임시 자격 증명을 발급합니다. 쿼리 API는 이러한 권한을 기반으로 S3에서 반환되는 데이터를 필터링합니다.
- **역할과 신뢰:** 서비스 연결 역할은 여러분을 대신해 AWS 서비스를 호출하는 데 필요한 권한을 제공합니다. 추가 권한이 필요하면 사용자 정의 역할을 사용할 수 있습니다.
- **태그 기반 접근 제어:** Lake Formation은 대량의 데이터 카탈로그 리소스를 관리하기 위한 태그 기반 접근 제어를 지원합니다.
- **API와 로깅:** AWS CloudTrail은 모든 Lake Formation API 호출을 캡처해 모든 접근이나 변경이 감사 목적으로 로깅되도록 보장합니다.

## 5. 가격 정책

많은 고급 보안 및 거버넌스 기능이 추가 비용 없이 제공되지만, AWS Lake Formation 가격 정책에는 여러 구성 요소가 포함됩니다.

- **트랜잭션 요청과 메타데이터 저장:** 트랜잭션 요청과 메타데이터 저장에 대해 요금이 청구됩니다.
- **데이터 필터링:** 데이터 필터링 작업이나 Storage API가 스캔한 바이트 수에 대해 요금이 부과됩니다.
- **스토리지 옵티마이저:** 스토리지 옵티마이저가 처리한 바이트 수를 기반으로 요금이 청구됩니다.
- **기본 서비스 비용:** Amazon S3, AWS Glue, (Athena나 EMR 같은) 통합 서비스에 대한 요금은 계속 적용됩니다.

## 6. 결론

AWS Lake Formation은 데이터 레이크의 전체 라이프사이클 — 수집과 카탈로깅부터 데이터 보안과 공유까지 — 을 간소화합니다. 고급 세밀한 권한 모델, AWS 분석 서비스와의 견고한 통합, Data Catalog, 거버넌스 테이블, 블루프린트, 워크플로 같은 핵심 구성 요소를 통해 조직은 안전하고, 확장 가능하고, 고도로 거버넌스가 적용된 데이터 레이크를 쉽게 구축할 수 있습니다.

많은 수동 작업을 자동화하고 포괄적인 감사 가능성과 보안을 보장함으로써 AWS Lake Formation은 엄격한 규정 준수와 거버넌스 표준을 유지하면서 기업이 데이터의 전체 가치를 활용할 수 있게 해줍니다.
