# AWS Data Exchange

## 1. 소개

AWS Data Exchange는 AWS 고객이 클라우드에서 서드파티 데이터를 쉽게 **공유, 구독, 관리**할 수 있게 해주는 완전관리형 서비스입니다. 고가치 데이터셋을 발견하고, 일관된 가격 정책 옵션으로 구독하고, AWS 분석과 머신 러닝 서비스와 데이터를 통합하는 프로세스를 간소화합니다. 본질적으로 데이터 소비자가 다양한 데이터 자산에 접근할 수 있고, 데이터 제공자가 자체적인 전달 및 자격 인프라를 구축하고 유지할 필요 없이 데이터 제품을 게시할 수 있는 중앙화된 마켓플레이스 역할을 합니다.
## 2. 핵심 개념

![data-exchange](@site/docs/Analytics/_assets/data-exchange.png)
### 2.1. 데이터 그랜트

**데이터 그랜트**는 AWS Data Exchange에서 교환의 기본 단위입니다. 데이터 발신자가 데이터 수신자에게 큐레이팅된 데이터셋에 대한 접근을 부여하기 위해 생성합니다. 각 그랜트는 다음을 포함합니다.

- **데이터셋:** 그랜트를 수락한 후 수신자가 접근하는 데이터 자산(파일, API, Redshift 데이터셋, S3 객체, 또는 Lake Formation 관리 데이터가 될 수 있음)의 모음.
- **데이터 그랜트 세부 사항:** 수신자에게 보이는 (이름과 설명 같은) 설명 정보.
- **수신자 접근 세부 사항:** 데이터에 얼마나 오래 접근할 수 있는지 지정하는 (수신자의 AWS 계정 ID와 접근 기간 같은) 정보.
### 2.2. AWS Marketplace의 데이터 제품

**데이터 제품**은 AWS Marketplace에 게시되는 교환의 단위입니다. 다음과 함께 하나 이상의 데이터셋을 패키징합니다.

- **제품 세부 사항:** 이름, 짧고 긴 설명, 로고, 샘플 데이터, 지원 연락처 정보 등.
- **제품 오퍼:** 가격 정책, 구독 기간(1개월에서 36개월), (데이터 구독 계약을 포함한) 조건, 환불 정책을 정의합니다. AWS의 지침과 약관에 따라 검토되고 승인되면 이 제품들은 단일한 전역 카탈로그에서 사용할 수 있게 됩니다.
### 2.3. 지원되는 데이터셋 유형

AWS Data Exchange는 다섯 가지 유형의 데이터셋을 지원합니다.

- **파일:** 전통적인 파일 기반 데이터(예: CSV, Parquet).
- **API:** REST API를 통해 전달되는 데이터.
- **Amazon Redshift:** Redshift 데이터 웨어하우스에서 직접 쿼리할 수 있는 데이터셋.
- **Amazon S3:** S3 버킷에 저장된 데이터 파일.
- **AWS Lake Formation(프리뷰):** Lake Formation을 통해 관리되는 세밀한 권한을 가진 데이터.
## 3. 핵심 기능

### 3.1. 데이터 찾기와 구독하기

![data-exchange-2](@site/docs/Analytics/_assets/data-exchange-2.png)
AWS Data Exchange를 사용하면 독립 소프트웨어 벤더, 데이터 게시자, 애그리게이터로부터 수천 개의 데이터 제품을 포함하는 중앙화된 카탈로그를 탐색할 수 있습니다. 데이터셋을 구독한 후에는 프로그래밍 방식으로 또는 수동으로 검색해 Amazon S3에 저장할 수 있습니다. 이는 Amazon SageMaker, AWS Glue, 또는 Amazon Athena 같은 AWS 서비스를 통한 추가 처리를 위해 데이터를 즉시 사용할 수 있게 만듭니다.

### 3.2. 다양한 데이터 제공자
주요 데이터 제공자 중 일부는 다음을 포함합니다.
- **Reuters**, 매년 여러 언어로 220만 개 이상의 고유한 뉴스 기사에서 데이터를 큐레이팅합니다.
- **Change Healthcare**, 연간 140억 건 이상의 헬스케어 거래와 1조 달러의 청구를 처리합니다.
- **Dun & Bradstreet**, 3억 3천만 개 이상의 전 세계 비즈니스 레코드를 유지 관리합니다.
- **Foursquare**, 전 세계 2억 2천만 명 이상의 고유 고객과 6천만 개의 장소에 대한 데이터를 축적합니다.

AWS Data Exchange를 통해 이러한 데이터셋에 접근함으로써 고객은 연구, 분석, 머신 러닝을 위한 전문화되고 고가치인 정보에 신속하게 접근할 수 있습니다.
## 4. 추가 기능

### 4.1. Amazon Redshift를 위한 Data Exchange

일부 시나리오에서는 분석 워크로드를 위해 Amazon Redshift에 데이터를 저장하는 것이 더 효율적일 수 있습니다. Amazon Redshift를 위한 AWS Data Exchange는 서드파티 데이터를 Amazon Redshift 데이터 웨어하우스로 직접 로드할 수 있게 합니다. 이 기능은 Redshift의 표준 SQL 인터페이스를 사용해 외부 데이터에 대한 쿼리를 단순화합니다. 반대로 조직은 AWS Data Exchange를 통해 자체 Redshift 기반 데이터 제품을 게시하고 라이선싱해 독점 데이터셋을 수익화할 수도 있습니다.
### 4.2. API를 위한 Data Exchange

정적 파일을 넘어 AWS Data Exchange는 서드파티 API 구독도 지원합니다. 소비자는 AWS 네이티브 인증 방법을 사용해 API를 호출해, 향상된 거버넌스, 일관된 자격 증명 관리, 기존 AWS 워크플로와의 원활한 통합을 보장합니다. 이는 거의 실시간에 가까운 데이터 소비 가능성을 확장해, 애플리케이션과 백엔드 서비스에 외부 데이터 포인트를 통합하기 쉽게 만듭니다.
## 5. 예시 사용 사례

내부 판매 데이터를 Foursquare의 위치 인텔리전스와 결합해 마케팅 분석을 확장하고 싶은 시나리오를 생각해보세요. AWS Data Exchange를 통해 Foursquare의 데이터셋을 구독하고, Amazon S3로 내보내고, Amazon Redshift Spectrum을 구성해 내부 판매 지표와 외부 Foursquare 파일에 대한 페더레이션 분석을 수행합니다. 마지막으로 이 결과를 Amazon SageMaker를 사용하는 ML 워크플로에 공급해 예측 통찰을 생성합니다 — 예를 들어 가장 유망한 고객 참여를 가진 지역을 식별하는 것입니다.

## 6. 결론

AWS Data Exchange는 저널리즘 피드, 헬스케어 거래, 비즈니스 레코드, 사용자 위치 데이터 등 가치 있는 서드파티 데이터셋에 대한 접근을 간소화합니다. Amazon S3, Amazon Redshift, 다양한 분석과 ML 도구 같은 핵심 AWS 서비스와의 긴밀한 통합은 데이터 기능을 확장하려는 조직에게 강력한 솔루션이 되게 합니다. 안전하고 확장 가능한 서드파티 데이터 구독과 공유를 위해 AWS Data Exchange를 활용함으로써 기업은 통찰을 향상시키고, 의사 결정을 가속화하고, 데이터 기반 워크로드 전반에서 혁신을 추진할 수 있습니다.

데이터 그랜트와 마켓플레이스 통합부터 지원되는 데이터 유형과 접근 제어까지 각 측면에 대한 자세한 내용은 공식 AWS 문서를 참고하세요.
