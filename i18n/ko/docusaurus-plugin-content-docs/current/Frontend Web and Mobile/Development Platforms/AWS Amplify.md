# AWS Amplify
## 1. 소개

핵심적으로 **AWS Amplify**는 AWS에서 현대적인 웹과 모바일 애플리케이션을 구축, 배포, 호스팅하기 위한 원스톱 솔루션입니다. 다음을 제공합니다.

- **Amplify Studio** – 프론트엔드 UI와 백엔드 서비스를 모두 구축하기 위한 시각적 인터페이스.
- **Amplify CLI** – 앱을 위한 AWS 서비스 구성을 안내하는 명령줄 도구.
- **Amplify Libraries** – AWS 서비스(예: Amazon Cognito, S3, AppSync)를 프론트엔드나 모바일 코드에 통합하기 위한 사전 구축된 라이브러리.
- **Amplify Hosting** – 내장된 지속적 통합과 지속적 전달(CI/CD)을 갖춘 완전관리형 호스팅 서비스.

Amplify를 개념화하는 쉬운 방법은 모바일과 웹 앱을 위해 특별히 맞춤화된 "Elastic Beanstalk"으로 생각하는 것입니다. AWS 서비스를 프로비저닝하고 관리하는 복잡함 대부분을 추상화해, 저수준 구성을 알아내는 것이 아니라 기능 구축에 집중할 수 있게 해줍니다.

## 2. AWS Amplify의 핵심 구성 요소

### 2.1. Amplify Studio

![amplify-studio](@site/docs/Frontend%20Web%20and%20Mobile/_assets/amplify-studio.png)
**Amplify Studio**는 애플리케이션의 프론트엔드 UI와 백엔드를 모두 설계하는 데 도움이 되는 시각적 개발 환경을 제공합니다. 다음을 포함합니다.

- **드래그 앤 드롭 UI 빌딩**: React나 다른 프론트엔드 프레임워크를 시각적으로 구성합니다.
- **데이터 모델링**: 데이터와 관계를 그래픽으로 모델링하며, 이는 Amazon DynamoDB와 AWS AppSync 같은 서비스에 프로비저닝됩니다.
- **Amplify Libraries와의 통합**: 데이터 모델과 인증을 설정하면 필요한 프론트엔드 코드가 자동으로 생성될 수 있습니다.

Amplify Studio는 일반적인 설정 작업에 로우코드나 노코드 접근 방식을 찾는 팀에게 특히 유용해, 애플리케이션 스캐폴딩 프로세스를 가속화합니다.

### 2.2. Amplify CLI

![amplify-cli](@site/docs/Frontend%20Web%20and%20Mobile/_assets/amplify-cli.png)

터미널로 작업하는 것을 선호하는 개발자를 위해 **Amplify CLI**는 앱을 위한 AWS 리소스를 생성하고 관리하는 안내된 접근 방식을 제공합니다. CLI를 설치한 후 다음으로 새 프로젝트를 초기화할 수 있습니다.

```
amplify init
```

거기서부터 백엔드 기능 추가는 간단합니다.

- **인증**: `amplify add auth`(Amazon Cognito를 구성)
- **API / DataStore**: `amplify add api`(GraphQL API와 자동 데이터 동기화를 위해 Amazon AppSync와 DynamoDB를 활용)
- **호스팅**: `amplify add hosting`(앱을 배포하기 위해 AWS Amplify Hosting을 설정)

그러면 Amplify CLI가 AWS 계정에 리소스를 프로비저닝하고, 구성 파일을 업데이트하고, 이 서비스들을 프론트엔드 애플리케이션에 통합하는 데 필요한 코드를 생성하는 것을 처리합니다.

### 2.3. Amplify Libraries

**Amplify Libraries**는 프론트엔드를 AWS 서비스와 통합하는 오픈소스 클라이언트 라이브러리 모음을 포함합니다. 다음을 위한 즉시 사용 가능한 UI 구성 요소와 추상화를 제공합니다.

- **사용자 인증**(Amazon Cognito)
- **안전한 파일 저장**(Amazon S3)
- **실시간 GraphQL API**(AWS AppSync)
- **분석, 푸시 알림 등**

이 라이브러리들은 **React.js, Vue.js, JavaScript, iOS, Android, Flutter**를 포함한 인기 있는 프레임워크와 언어를 지원해, 애플리케이션 요구에 맞는 스택을 선택할 수 있게 해줍니다.

### 2.4. Amplify Hosting

![aplify-hosting](@site/docs/Frontend%20Web%20and%20Mobile/_assets/aplify-hosting.png)
**Amplify Hosting**은 현대적인 웹 앱을 위한 AWS의 완전관리형 CI/CD와 호스팅 플랫폼입니다. 핵심 기능은 다음을 포함합니다.

- **자동화된 빌드**: Git 저장소(예: GitHub, GitLab, Bitbucket, 또는 AWS CodeCommit)에 코드를 푸시할 때마다 Amplify가 자동으로 프론트엔드를 빌드할 수 있습니다.
- **지속적 배포**: (종종 Amazon CloudFront로 뒷받침되는) 전 세계적으로 사용 가능한 콘텐츠 전송 네트워크로 변경 사항을 배포합니다.
- **풀 리퀘스트 미리보기**: 변경 사항을 병합하기 전에 테스트와 피드백을 위한 임시적이고 공유 가능한 애플리케이션 미리보기를 생성합니다.
- **커스텀 도메인과 HTTPS**: 도메인 관리를 단순화하고 SSL 인증서를 자동으로 프로비저닝합니다.
- **모니터링과 로깅**: 애플리케이션 성능, 사용량, 오류에 대한 통찰을 얻습니다.
- **리디렉션, 커스텀 헤더, 비밀번호 보호**: 고급 호스팅 요구 사항을 위한 추가 구성을 구현합니다.

Amplify Hosting은 Netlify나 Vercel 같은 플랫폼에 대한 AWS 네이티브 대안으로 볼 수 있으며, 코드부터 프로덕션 배포까지의 간소화된 경로를 제공합니다.

## 3. 핵심 기능

Amplify는 현대적인 애플리케이션의 가장 일반적인 요구를 다루도록 설계되었습니다.

1. **인증**
    - **가입, 로그인, 비밀번호 복구, 다중 인증(MFA)**을 위해 Amazon Cognito를 활용합니다.
    - 사용자 흐름에 필요한 커스텀 코드를 줄여주는 **사전 구축된 UI 구성 요소**를 제공합니다.
    - 백엔드의 보호된 리소스에 대한 **세밀한 권한 부여**를 지원합니다.

2. **데이터 저장(DataStore)**
    - 애플리케이션의 데이터베이스를 위해 **AWS AppSync**(관리형 GraphQL 서비스)와 **Amazon DynamoDB**를 활용합니다.
    - 클라우드로 **자동 동기화**되는 로컬 데이터로 작업할 수 있게 해주어, **오프라인**과 **실시간** 기능을 가능하게 합니다.
    - 데이터 모델링을 단순화하고 Amplify Studio의 시각적 도구와 원활하게 통합됩니다.

3. **머신 러닝**
    - Amplify 생태계 내에 머물면서 Amazon Rekognition이나 Amazon Comprehend 같은 AWS 서비스로 구동되는 AI/ML 기능(예: 예측, 번역, 이미지 인식)을 추가하는 옵션을 제공합니다.

내부적으로 AWS 모범 사례를 통합함으로써 Amplify는 애플리케이션이 **확장 가능**하고, **안전**하고, **고가용성**이도록 보장합니다.

## 4. AWS Amplify를 사용한 엔드투엔드 테스트

테스트는 모든 현대적인 CI/CD 파이프라인의 중요한 측면이며, Amplify는 견고한 테스트 옵션을 제공합니다.

1. **단위 테스트**
    - 빌드 단계에서 실행되어 작은 코드 단위가 예상대로 동작하는지 검증합니다.
    - 일반적인 라이브러리와 프레임워크(예: Jest, Mocha)를 통합할 수 있습니다.

2. **엔드투엔드(E2E) 테스트**
    - 애플리케이션이 임시 또는 프로덕션 환경에 배포된 후 실행됩니다.
    - 코드 병합이나 최종 프로덕션 릴리스 전에 회귀나 통합 문제를 식별하는 데 도움을 줍니다.
    - **Cypress**는 Amplify가 지원하는 인기 있는 프레임워크로, 브라우저와 유사한 환경 내에서 버튼 클릭과 양식 제출 같은 사용자 작업을 시뮬레이션할 수 있게 해줍니다.
    - `amplify.yml` 파일에서 이 테스트 단계를 정의해 CI/CD 파이프라인의 **테스트** 단계에서 Amplify가 자동으로 실행하도록 지시할 수 있습니다.

빌드 수준 테스트(단위 테스트)와 (Cypress를 통한) E2E 테스트를 결합함으로써 최종 사용자에게 새 기능이나 업데이트를 배포하기 전에 높은 수준의 품질과 신뢰도를 보장할 수 있습니다.

## 5. 결론

AWS Amplify는 AWS에서 풀 스택 애플리케이션을 생성, 배포, 관리하는 프로세스를 극적으로 단순화합니다. 시각적 개발 환경(Amplify Studio)과 강력한 CLI를 모두 제공함으로써, 광범위한 개발자 선호와 요구를 다룹니다. 내장된 인증, 데이터베이스 통합, 호스팅, 테스트를 통해 Amplify는 보안, 확장성, 성능에 대한 모범 사례를 희생하지 않으면서 더 빠른 개발 주기의 길을 열어줍니다.

첫 제품을 프로토타이핑하는 스타트업이든 개발 워크플로를 간소화하려는 대규모 조직이든, AWS Amplify는 현대적인 애플리케이션 스택의 초석이 될 수 있습니다. Amplify를 계속 탐구하면서 이것이 단순한 서비스 모음이 아니라 팀이 인프라가 아닌 혁신에 집중할 수 있게 해주는 엔드투엔드 플랫폼이라는 것을 발견하게 될 것입니다.

더 포괄적인 세부 사항은 [공식 문서](https://aws.amazon.com/amplify/?nc=sn&loc=0)를 참고하세요.
