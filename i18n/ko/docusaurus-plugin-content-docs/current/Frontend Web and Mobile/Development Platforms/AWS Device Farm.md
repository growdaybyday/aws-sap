# AWS Device Farm

## 1. 소개

AWS Device Farm은 다양한 실제 장치에서 모바일과 웹 애플리케이션을 테스트하는 간소화된 방법을 제공합니다. 실제 최종 사용자 환경을 반영하는 하드웨어에서 테스트를 실행함으로써 개발자와 QA 팀은 장치별 문제를 더 신뢰성 있게 식별할 수 있습니다. 자동화된 테스트 프레임워크, 견고한 로깅, 원격 디버깅을 통해 AWS Device Farm은 앱이 가장 광범위한 브라우저와 장치 집합에서 원활하게 실행되도록 보장하는 데 도움을 줍니다.

## 2. 핵심 기능

### 2.1. 실제 테스트를 위한 실제 장치

에뮬레이터에만 의존하는 대신 AWS Device Farm은 물리적 장치에서 앱을 테스트합니다. 이 접근 방식은 미묘한 하드웨어와 OS 버전 차이가 고려되도록 보장해, 앱이 릴리스된 후 예기치 않은 동작의 위험을 줄여줍니다.

- 다양한 모델과 OS 버전을 포함해 인기 있는 Android와 iOS 장치를 다룹니다.
- 반응형 웹 앱의 엔드투엔드 테스트를 위한 실제 웹 브라우저도 포함합니다.
### 2.2. 자동화된 테스트 실행

AWS Device Farm은 여러 자동화 프레임워크와 통합됩니다. 테스트를 한 번 작성하고, 업로드하고, 지정된 풀의 각 장치에서 이 스크립트들이 실행되게 할 수 있습니다. 이 자동화는 회귀 테스트를 가속화하고 팀이 새 기능에 집중할 수 있는 시간을 확보해줍니다.

- 호환되는 프레임워크는 XCTest, Espresso, Appium 등을 포함합니다.
- 병렬 실행 지원을 통해 여러 장치에서 동시에 테스트할 수 있습니다.
### 2.3. 심층적인 보고와 디버깅

오류가 발생하면 AWS Device Farm은 진행 중인 테스트의 스크린샷, 로그, 심지어 비디오까지 자동으로 캡처합니다. 이 자료들은 근본 원인을 신속하게 짚어내는 데 도움을 줍니다. 더 깊은 검사를 위해 장치에 원격으로 로그인해 실시간 디버깅을 수행할 수도 있습니다.

- 실패 보고서를 자동으로 생성합니다.
- 더 깊은 분석을 위한 상세한 장치 로그에 접근합니다.
- 원격 접근을 사용해 문제를 실시간으로 격리하고 수정합니다.
## 3. 일반적인 워크플로

1. 테스트 스크립트와 애플리케이션 패키지를 업로드합니다.
2. (특정 장치 집합과 OS 유형을 포함한) 장치 풀을 정의합니다.
3. 이 장치들에서 자동화된 테스트 실행을 트리거합니다.
4. 실행 결과의 로그, 비디오, 스크린샷을 수집하고 검토합니다.
5. 문제가 발견되면 실패를 재생하거나 더 깊은 디버깅을 위해 해당 장치에 원격으로 연결합니다.

## 4. 실용적인 예시

모바일 뱅킹 앱의 새 버전을 게시한다고 상상해보세요. 릴리스하기 전에 다양한 인기 모델에서의 동작을 검증하고 싶습니다.

- Device Farm은 Nexus 6나 LG G Flex 2 같은 특정 Android 장치가 예기치 않은 UI 레이아웃 문제를 겪는다는 것을 짚어낼 수 있습니다.
- 특정 삼성 갤럭시 모델 같은 다른 장치에서는 테스트가 성공해, 앱이 최소한 그 장치들에서는 작동한다는 것을 확인합니다.

자동으로 생성된 로그와 비디오 녹화를 통해 오류가 정확히 어떻게 나타나는지 볼 수 있어, 신속한 수정과 재테스트가 가능해집니다.

## 5. 결론

AWS Device Farm은 다양한 실제 장치, 자동화된 테스트 통합, 철저한 보고를 제공함으로써 모바일과 웹 애플리케이션 테스트의 마찰을 줄여줍니다. 이 서비스에 익숙해지면 팀이 개발 주기를 단축하고, 앱 신뢰성을 개선하고, 다양한 장치 전반에서 더 일관된 사용자 경험을 보장하는 데 도움이 될 수 있습니다.

더 포괄적인 세부 사항은 [공식 문서](https://aws.amazon.com/device-farm/)를 참고하세요.
