# EC2 Image Builder

## 1. 소개

**EC2 Image Builder**는 Amazon Machine Image(AMI)와 컨테이너 이미지를 포함해, 커스터마이징되고 안전하며 최신 상태인 서버 이미지를 만들고 유지 관리하고 검증하고 배포하는 과정을 자동화하는 완전관리형 AWS 서비스입니다. 자체 자동화 파이프라인을 구축할 필요 없이 최신 운영체제 패치와 소프트웨어 업데이트로 이미지를 최신 상태로 유지하는 데 도움이 됩니다.

## 2. 워크플로 개요

EC2 Image Builder는 본질적으로 다음과 같은 파이프라인을 사용합니다.

![ec2-image-builder](@site/docs/Compute/_assets/ec2-image-builder.png)

- **레시피 정의:**
	베이스 이미지와 구성 요소 목록을 지정하는 선언적 문서입니다. 구성 요소는 이미지를 커스터마이징하는 스크립트나 구성 단계입니다(예: 소프트웨어 패키지 설치, 보안 강화 적용, 테스트 실행).

- **빌드 환경 구성:**
	인프라 구성은 빌드 과정의 런타임 설정을 정의합니다. 여기에는 EC2 인스턴스 유형, 네트워크 설정(VPC, 서브넷, 보안 그룹), 로깅 대상, 임시 인스턴스를 시작하는 데 필요한 기타 설정이 포함됩니다.

- **이미지 빌드와 테스트:**
	파이프라인이 실행되면(수동 또는 예약에 따라) Image Builder는 임시 EC2 인스턴스를 시작합니다. 이 인스턴스는 정의된 베이스 이미지를 사용한 다음, 두 가지 주요 단계에서 레시피의 구성 요소를 순차적으로 적용합니다.
    - **빌드 단계:** 필요에 따라 이미지를 구성하도록 커스터마이징이 적용됩니다.
    - **테스트 단계:** 테스트 구성 요소가 지정되어 있다면 이미지가 검증됩니다(예: 서비스가 올바르게 시작되는지, 보안 설정이 강제되는지 확인).

- **최종 이미지 생성:**
	빌드와 테스트가 성공적으로 완료되면 Image Builder는 출력 이미지를 만듭니다. AMI의 경우 Amazon EBS 스냅샷을 만들고 새 AMI를 등록하는 과정을 포함하고, 컨테이너 이미지의 경우 Docker 컨테이너 이미지를 빌드하는 것으로 마무리됩니다.

- **이미지 배포:**
	배포 설정을 통해 최종 이미지를 다른 AWS 리전으로 복사하고 다른 AWS 계정과 공유할 수 있습니다. AMI의 경우 시작 권한도 설정할 수 있습니다(이미지를 프라이빗, 퍼블릭, 또는 선택한 계정과 공유하도록 설정).

- **임시 리소스 정리:**
	모든 임시 빌드 리소스(EC2 인스턴스, 임시 스냅샷이나 컨테이너 빌드 리소스)는 이미지가 성공적으로 만들어진 후 자동으로 삭제됩니다.

## 2. AMI(EC2) 파이프라인의 동작 방식

1. **파이프라인 생성:**
    - EC2 Image Builder 콘솔에서 "이미지 파이프라인 생성"을 선택합니다.
    - 첫 단계에서는 고유한 파이프라인 이름과 빌드 일정(원한다면 cron 표현식 사용) 같은 일반 세부 정보를 제공합니다. 기반 이미지나 구성 요소가 변경되었을 때만 새 빌드가 트리거되도록, 의존성 업데이트를 확인하는 방식으로 일정을 구성할 수 있습니다.

2. **이미지 레시피 선택:**
    - 기존 레시피를 사용할지 새로 만들지 선택합니다.
    - 이미지 레시피는 베이스 AMI를 정의하고 적용할 빌드·테스트 구성 요소를 나열합니다. 예를 들어 빌드 구성 요소는 애플리케이션 소프트웨어를 설치할 수 있고, 테스트 구성 요소는 보안 설정(방화벽 규칙 등)이 갖춰져 있는지 확인할 수 있습니다.

3. **인프라 구성:**
    - 선택 사항이지만, 임시 EC2 인스턴스의 파라미터(인스턴스 유형, IAM 역할, VPC/서브넷 세부 정보, 로깅 설정 등)를 설정하는 인프라 구성을 지정할 수 있습니다.

4. **배포 설정 정의:**
    - 여기서 최종 AMI가 어떻게, 어디로 배포될지 구성할 수 있습니다. AMI를 여러 리전에 복사하고, 어떤 AWS 계정이 이를 사용할 수 있는지 제어하는 시작 권한을 설정하는 것이 포함될 수 있습니다.

5. **검토와 파이프라인 실행:**
    - 구성을 검토한 후 파이프라인을 시작합니다.
    - Image Builder는 임시 빌드 인스턴스를 만들고, 레시피(빌드 구성 요소)를 적용한 다음, 테스트를 실행합니다. 성공하면 새 AMI와 연관된 EBS 스냅샷을 만듭니다.

6. **빌드 후 작업:**
    - 새로 만들어진 AMI는 지정된 배포 구성에 따라 배포됩니다.
    - 모든 임시 리소스가 정리되고, 원하는 구성과 보안 설정을 준수하는 프로덕션 준비 이미지가 남습니다.

## 3. 컨테이너 파이프라인의 동작 방식

1. **컨테이너 파이프라인 생성:**
    - 콘솔에서 새 파이프라인을 만드는 것으로 유사하게 시작합니다. 이번에는 컨테이너 이미지용입니다.
    - AMI 파이프라인과 마찬가지로 이름과 일정 세부 정보를 제공합니다.

2. **컨테이너 레시피 선택:**
    - AMI 레시피 대신 컨테이너 레시피를 선택합니다. 이 문서는 베이스 컨테이너 이미지(퍼블릭 리포지토리, Amazon ECR, AWS Marketplace에서 가져올 수 있음)와 일련의 빌드 단계를 지정합니다.
    - 레시피에는 컨테이너 이미지를 커스터마이징하는 Dockerfile이나 커스텀 명령이 포함될 수 있습니다(예: 의존성 설치나 환경 변수 구성).

3. **인프라 설정:**
    - AMI 파이프라인과 유사하게, 빌드에 사용되는 임시 EC2 인스턴스의 설정을 결정하는 인프라 구성을 정의합니다.
    - 이 인스턴스는 컨테이너 빌드 과정을 실행하는 역할을 하므로 Docker에 접근할 수 있어야 합니다.

4. **빌드, 테스트, 푸시:**
    - 파이프라인이 실행되면 Image Builder는 컨테이너 레시피가 적용되는 임시 인스턴스를 시작합니다.
    - 베이스 컨테이너 이미지를 가져오고, 빌드 구성 요소가 실행되며(예: Dockerfile 명령 실행), 레시피에 구성된 테스트가 실행되어 컨테이너의 무결성과 기능을 검증합니다.
    - 컨테이너 이미지가 성공적으로 빌드되면 배포 구성에서 지정한 Amazon ECR 리포지토리로 푸시됩니다.

5. **정리:**
    - AMI 파이프라인과 마찬가지로, 과정이 완료된 후 모든 임시 리소스(빌드 인스턴스, 임시 컨테이너 등)가 정리됩니다.

## 4. 두 파이프라인의 공통 요소

- **자동화와 예약:**
    두 파이프라인 모두 일정(cron 표현식이나 EventBridge 규칙 사용)에 따라 실행되도록 구성할 수 있으며, 베이스 이미지나 구성 요소의 변경을 자동으로 감지해 필요한 경우에만 새 빌드를 트리거할 수 있습니다.

- **보안과 테스트:**
    선택적 테스트 구성 요소(Amazon Inspector와의 통합 포함)를 포함해, 이미지가 최종 확정되기 전에 취약점 스캔을 수행하고 커스터마이징이 보안 표준을 충족하는지 검증할 수 있습니다.

- **서비스 연결 역할과 IAM:**
    EC2 Image Builder는 서비스 연결 역할(AWSServiceRoleForImageBuilder)을 활용해 여러분을 대신해 안전하게 작업을 수행합니다. 또한 빌드와 테스트 작업을 허용하려면 IAM 역할과 정책(EC2InstanceProfileForImageBuilder 등)이 올바르게 구성되어 있어야 합니다.

- **AWS 생태계와의 통합:**
    원격 명령 실행과 향상된 메타데이터 수집을 위한 Systems Manager와의 통합 외에도, Image Builder는 로깅을 위한 CloudWatch, 알림을 위한 SNS, 컨테이너 저장을 위한 ECR, 계정 간 이미지 공유를 위한 AWS Organizations/Resource Access Manager(RAM) 같은 서비스와 함께 동작합니다.

## 5. 결론

EC2 Image Builder는 AWS에서 서버와 컨테이너 이미지를 빌드하고 관리하는 완전한 자동화 솔루션을 제공합니다. 이미지 레시피, 모듈식 구성 요소, 인프라 구성, 자동화된 파이프라인을 결합해 과정을 단순화합니다. 보안 테스트, 다중 리전 배포, 광범위한 AWS 서비스와의 통합을 기본적으로 지원해 현대적인 DevOps와 IT 운영을 위한 강력한 도구입니다.

더 자세한 정보는 공식 [EC2 Image Builder API 참조](https://docs.aws.amazon.com/imagebuilder/latest/APIReference/Welcome.html)와 [EC2 Image Builder 사용자 가이드](https://docs.aws.amazon.com/imagebuilder/latest/userguide/what-is-image-builder.html)를 참고하세요.
