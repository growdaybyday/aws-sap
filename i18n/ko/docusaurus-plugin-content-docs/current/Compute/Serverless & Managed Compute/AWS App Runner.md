# AWS App Runner

## 1. 소개

AWS App Runner는 소스 코드나 컨테이너 이미지로부터 확장성 있고 안전한 웹 애플리케이션을 AWS 클라우드에 빠르고 간단하며 비용 효율적으로 배포할 수 있게 하는 AWS 서비스입니다. 새로운 기술을 배우거나, 어떤 컴퓨팅 서비스를 사용할지 결정하거나, AWS 리소스를 프로비저닝하고 구성하는 방법을 알 필요가 없습니다.

![appruner-intor](@site/docs/Compute/_assets/appruner-intor.png)

App Runner는 코드나 이미지 리포지토리에 직접 연결됩니다. 완전관리형 운영, 높은 성능, 확장성, 보안을 갖춘 자동 통합·배포 파이프라인을 제공합니다.

## 2. 주요 기능

- **자동 확장:** App Runner는 들어오는 트래픽을 모니터링하고 수요에 맞춰 컨테이너 인스턴스 수를 조정하며, 트래픽이 적거나 없는 기간에는 프로비저닝된 인스턴스로 축소해 비용을 최적화합니다.

- **내장 보안과 컴플라이언스:** 이 서비스는 자동 HTTPS 암호화를 제공하고, 접근 제어를 위해 AWS Identity and Access Management(IAM)와 통합되며, VPC(Virtual Private Cloud) 통합을 지원해 다른 AWS 리소스와 안전하게 통신할 수 있게 합니다.

- **AWS 서비스와의 매끄러운 통합:** App Runner는 데이터베이스, 캐싱, 메시징 서비스 같은 다양한 AWS 서비스에 연결할 수 있어, 종합적인 애플리케이션 개발을 지원합니다.
## 3. 아키텍처

AWS App Runner는 리포지토리에서 소스 코드나 소스 이미지를 가져와 AWS 클라우드에서 실행되는 웹 서비스를 만들고 유지 관리합니다. 일반적으로 서비스를 만들려면 *CreateService* 작업 하나만 호출하면 됩니다.

소스 이미지 리포지토리를 사용하면 App Runner가 웹 서비스를 실행하기 위해 배포할 수 있는, 즉시 사용 가능한 컨테이너 이미지를 제공하는 것입니다. 소스 코드 리포지토리를 사용하면 코드와 웹 서비스를 빌드·실행하는 지침을 제공하고 특정 런타임 환경을 대상으로 지정합니다. App Runner는 여러 프로그래밍 플랫폼을 지원하며, 각 플랫폼의 주요 버전마다 하나 이상의 관리형 런타임을 제공합니다.

현재 App Runner는 Bitbucket이나 GitHub 리포지토리에서 소스 코드를 가져올 수 있고, AWS 계정의 Amazon ECR에서 소스 이미지를 가져올 수 있습니다.

다음 다이어그램은 App Runner 서비스 아키텍처의 개요를 보여줍니다. 다이어그램에는 두 가지 예시 서비스가 있습니다. 하나는 GitHub에서 소스 코드를 배포하고, 다른 하나는 Amazon ECR에서 소스 이미지를 배포합니다. Bitbucket 리포지토리에도 동일한 흐름이 적용됩니다.

![apprunner-arch](@site/docs/Compute/_assets/apprunner-arch.png)

## 4. App Runner용 애플리케이션 코드 개발

- **프레임워크 지원:** App Runner는 어떤 웹 애플리케이션 프레임워크나 언어와도 호환되며, 빌드 과정과 컨테이너 이미지 생성을 단순화하는 플랫폼별 관리형 런타임을 제공합니다.

- **웹 요청:** 이 서비스는 HTTP 1.0과 HTTP 1.1 프로토콜을 지원하며, HTTP 요청을 자동으로 HTTPS로 리디렉션합니다. App Runner가 TLS 종료를 관리하므로 수동 구성이 필요 없습니다. HTTP 요청에는 요청 읽기와 응답 쓰기를 모두 포함해 120초의 타임아웃이 있다는 점에 유의하세요.

- **스테이트리스 애플리케이션:** App Runner는 ***스테이트리스 애플리케이션을 위해 설계***되었으며, 개별 웹 요청 처리를 넘어서는 상태 유지를 보장하지 않습니다.

- **스토리지:** 각 컨테이너 인스턴스에는 3GB의 임시 스토리지가 포함되어 있으며, 이는 일시적이라 요청 간에 유지되지 않을 수 있습니다. 안정적인 캐싱을 위해서는 Amazon ElastiCache 같은 서비스와의 통합을 고려하세요.

- **환경 변수:** App Runner는 기본 `PORT` 환경 변수를 제공하며 커스텀 변수 추가도 지원합니다. 민감한 데이터는 AWS Secrets Manager나 AWS Systems Manager Parameter Store에서 안전하게 참조할 수 있습니다.

- **인스턴스 역할:** 애플리케이션이 다른 AWS 서비스와 상호작용할 수 있게 하려면, IAM 인스턴스 역할을 만들어 App Runner 서비스를 생성할 때 연결하세요.

## 5. 요금

AWS App Runner는 애플리케이션이 사용한 컴퓨팅과 메모리 리소스를 기준으로 요금이 부과되는 사용량 기반 요금 모델을 제공합니다. 자동 배포와 빌드 서비스 같은 추가 기능에는 추가 비용이 발생할 수 있습니다.

## 6. 결론

AWS App Runner를 사용하려면 AWS Management Console, AWS CLI, AWS SDK를 통해 서비스에 접근할 수 있습니다. 이 서비스는 간단한 설정 절차를 제공해 애플리케이션을 빠르고 효율적으로 배포할 수 있게 합니다.

더 자세한 정보는 [AWS App Runner 개발자 가이드](https://docs.aws.amazon.com/apprunner/latest/dg/)와 [AWS App Runner 요금 페이지](https://aws.amazon.com/apprunner/pricing/)를 참고하세요.
