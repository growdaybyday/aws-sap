# Amazon Keyspaces

## 1. 소개

Amazon Keyspaces(Apache Cassandra용)는 AWS 클라우드에서 Cassandra 워크로드를 실행하도록 설계된 완전관리형이고 확장 가능하며 고가용성인 데이터베이스 서비스입니다. 서버를 프로비저닝, 패치, 관리할 필요 없이 이미 사용하고 있는 동일한 Cassandra 애플리케이션 코드, 드라이버, 도구를 사용할 수 있게 합니다. 이 서비스는 서버리스이기 때문에 애플리케이션 트래픽에 따라 테이블을 자동으로 확장하며, 사용한 리소스에 대해서만 비용을 지불합니다. Amazon Keyspaces는 99.99% 가용성 SLA와 저장 시 및 전송 중 암호화 같은 내장 보안 기능을 갖춘 미션 크리티컬 애플리케이션을 위해 설계되었습니다.

## 2. 기능과 역량

**Cassandra 호환성:**
Amazon Keyspaces는 Apache Cassandra와 100% 호환됩니다. 즉, Cassandra Query Language(CQL)와 기존 Cassandra 드라이버 및 개발자 도구를 최소한의 변경으로 계속 사용할 수 있습니다. 대부분 호스트 이름을 Amazon Keyspaces 엔드포인트를 가리키도록 업데이트하는 정도로 간단합니다.

**서버리스와 유연한 확장:**

- **서버 관리 불필요:** 인프라를 관리하거나 프로비저닝할 필요가 없습니다. AWS가 패치, 확장, 유지보수 같은 모든 운영 부담을 처리합니다.
- **용량 모드:** 워크로드의 예측 가능성에 맞춰 비용을 최적화하기 위해 온디맨드(요청당 지불)와 프로비저닝된 용량 모드 중에서 선택할 수 있습니다.
- **자동 확장:** 테이블은 트래픽을 기반으로 자동으로 확장되거나 축소되어, 급증 상황에서도 일관된 성능을 보장합니다.

**성능과 가용성:**

- **낮은 지연 시간:** 대규모에서도 한 자릿수 밀리초 응답 시간을 제공하도록 설계되었습니다.
- **고가용성:** 데이터는 99.99% 가용성 SLA를 충족하기 위해 AWS 리전 내 세 개의 가용 영역에 자동으로 복제됩니다.

**보안과 규정 준수:**

- **AWS IAM과 통합:** AWS Identity and Access Management(IAM)를 통해 세밀한 접근을 관리합니다.
- **암호화:** 데이터는 기본적으로 저장 시(AWS 소유 또는 고객 관리형 키 사용) 암호화되며 전송 중에는 TLS로 암호화됩니다.
- **백업과 복구:** 특정 시점 복구(PITR) 기능이 있는 지속적인 백업을 통해 35일 이내의 어느 초 단위 시점으로든 데이터를 복원할 수 있습니다.

**운영 도구와 생태계 통합:**

- **모니터링:** Amazon Keyspaces는 상세한 성능 및 운영 모니터링을 위해 Amazon CloudWatch와 통합됩니다.
- **VPC 엔드포인트:** AWS PrivateLink를 사용해 Keyspaces에 안전하게 접근할 수 있어, 트래픽이 AWS 네트워크 내에 남아 있도록 보장합니다.
- **개발자 도구:** AWS SDK, AWS CLI, CloudFormation, Terraform을 사용해 데이터베이스 작업을 자동화하고 관리할 수 있습니다.

## 3. 사용 사례

**Cassandra 워크로드 마이그레이션:**
기존 Cassandra 배포를 운영하는 조직은 코드 변경을 거의 하지 않고도 Amazon Keyspaces로 마이그레이션할 수 있습니다. 이 전환은 클러스터를 수동으로 관리할 필요를 없애면서 완전관리형 서비스의 혜택을 누릴 수 있게 합니다.

**낮은 지연 시간, 높은 처리량 애플리케이션:**
실시간 분석, 게임 리더보드, 거래 모니터링, IoT 텔레메트리처럼 한 자릿수 밀리초 지연 시간과 높은 처리량을 요구하는 애플리케이션에 이상적입니다.

**시계열 데이터와 로깅:**
Amazon Keyspaces는 로그 데이터, 센서 데이터, 채팅 기록을 포함한 대량의 시계열 데이터를 저장하고 처리하는 데 적합합니다. 자동 확장 기능은 급격한 데이터 수집 급증도 매끄럽게 처리하도록 보장합니다.

**전역 및 멀티 리전 배포:**
전역 분산이 필요한 조직을 위해 Keyspaces는 멀티 리전 복제를 지원합니다. 이를 통해 여러 AWS 리전에 데이터를 복제함으로써 낮은 지연 시간 접근과 향상된 복원력을 제공합니다.

**현대적인 애플리케이션 개발:**
Cassandra API와 오픈소스 도구를 사용해 새 애플리케이션을 구축하는 개발자는 익숙한 Cassandra 패러다임을 유지하면서 관리형 서비스의 확장성, 보안, 비용 효율성을 활용할 수 있는 Amazon Keyspaces를 활용할 수 있습니다.

## 4. 결론

Amazon Keyspaces는 완전관리형 서버리스 패키지로 Apache Cassandra의 강력함과 유연성을 제공합니다. 분산 NoSQL 데이터베이스를 운영하는 운영상의 복잡성을 오프로딩함으로써 개발자와 기업이 혁신적이고 고성능인 애플리케이션을 구축하는 데 집중할 수 있게 합니다. 견고한 보안, 내장된 백업과 복구, 더 넓은 AWS 생태계와의 매끄러운 통합을 갖춘 Amazon Keyspaces는 기존 Cassandra 워크로드를 마이그레이션하거나 새롭고 확장 가능하며 복원력 있는 애플리케이션을 설계하는 데 훌륭한 선택입니다.
