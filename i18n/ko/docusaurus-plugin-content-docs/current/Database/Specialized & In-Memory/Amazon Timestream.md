# Amazon Timestream

## 1. 소개

Amazon Timestream은 시계열 데이터를 위해 특별히 설계된 완전관리형 서버리스 데이터베이스 서비스입니다. 시계열 데이터는 일반적으로 일정한 간격으로 기록된 일련의 데이터 포인트를 포함합니다 — 예를 들어 시간에 따른 온도나 성능 지표 추적입니다. Timestream은 이러한 방대한 양의 데이터를 비용 효율적이고 매우 확장 가능한 방식으로 처리하도록 최적화되어 있어, 사물인터넷(IoT) 텔레메트리, 운영 모니터링, 실시간 분석 시나리오에 훌륭하게 적합합니다.

일반적인 관계형 데이터베이스와 달리, Timestream은 시간 참조 데이터를 효율적으로 수집하고 쿼리하는 데 초점을 맞춥니다. 필요에 따라 스토리지와 컴퓨팅 리소스를 자동으로 확장해 용량 계획을 단순화합니다. 최신 데이터가 도착하면 Timestream은 이를 빠른 접근을 위해 메모리에 저장합니다. 데이터가 오래되면 Timestream은 이를 비용 최적화된 내구성 있는 스토리지로 투명하게 전환합니다.

## 2. 아키텍처

Amazon Timestream은 수집, 스토리지, 쿼리 처리를 분리하는 현대적인 분리형 아키텍처로 구축되어 있습니다.

- **쓰기 아키텍처:**
    수신되는 데이터는 높은 처리량에 최적화된 내결함성 메모리 스토어로 수집됩니다. 이후 서비스는 내구성과 고가용성을 보장하기 위해 세 개의 가용 영역(AZ)에 걸쳐 데이터를 복제합니다. 처리량이 낮거나 늦게 도착하는 데이터는 마그네틱 스토어에 직접 쓸 수도 있습니다.

- **스토리지 아키텍처:**
    데이터는 자동으로 파티셔닝되고 인덱싱됩니다. Timestream은 시간과 컨텍스트 속성(예: 기기 ID나 위치)이라는 두 차원으로 데이터를 파티셔닝하는 "타일" 접근 방식을 사용합니다. 이 설계는 시스템이 페타바이트 규모의 데이터로 확장되면서도 쿼리 중 데이터를 효율적으로 정리(prune)할 수 있게 합니다.

- **쿼리 아키텍처:**
    Timestream은 시계열 특화 함수(보간, 스무딩, 윈도우 처리 등)로 강화된 SQL 쿼리를 지원합니다. 적응형 분산 쿼리 엔진은 대규모 데이터셋에 걸쳐 병렬로 쿼리를 처리해, 테라바이트나 페타바이트 규모의 데이터를 쿼리하더라도 낮은 지연 시간 성능을 보장합니다.

- **셀형 아키텍처:**
    99.99%의 가용성을 달성하고 장애의 영향을 제한하기 위해 Timestream은 인프라를 독립적인 "셀"로 분할합니다. 디스커버리 계층은 요청을 적절한 셀로 라우팅해 문제를 격리하고 한 셀의 장애가 전체 서비스에 영향을 미치지 않도록 보장합니다.

## 3. 데이터 생명주기와 스토리지 티어

Amazon Timestream은 두 가지 스토리지 티어를 사용해 데이터 생명주기를 자동으로 관리합니다.

- **메모리 스토어:**
    빠르고 거의 실시간에 가까운 쿼리(대시보드와 알림에 적합)를 위해 설계되어 있으며, 가장 최근의 데이터를 저장합니다. 메모리 스토어에 데이터가 남아 있는 기간에 대한 보존 기간을 구성할 수 있습니다.

- **마그네틱 스토어:**
    과거 데이터를 위한 비용 효율적인 장기 스토리지를 제공합니다. 데이터는 보존 정책에 따라 메모리 스토어에서 마그네틱 스토어로 자동 이동되며, 고성능 분석 쿼리를 위해 구성됩니다.

## 4. 쿼리 기능

Timestream은 시계열 데이터에 맞춘 확장 기능을 갖춘 SQL과 유사한 쿼리 언어를 지원합니다. 주요 기능은 다음과 같습니다.

- **시계열 함수:**
    스무딩, 보간, 윈도우 함수, 고급 집계를 위한 내장 함수가 시계열 분석을 단순화합니다.

- **대규모 병렬 처리:**
    분산 쿼리 엔진은 쿼리 복잡도와 데이터 양에 따라 컴퓨팅 리소스를 동적으로 할당해, 대규모 데이터셋에서도 신속한 처리를 가능하게 합니다.

- **사용 편의성:**
    SQL에 익숙한 개발자는 새로운 쿼리 언어를 배울 필요 없이 Timestream을 빠르게 도입해 쿼리를 실행할 수 있습니다.

## 5. 통합과 생태계

Amazon Timestream은 다른 AWS 서비스와 서드파티 도구와 매끄럽게 통합되도록 설계되었습니다.

- **AWS 통합:**
    AWS IoT Core, Amazon Kinesis, AWS Lambda, Amazon CloudWatch 같은 서비스와 통합되어, 시계열 데이터를 수집, 처리, 시각화하기 더 쉽게 만듭니다.

- **시각화와 분석:**
    많은 고객이 Amazon QuickSight, Grafana, 또는 (JDBC/ODBC 드라이버를 통한) 다른 BI 도구를 사용해 Timestream 데이터에 대한 대시보드를 구축하고 애드혹 분석을 수행합니다.

- **데이터 마이그레이션:**
    AWS Database Migration Service(DMS)는 Timestream을 대상 데이터베이스로 지원해, 기존 시계열 데이터를 Timestream으로 매끄럽게 마이그레이션할 수 있게 합니다.

## 6. Timestream for InfluxDB

네이티브 인터페이스 외에도 Amazon Timestream은 **Amazon Timestream for InfluxDB**도 제공합니다. 이 서비스는 AWS에서 관리형 InfluxDB 경험을 제공해, 익숙한 InfluxDB 2.x API와 도구를 사용하면서도 Timestream의 확장 가능한 서버리스 인프라의 혜택을 누릴 수 있게 합니다. 이미 InfluxDB를 사용하고 있지만 관리와 확장에 대한 부담을 AWS에 오프로딩하고 싶은 팀에 이상적입니다.

## 7. 결론

Amazon Timestream은 AWS에서 시계열 데이터를 저장하고 분석하기 위한 효율적이고 실용적인 솔루션을 제공합니다. 완전관리형 서버리스 접근 방식을 통해 인프라를 프로비저닝하거나 튜닝하지 않고도 데이터 수집과 쿼리를 시작할 수 있습니다. 특화된 시계열 함수를 활용함으로써 Timestream은 내장 분석 기능을 제공해, IoT 텔레메트리, 운영 지표 추적, 실시간 대시보드에 강력한 후보가 됩니다.

더 자세한 정보는 [공식 문서](https://docs.aws.amazon.com/timestream/latest/developerguide/what-is-timestream.html)를 참고하세요.
