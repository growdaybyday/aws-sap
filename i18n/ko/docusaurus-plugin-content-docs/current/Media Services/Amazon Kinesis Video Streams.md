# Amazon Kinesis Video Streams

## 1. 소개

Amazon Kinesis Video Streams는 수백만 개의 연결된 장치로부터 스트리밍 비디오(그리고 오디오와 다른 시간 인코딩된 데이터)를 수집, 처리, 저장, 검색하도록 설계된 완전관리형 AWS 서비스입니다. 기본 인프라를 관리하지 않고도 개발자가 실시간 비디오 처리 애플리케이션을 구축하고, 배치 지향 분석을 수행하고, 머신 러닝 서비스와 통합할 수 있게 해줍니다. 보안 카메라, 드론, 모바일 장치, 또는 IoT 센서에서 비디오를 캡처하든, Kinesis Video Streams는 지능적인 비디오 지원 애플리케이션을 구축하기 위한 기반 역할을 하는 안전하고 확장 가능한 수집과 재생 기능을 제공합니다.

## 2. 기능과 역량

**미디어 수집과 스트리밍**
- **다재다능한 데이터 소스:** (스마트폰, IP 카메라, 드론 같은) 다양한 장치로부터의 라이브 비디오와 오디오뿐만 아니라 센서 판독값, 열화상, RADAR 데이터 같은 비디오가 아닌 시간 인코딩된 데이터도 지원합니다.
- **실시간과 배치 처리:** 즉각적인 처리를 위해 실시간으로 데이터를 수집하며 온디맨드 배치 분석을 위해 데이터를 내구성 있게 저장하기도 합니다.

**내구성 있는 저장과 인덱싱**
- **자동 저장:** 저장 중 자동 암호화와 함께 비디오 조각을 안전하고 내구성 있게 저장하기 위한 기본 데이터 저장소로 Amazon S3를 사용합니다.
- **시간 인덱싱:** 조각은 생산자와 수집 타임스탬프 모두로 인덱싱되어, 효율적인 검색과 재생을 가능하게 합니다.

**재생과 접근 API**
- **낮은 지연 시간 재생:** 실시간과 온디맨드 재생 모두를 용이하게 하기 위해 (GetMedia, GetClip, GetHLSStreamingSessionURL, GetDASHStreamingSessionURL 같은) 여러 API를 제공합니다.
- **유연한 미디어 형식:** 다양한 코덱과 스트리밍 프로토콜을 지원해, 광범위한 장치와 재생 시나리오와의 호환성을 보장합니다.

**보안**
- **견고한 접근 제어:** 스트림에 대한 접근을 제어하기 위해 AWS Identity and Access Management(IAM)와 통합됩니다.
- **데이터 보호:** TLS를 사용해 전송 중 데이터를 암호화하고 AWS Key Management Service(KMS)를 사용해 저장 중 데이터를 암호화해, 종단 간 보안을 보장합니다.

**확장성과 관리**
- **서버리스 운영:** 자동으로 인프라를 프로비저닝하고 확장해, 수동 관리의 필요성을 없애고 운영 오버헤드를 줄입니다.
- **비용 효율성:** 사용한 만큼 지불하는 가격 정책 모델을 따라, 수집하고 저장하는 데이터에 대해서만 비용을 지불합니다.

**AWS 생태계와의 통합**
- **머신 러닝과 분석:** Amazon Rekognition Video 같은 서비스와 원활하게 통합되며 인기 있는 ML 프레임워크(TensorFlow, Apache MXNet, OpenCV)를 사용한 커스텀 분석을 지원합니다.
- **개발자 도구와 SDK:** 여러 플랫폼(Android, iOS, JavaScript, C++)을 위한 SDK를 제공하며, 심지어 미디어 파이프라인 통합을 단순화하는 GStreamer 플러그인(kvssink)도 포함합니다.

**WebRTC를 통한 실시간 통신**
- **양방향 스트리밍:** 초저지연 양방향 오디오와 비디오 스트리밍을 가능하게 하는 WebRTC에 대한 내장 지원을 제공합니다 — 비디오 도어벨이나 원격 제어 장치 같은 대화형 애플리케이션에 이상적입니다.
- **관리형 시그널링과 NAT 순회:** 추가 인프라 없이도 안전한 피어투피어 연결을 용이하게 하는 관리형 STUN/TURN 엔드포인트와 함께 제공됩니다.

**엣지 기능**
- **로컬 녹화와 예약된 스트리밍:** Kinesis Video Streams Edge Agent를 사용하면 온프레미스 IP 카메라에서 비디오를 로컬로 녹화하고 클라우드로의 업로드를 예약할 수 있어, 로컬 스토리지와 장기 클라우드 보존 사이의 균형을 맞출 수 있습니다.

## 3. 사용 사례

**스마트 홈과 보안**
- **비디오 도어벨과 베이비 모니터:** 실시간 모니터링과 양방향 통신을 위해 모바일 장치로 라이브 비디오를 스트리밍합니다.
- **홈 감시:** 보안 카메라의 비디오 영상을 안전하게 캡처하고 저장해, 나중에 재생과 분석을 가능하게 합니다.

**스마트 시티와 공공 안전**
- **교통과 감시:** 도시 전역 카메라에서 비디오를 수집해 교통 상황을 모니터링하고, 공공 안전을 강화하고, 비상 대응 시스템을 지원합니다.
- **도시 분석:** 저장된 비디오 데이터를 사용해 보행자 흐름과 차량 이동을 실시간으로 분석합니다.

**산업 자동화와 IoT**
- **장비 모니터링:** 산업 기계에서 비디오와 센서 데이터를 스트리밍해 이상 징후를 탐지하고, 예측 유지보수를 수행하고, 다운타임을 줄입니다.
- **로보틱스:** 낮은 지연 시간의 비디오 피드를 통해 로봇과 드론의 원격 제어와 모니터링을 가능하게 합니다.

**소매와 고객 참여**
- **매장 내 분석:** 레이아웃을 최적화하고 서비스를 개선하기 위해 소매 환경 내 고객 이동과 행동을 분석합니다.
- **대화형 경험:** 가상 시착이나 대화형 키오스크 같은 애플리케이션을 위해 양방향 스트리밍을 사용합니다.

**라이브 이벤트 방송과 원격 협업**
- **실시간 통신:** 최소한의 지연 시간으로 라이브 방송, 원격 의료 상담, 또는 대화형 이벤트 스트리밍을 위해 WebRTC 통합을 활용합니다.

## 4. 결론

Amazon Kinesis Video Streams는 광범위한 장치로부터 비디오와 다른 시간 인코딩된 데이터를 스트리밍하기 위한 포괄적이고, 안전하고, 확장 가능한 솔루션을 제공합니다. 비디오 수집, 저장, 재생의 복잡함을 추상화함으로써, 개발자와 기업이 스마트 홈 솔루션과 산업 자동화부터 대화형 라이브 이벤트까지 혁신적인 애플리케이션을 만드는 데 집중할 수 있게 해줍니다. 실시간 분석에 대한 내장 지원, AWS 머신 러닝 서비스와의 통합, 풍부한 API와 SDK 모음을 통해 Kinesis Video Streams는 현대적인 IoT나 비디오 지원 애플리케이션의 핵심 구성 요소입니다. 서버리스이고 사용한 만큼 지불하는 모델은 인프라 관리의 오버헤드 없이 엔터프라이즈급 기능을 얻을 수 있도록 보장합니다.
