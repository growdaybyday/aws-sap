# AWS Well-Architected Tool

## 1. 소개

클라우드 컴퓨팅은 오늘날 기술 환경에서 기초적인 기술이 되었으며, Amazon Web Services(AWS)는 이 혁명의 최전선에 있습니다. 클라우드 인프라를 구축, 유지, 개선하는 방법을 이해하는 것은 필수적입니다. 이 프로세스를 단순화하는 강력한 리소스 중 하나는 **AWS Well-Architected Tool**(AWS WA Tool)입니다. 이 장에서는 도구의 목적, 작동 방식, 주요 기능, 실용적인 사용 사례를 살펴봅니다. 끝까지 읽으면 이 도구가 확장 가능하고, 안전하고, 비용 효율적이며, 지속 가능한 클라우드 시스템을 설계하는 데 어떻게 도움이 되는지 이해하게 될 것입니다.

## 2. AWS Well-Architected Framework

AWS WA Tool의 핵심에는 AWS 솔루션 아키텍트가 수년간의 경험으로 개발한 모범 사례 세트인 **AWS Well-Architected Framework**가 있습니다. 이 프레임워크는 클라우드 워크로드를 평가하고 최적화하기 위한 구조화된 접근 방식을 제공하며 **여섯 가지 기둥**을 중심으로 구축되어 있습니다.

![Well-Architected Framework - pillars](@site/docs/Management%20and%20Governance/_assets/well-architected_framework_-_pillars.png)

- **운영 우수성:**
    운영을 실행, 모니터링, 개선하는 데 초점을 맞춥니다. 자동화, 변경 관리, 프로세스 개선을 다룹니다.

- **보안:**
    정보와 시스템 보호를 강조합니다. 데이터 기밀성, 신원 및 접근 관리, 위협 탐지, 워크로드 보안에 대한 지침을 제공합니다.

- **신뢰성:**
    시스템이 의도된 기능을 수행하고, 장애로부터 복구하고, 변화하는 요구 사항에 적응하도록 보장합니다.

- **성능 효율성:**
    워크로드 수요와 성능 목표를 충족하기 위해 컴퓨팅 리소스를 최적으로 선택하고 관리하는 데 초점을 맞춥니다.

- **비용 최적화:**
    리소스 크기를 적절히 조정하고 비용 효율적인 가격 모델을 사용해 불필요한 비용을 관리하고 줄이는 데 도움을 줍니다.

- **지속 가능성:**
    (최근에 추가됨) 리소스 활용을 극대화하고 낭비를 줄임으로써 환경적 영향을 최소화하는 데 초점을 맞춥니다.


이 기둥들은 AWS WA Tool이 아키텍처를 평가하는 기반입니다.

## 3. AWS Well-Architected Tool이란?

**AWS Well-Architected Tool**은 AWS Management Console을 통해 제공되는 무료 서비스입니다. Well-Architected Framework에 정의된 AWS의 모범 사례에 대해 클라우드 아키텍처를 평가하는 데 도움을 줍니다. 일련의 상세한 질문과 평가를 안내함으로써 이 도구는 잠재적인 위험을 식별하고 개선을 위한 실행 가능한 권장 사항을 제공합니다.

![Well-Architected Framework](@site/docs/Management%20and%20Governance/_assets/well-architected_framework.png)

주요 사항은 다음과 같습니다.

- **무료이고 접근 가능함:**
    모든 AWS 계정 소유자에게 추가 비용 없이 제공됩니다.

- **프레임워크 기반 평가:**
    여섯 가지 기둥(지속 가능성 포함)이나 전문화된 렌즈(예: 서버리스, SaaS)를 기반으로 아키텍처를 평가합니다.

- **실행 가능한 인사이트:**
    워크로드의 신뢰성, 보안, 효율성, 비용 효율성, 지속 가능성을 강화하기 위한 우선순위가 매겨진 개선 항목 목록을 제공합니다.

## 4. 작동 방식

AWS Well-Architected Tool을 사용하는 프로세스는 여러 핵심 단계로 나눌 수 있습니다.

1. **워크로드 정의:**
    워크로드는 애플리케이션을 구성하는 AWS 리소스와 코드의 모음입니다. 워크로드를 설명하고 핵심 아키텍처 결정을 문서화하는 것부터 시작하세요.

2. **검토 시작:**
    AWS Management Console을 통해 Well-Architected 검토를 시작하세요. 도구는 여섯 가지 기둥(또는 필요한 경우 커스텀 렌즈)별로 조직화된 일련의 질문을 제시합니다.

3. **안내된 질문에 답하기:**
    각 질문은 설계 선택을 조사하고 AWS 모범 사례와의 정렬을 보장하도록 설계되었습니다. 일부 질문은 모범 사례 답변을 가지고 있고, 다른 질문은 해당하지 않으면 건너뛸 수 있습니다.

4. **위험과 권장 사항 식별:**
    검토를 완료하면 도구는 응답을 평가해 고위험 문제를 강조하고 이를 개선하는 방법에 대한 상세한 권장 사항을 제공합니다.

5. **개선 사항 추적:**
    검토의 스냅샷을 마일스톤으로 저장하세요. 이 기능은 시간이 지남에 따른 변화를 모니터링하고 구현된 개선 사항이 아키텍처를 어떻게 강화하는지 측정할 수 있게 합니다.

6. **워크플로와 통합:**
    팀이나 조직의 경우 도구의 견고한 API는 CI/CD 파이프라인과 거버넌스 프로세스로의 통합을 가능하게 합니다. 추가로 AWS Trusted Advisor와 AWS Service Catalog AppRegistry와의 통합은 검토 프로세스를 간소화하는 데 도움을 줍니다.

## 5. AWS Well-Architected Tool의 주요 기능

AWS WA Tool은 초보자와 숙련된 실무자 모두에게 귀중한 리소스가 되게 하는 여러 뛰어난 기능을 제공합니다.

### 5.1. 아키텍처 지침

- **맞춤형 권장 사항:**
    아키텍처가 AWS 모범 사례를 준수하도록 보장하는 상세한 제안을 받으세요. 클라우드 결정을 단계별로 안내하는 멘토가 있는 것으로 생각하세요.

- **모범 사례 문서화:**
    도구의 권장 사항은 AWS 아키텍트의 광범위한 경험을 기반으로 하며 AWS가 발전함에 따라 지속적으로 업데이트됩니다.

### 5.2. 워크플로 내 모범 사례

- **API 통합:**
    API를 활용해 도구를 개발 및 운영 워크플로에 통합하세요. 이는 아키텍처 검토를 자동화하고 전체적인 거버넌스 프로세스에 통합하는 데 도움을 줍니다.

- **확장된 생태계:**
    평가를 보완하기 위해 AWS Trusted Advisor 같은 서비스와의 통합을 사용하세요.

### 5.3. 마일스톤 추적

- **검토 버전 관리:**
    아키텍처 검토의 특정 시점 스냅샷을 저장하세요. 이를 통해 진행 상황을 추적하고, 개선 사항을 비교하고, 시간이 지남에 따른 변화가 시스템을 모범 사례에 더 가깝게 만들도록 보장할 수 있습니다.

### 5.4. 협업과 커스터마이징

- **멀티 사용자 협업:**
    워크로드 검토를 팀원이나 조직 전체와 공유하세요. 최대 300명의 IAM 사용자나 심지어 전체 AWS Organization도 검토에 접근할 수 있습니다.

- **커스텀 렌즈:**
    표준 프레임워크를 넘어 특정 기술이나 산업 요구 사항에 맞춘 커스텀 렌즈를 만들 수 있습니다(예: 환경적 영향을 평가하기 위한 지속 가능성 렌즈 추가). 커스텀 렌즈는 자체 질문, 모범 사례, 개선 계획을 추가할 수 있게 합니다.

## 6. 결론

AWS Well-Architected Tool은 클라우드 컴퓨팅의 세계에 발을 들이는 모든 사람에게 없어서는 안 될 리소스입니다. 여정을 시작하는 대학생이든, 스타트업이나 사이드 프로젝트를 진행 중이든, 대학 연구에 참여하고 있든, AWS 자격증을 준비하고 있든, 이 도구는 견고한 클라우드 시스템을 설계하고 운영하는 것에 대한 포괄적이고 안내된 인사이트를 제공합니다.

AWS WA Tool을 워크플로에 통합함으로써 AWS 모범 사례를 배우고 적용할 뿐만 아니라 실제 클라우드 과제를 해결할 자신감도 얻게 됩니다. 무료 접근, 협업 기능, 지속적인 개선 사이클을 갖춘 이 도구는 클라우드 아키텍처 마스터를 향한 여정에서 강력한 멘토입니다.
