# AWS Service Quotas

## 1. 소개

AWS Service Quotas는 200개 이상의 AWS 서비스에 걸친 리소스 한도(또는 "할당량")에 대한 통합된 시각을 제공합니다. 이 한도에 대한 사용량을 지속적으로 모니터링함으로써 예기치 않은 스로틀링이나 서비스 중단을 방지하는 데 도움을 줍니다. 단일 계정을 관리하는 개발자든 조직 내 여러 계정을 감독하는 관리자든, Service Quotas는 선제적인 리소스 관리를 위한 강력한 솔루션을 제공합니다.

## 2. AWS Service Quotas 개요

### 중앙화된 관리

- **통합 대시보드:**
    AWS Service Quotas는 AWS가 부과하는 다양한 한도를 하나의 중앙화된 대시보드로 통합합니다. 이를 통해 EC2, S3, Lambda, API Gateway 등의 서비스에 대한 할당량을 신속하게 검토할 수 있습니다.

- **멀티 인터페이스 접근:**
    AWS Management Console, CLI, 또는 API를 통해 Service Quotas와 상호작용할 수 있어, 기존 워크플로와 자동화 스크립트에 통합할 수 있습니다.

### 계정 간 및 조직적 인사이트

여러 AWS 계정을 관리하는 조직을 위해 Service Quotas는 전반적으로 일관된 리소스 한도를 감독하고 강제하는 데 사용할 수 있습니다. 이는 AWS Organizations의 거버넌스와 중앙화된 통제에 특히 유용합니다.
## 3. AWS Service Quotas의 핵심 개념

### 할당량이 존재하는 이유

AWS는 전체적인 인프라 안정성을 유지하고, 공정한 리소스 분배를 보장하고, 공유 환경의 성능을 보호하기 위해 서비스에 할당량을 강제합니다. 이 할당량들은 다음에 도움을 줍니다.

- **과다 소비 방지:** 어떤 단일 고객도 공유 리소스를 고갈시킬 수 없도록 보장해, 모든 사용자를 위한 안정성을 유지합니다.
- **보안과 신뢰성 강화:** 성능 저하로 이어질 수 있는 예기치 않은 사용량 급증의 위험을 완화하는 데 도움이 되는 한도를 강제합니다.
- **운영 간소화:** 명확한 지침과 자동화된 알림을 제공해 리소스 소비를 선제적으로 관리할 수 있게 합니다.

### 할당량 유형과 지표

- **기본 할당량:**
    AWS는 각 서비스에 대해 기본 할당량 값을 할당합니다(예: 동시 Lambda 실행, 초당 API Gateway 요청). 이 값들은 모범 사례와 일반적인 사용 패턴을 기반으로 합니다.

- **조정 가능한 할당량:**
    필요가 발전함에 따라 많은 할당량은 요청을 제출함으로써 늘릴 수 있습니다. 이는 콘솔을 통해 직접, AWS CLI를 통해, 또는 API를 사용해 프로그래밍 방식으로 수행할 수 있습니다.

## 4. 할당량 임계값과 알림

### 할당량 임계값 이해하기

- **정의된 한도:**
    각 AWS 서비스에는 특정 한도가 있습니다. 예를 들어 AWS Lambda는 동시 실행 수에 할당량이 있고, EC2는 리전별 인스턴스 유형에 한도가 있습니다.

- **임계값 설정:**
    안전 마진을 확보하기 위해 실제 할당량보다 낮은 사용량 임계값(예: 최댓값의 90%)을 정의하는 것이 모범 사례입니다. 이 관행은 시기적절한 시정 조치를 취하는 데 도움이 됩니다.

### 자동화된 알림

- **CloudWatch 통합:**
    AWS Service Quotas는 Amazon CloudWatch와 통합되어, 사용량 지표를 기반으로 알람을 설정할 수 있게 합니다. 사용량이 정의된 임계값에 근접하면 CloudWatch는 이메일, SMS, 또는 Amazon SNS를 통해 알림을 트리거할 수 있습니다.

- **선제적 알림:**
    이 알림들은 중요한 한도에 도달하기 전에 애플리케이션을 확장하거나 할당량 증가를 요청할 수 있게 합니다.

## 5. 할당량 증가 요청하기

### 작동 방식

- **단순한 프로세스:**
    사용량이 한도에 근접하고 있다는 것을 발견하면 AWS Service Quotas 콘솔을 통해 직접 증가를 요청할 수 있습니다. 요청 프로세스는 전통적인 지원 티켓에 비해 간소화되어 있습니다.

- **여러 접근 방법:**
    콘솔 외에도 AWS CLI나 API를 사용해 요청을 프로그래밍 방식으로 제출할 수 있어, 할당량 관리를 자동화된 워크플로에 통합하기 더 쉽습니다.

### 증가를 위한 모범 사례

- **미리 계획:**
    항상 사용량 트렌드를 모니터링하고 애플리케이션이 한도에 도달하기 훨씬 전에 증가를 요청하세요.
- **점검 자동화:**
    필요한 조정이 자동으로 식별되고 조치되도록 CI/CD 파이프라인에 할당량 모니터링을 통합하세요.

## 6. 결론

AWS Service Quotas는 AWS 리소스를 효과적으로 관리하고 확장하기 위한 필수적인 도구입니다. 가시성을 위한 중앙화된 대시보드, CloudWatch를 통한 자동화된 알림, 할당량 증가를 요청하기 위한 간소화된 프로세스를 제공합니다. 단일 계정에서 운영하든 대규모 멀티 계정 조직을 관리하든, 워크플로에 AWS Service Quotas를 통합하면 견고한 애플리케이션 성능을 유지하고, 성장을 계획하고, 예기치 않은 중단을 피할 수 있습니다.

상세한 모니터링, 선제적 알림, 자동화를 결합함으로써 워크로드 변화를 처리하고 성능과 비용 모두를 위해 인프라를 최적화할 준비를 잘 갖출 수 있습니다.
