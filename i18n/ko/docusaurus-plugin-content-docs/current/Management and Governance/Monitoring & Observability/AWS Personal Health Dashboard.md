# AWS Personal Health Dashboard

## 1. 소개

AWS 인프라가 복원력을 유지하고 중단이나 유지보수 이벤트로부터 신속하게 복구되도록 보장하는 것은 모든 조직에게 무엇보다 중요합니다. AWS Personal Health Dashboard(PHD)는 AWS 서비스와 리소스에 영향을 미치는 운영 및 유지보수 이벤트에 대한 중요한 계정별 인사이트를 제공합니다. Amazon EventBridge와 AWS Health API 같은 이벤트 기반 메커니즘과 결합되면 문제에 선제적으로 대응하고 유지보수를 실시간으로 조율할 수 있습니다. 이 장에서는 Personal Health Dashboard가 어떻게 귀중한 가시성을 제공하는지, AWS Organizations를 사용해 계정 전반의 상태 정보를 어떻게 집계하는지, 잠재적으로 파괴적인 이벤트에 대한 실용적인 알림과 자동화된 개선을 어떻게 설정하는지 설명합니다.

## 2. AWS Personal Health Dashboard 이해하기

![AWS Personal Health Dashboard](@site/docs/Management%20and%20Governance/_assets/aws_personal_health_dashboard.png)

Personal Health Dashboard는 여러분의 특정 AWS 환경과 관련된 이벤트만 모니터링하고 표시하는 전역 서비스입니다. 핵심 기능은 다음을 포함합니다.

- **유지보수와 중단 이벤트 모니터링:**
    - **예정된 유지보수:** 다가오는 유지보수 창(예: EC2 인스턴스나 EBS 볼륨에 영향을 미치는 대기 중인 패치)을 탐지합니다.
    - **중단이나 가용성 이벤트:** 운영상의 문제가 여러분의 리소스에 직접 영향을 미칠 때 알림을 보냅니다.

- **상세한 이벤트 정보:**
    각 알림은 영향받은 엔티티 — 리소스 식별자(인스턴스 ID, 볼륨 ID 등) — 에 대한 세부 사항을 제공하며, 문제를 신속하게 해결하는 데 도움이 되는 권장 개선 단계를 포함합니다.

- **개인화된 뷰 vs. 전역 뷰:**
    모든 AWS 고객에 대한 전체적인 상태를 보여주는 AWS Service Health Dashboard와 달리, Personal Health Dashboard는 전역 이벤트를 걸러내고 계정에 영향을 미치는 정보만 표시합니다. 이 집중된 뷰는 중단과 예정된 이벤트가 리소스와 어떻게 직접 관련되는지에 대한 실시간 업데이트를 받도록 보장합니다.

- **개선 지침:**
    탐지된 모든 이벤트에 대해 PHD는 상세한 문제 해결 정보와 개선 지침(예: 스냅샷에서 EBS 볼륨을 복원하는 권장 사항)을 포함해, 다운타임을 최소화하는 데 도움을 줍니다.

## 3. 여러 계정에 걸쳐 상태 정보 집계하기

여러 AWS 계정을 사용하는 조직을 위해 AWS Organizations는 Personal Health Dashboard에서 조직적 뷰를 제공합니다.

- **중앙화된 모니터링:**
    활성화되면 관리 계정의 관리자는 모든 회원 계정에 걸친 상태 이벤트를 보고 쿼리할 수 있습니다. 이 통합된 관점은 전체 조직에 걸친 잠재적인 중단을 모니터링하기 위한 단일 통합 대시보드를 제공함으로써 대규모 운영을 단순화합니다.

- **조율된 유지보수:**
    조직적 뷰는 중앙 팀이 유지보수 이벤트를 일관되게 계획하고 예약할 수 있게 하여, 영향받은 모든 계정이 선제적이고 통일되게 관리되도록 보장합니다.

## 4. Amazon EventBridge를 사용한 이벤트 기반 알림

Personal Health Dashboard는 상태 이벤트를 추적하기 위한 풍부한 시각적 콘솔을 제공하지만, 많은 조직은 Amazon EventBridge를 사용해 대응을 자동화함으로써 그 기능을 확장합니다.

- **자동화된 이벤트 라우팅:**
    EventBridge는 AWS Health 이벤트를 소비해 다양한 대상으로 라우팅합니다. 예를 들면:
    - **Amazon SNS:** (이메일, SMS, 또는 모바일 푸시를 통해) 운영 팀에 직접 알림을 보냅니다.
    - **AWS Lambda:** 실패한 인스턴스를 다른 가용 영역으로 교체하거나 워크로드를 마이그레이션하는 것 같은 즉각적인 개선을 수행하는 함수를 호출합니다.
    - **Amazon SQS나 Kinesis Data Streams:** 상태 이벤트를 로깅, 감사, 추가 처리합니다.

- **자동화를 위한 사용 사례:**
    - **사고 알림:** 중요한 이벤트에 대해 운영 팀에 즉시 알립니다.
    - **자동화된 개선:** 문제를 자동으로 완화하는 워크플로를 트리거합니다(예: 실패한 리소스 교체).
    - **감사와 분석:** 규정 준수 보고와 과거 분석을 위해 이벤트를 스트리밍합니다.

- **퍼블릭 vs. 프라이빗 알림:**
    Personal Health Dashboard는 리소스별 이벤트에 초점을 맞추지만, (리소스와 관련 없는) 퍼블릭 이벤트는 AWS Service Health Dashboard RSS 피드 같은 퍼블릭 채널을 통해 계속 사용 가능하다는 점에 유의하세요.

## 5. AWS Health API와 IT 관리 도구 통합하기

시각적 모니터링과 자동화된 알림을 넘어 AWS Health API는 기존 IT 관리 시스템과의 더 깊은 통합을 가능하게 합니다.

- **프로그래밍 방식 접근:**
    AWS Health API를 사용하면 이벤트 세부 사항, 영향받은 엔티티, 개선 지침을 프로그래밍 방식으로 가져올 수 있어, 커스텀 대시보드나 내부 도구와의 통합을 가능하게 합니다.

- **서드파티 통합:**
    많은 조직이 Service Management Connector(SMC)를 통해 AWS 상태 이벤트를 ServiceNow나 JIRA 같은 시스템과 통합해, 상태 이벤트에 기반한 티켓 생성과 업데이트를 자동화합니다. 이 긴밀한 통합은 사고 관리 워크플로를 간소화하고 수동 오버헤드를 줄여줍니다.

- **세밀한 접근 제어:**
    AWS Identity and Access Management(IAM) 정책 조건을 사용하면 이벤트 메타데이터(이벤트 유형이나 영향받은 서비스 등)를 기반으로 민감한 상태 이벤트에 대한 접근을 제한할 수 있어, 승인된 사용자만 중요한 알림을 받도록 보장합니다.

## 6. 예시 시나리오

여러 리전에 분산된 EC2 인스턴스 함대를 관리하고 있다고 상상해보세요. 갑자기 하나의 가용 영역이 연결성 문제를 경험해, 인스턴스가 비정상적으로 오랫동안 대기 상태로 남아 있게 됩니다. AWS Personal Health Dashboard가 문제를 탐지하고 미해결 문제 아래에 표시해, 특정 가용 영역이 영향을 받았다는 것을 나타냅니다. EventBridge 규칙이 구성되어 있다면:

- **알림:**
    문제를 알리는 SNS 메시지가 운영 팀에 전송됩니다.

- **자동화된 개선:**
    Lambda 함수가 트리거되어 영향받지 않은 가용 영역에 새 EC2 인스턴스를 자동으로 시작해, 다운타임을 최소화하고 지속적인 서비스 가용성을 보장합니다.


이 시나리오는 선제적인 모니터링과 이벤트 기반 자동화를 결합하면 예기치 않은 중단 중에도 서비스 연속성을 유지하는 데 어떻게 도움이 되는지 보여줍니다.

## 7. AWS Health Dashboard vs. Personal Health Dashboard

핵심적인 차이는 AWS Health Dashboard가 AWS 서비스의 전반적인 상태에 대한 일반적인 뷰를 제공하는 반면, Personal Health Dashboard는 개인화된 계정별 뷰를 전달한다는 것입니다. 다시 말해:

- **AWS Health Dashboard(서비스 상태 뷰):**
    이 부분은 전 세계적으로 모든 AWS 서비스의 전반적인 상태와 성능을 보여줍니다. 특정 AWS 리소스에 맞춤화되지 않고 광범위한 중단이나 문제에 대한 넓은 그림을 제공합니다.

- **Personal Health Dashboard:**
    로그인했을 때 이 뷰는 이러한 전역 문제(또는 예정된 유지보수 이벤트)가 자신의 리소스에 어떻게 영향을 미치는지에 초점을 맞춥니다. 개인화된 알림, 상세한 개선 지침, AWS 계정에 영향을 미칠 수 있는 다가오는 변경 사항에 대한 알림을 제공합니다.


즉, 퍼블릭 Service Health 뷰는 AWS가 전반적으로 문제를 겪고 있는지 볼 수 있게 해주는 반면, Personal Health Dashboard는 그 문제들이 여러분 자신의 환경에 영향을 미칠 수 있는지 여부와 방법을 알려줍니다.

## 8. 결론

AWS Personal Health Dashboard는 AWS 이벤트가 특정 리소스에 어떤 영향을 미치는지에 대한 실시간 가시성을 얻기 위한 필수적인 도구입니다. 오로지 여러분의 환경에만 초점을 맞춤으로써 계획하고 신속하게 대응하는 데 도움이 되는 예정된 유지보수 알림과 중단 알림 같은 실행 가능한 인사이트를 제공합니다. 게다가 Amazon EventBridge를 활용하면 팀에 알릴 뿐만 아니라 즉각적인 개선 조치도 트리거할 수 있는 자동화되고 이벤트 기반 워크플로를 가능하게 합니다. AWS Health API를 통한 추가 통합과 IAM을 사용한 세밀한 접근 제어를 통해 조직은 견고하고, 확장 가능하고, 복원력 있는 클라우드 환경을 구축할 수 있습니다.
