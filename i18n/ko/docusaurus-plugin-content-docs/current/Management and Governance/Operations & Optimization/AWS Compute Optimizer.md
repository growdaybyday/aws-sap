# AWS Compute Optimizer

## 1. 소개

**AWS Compute Optimizer**는 AWS 컴퓨팅 리소스 구성과 그 활용 지표를 분석하는 머신 러닝 기반 서비스입니다. 주요 목표는 비용을 낮추고 성능을 개선할 수 있는 적정 크기 조정 권장 사항을 제공함으로써 워크로드를 최적화하는 데 도움을 주는 것입니다. 리소스의 현재 구성을 실제 사용 패턴과 비교한 다음 더 최적의 리소스 유형이나 크기를 제안함으로써 이를 달성합니다.

## 2. 지원되는 리소스

Compute Optimizer는 현재 다음을 포함한 여러 AWS 컴퓨팅 리소스에 대한 권장 사항을 지원합니다.

- **Amazon EC2 인스턴스:** CPU, 메모리, 네트워크, 디스크 I/O 활용을 평가해 성능 요구를 충족하면서도 비용 효율적인 인스턴스 유형을 권장합니다.
- **Amazon EC2 Auto Scaling 그룹:** 단일 또는 혼합 인스턴스 유형을 가진(지원되는 확장 정책과 함께) 그룹을 분석하고 적정 크기 조정 기회를 제안합니다.
- **Amazon EBS 볼륨:** 다른 볼륨 유형으로 이동하거나, 볼륨 크기, 또는 IOPS 설정을 조정하는 권장 사항을 제공합니다.
- **AWS Lambda 함수:** 메모리 구성과 사용 패턴을 검토해 더 적절한 메모리 설정을 권장합니다.
- **AWS Fargate의 Amazon ECS 서비스:** CPU와 메모리 활용을 검사해 최적의 태스크 리소스 설정을 제안합니다.
- **상용 소프트웨어 라이선스:** 해당하는 경우 EC2에서 실행되는 Microsoft SQL Server 라이선스에 대한 권장 사항을 제공합니다.
- **Amazon RDS DB 인스턴스:** Aurora, RDS MySQL, PostgreSQL을 포함한 여러 지원되는 데이터베이스 엔진에 대한 적정 크기 조정 권장 사항을 제공합니다.

## 3. 작동 방식

![aws-cost-optimizer](@site/docs/Management%20and%20Governance/_assets/aws-cost-optimizer.png)


1. **데이터 수집:**
    (AWS Management Console, CLI, 또는 SDK를 사용해) 옵트인하면 Compute Optimizer는 Amazon CloudWatch로부터 구성 세부 사항과 활용 데이터를 수집하기 시작합니다. 기본적으로 지난 14일간의 데이터를 사용합니다. (선택적 유료 기능인) 강화된 인프라 지표를 사용하면 조회 기간을 최대 93일까지 확장할 수 있습니다.

2. **분석과 머신 러닝:**
    이 서비스는 머신 러닝 알고리즘을 사용해 CPU 활용률, 메모리 사용량, 네트워크 I/O, (EC2와 EBS의) 디스크 I/O 같은 지표와 다른 관련 파라미터를 처리해 리소스가 과다 프로비저닝되었는지, 부족하게 프로비저닝되었는지, 또는 최적화되었는지 평가합니다.

3. **권장 사항:**
    분석을 기반으로 Compute Optimizer는 권장 사항을 생성합니다.

    - **적정 크기 조정 권장 사항:** 비용을 줄이거나 성능을 개선할 수 있는 인스턴스 유형이나 크기 변경 제안.
    - **유휴 리소스 권장 사항:** 거의 사용되지 않아 종료 대상이 될 수 있는 리소스 식별.
    - **라이선스 최적화:** EC2에서 실행되는 특정 상용 소프트웨어의 경우 라이선스 비용 조정을 포함할 수 있는 권장 사항.
    - **예상 지표:** 현재 사용량 외에도 권장된 리소스 구성에 대한 예상 활용 데이터를 보여줍니다.

## 4. 멀티 계정 지원

Compute Optimizer는 독립형 계정과 AWS Organizations 모두를 지원합니다. 조직에서는 관리 계정이 옵트인하고 통합된 권장 사항 시각을 위해 모든 회원 계정을 포함하도록 선택할 수 있습니다.

## 5. 가격 정책

AWS Compute Optimizer 자체는 추가 요금이 발생하지 않습니다. 다만 다음을 유념하세요.

- **CloudWatch 비용:**
    이 서비스는 분석을 위해 CloudWatch 지표를 사용하며, 기본 CloudWatch 모니터링은 무료지만 확장 지표나 고해상도 지표는 요금이 부과될 수 있습니다.
- **강화된 인프라 지표:**
    이 기능을 활성화하면 분석을 위한 조회 기간이 확장되며 추가 비용이 발생할 수 있습니다.

## 6. 결론

AWS Compute Optimizer는 머신 러닝을 활용해 컴퓨팅 리소스 사용을 최적화하기 위한 실행 가능한 권장 사항을 제공하는 강력한 도구입니다. 과거 활용과 구성 데이터를 분석함으로써 Amazon EC2 인스턴스, Auto Scaling 그룹, EBS 볼륨, Lambda 함수, ECS 서비스 등을 적정 크기로 조정하는 데 도움을 주어 비용과 성능의 더 나은 균형을 달성할 수 있게 합니다. CloudWatch, AWS Organizations와의 통합과 커스터마이징 가능한 권장 사항 설정은 효율적인 AWS 리소스 관리를 위한 필수적인 서비스가 되게 합니다.

자세한 정보는 [AWS Compute Optimizer 시작하기](https://docs.aws.amazon.com/compute-optimizer/latest/ug/getting-started.html) 가이드를 참고하세요.
