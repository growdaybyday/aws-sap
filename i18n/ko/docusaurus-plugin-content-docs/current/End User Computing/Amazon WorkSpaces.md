# Amazon WorkSpaces

## 1. 소개

**Amazon WorkSpaces**는 조직이 AWS 클라우드에서 Windows나 Linux 데스크톱을 신속하게 프로비저닝할 수 있게 해주는 완전관리형이고 안전한 가상 데스크톱 서비스입니다. 하드웨어를 구매, 프로비저닝, 관리할 필요를 없애면서 사용자가 다양한 장치에서 어디서든 접근할 수 있는 영구적인 데스크톱 경험을 전달합니다.

핵심 측면은 다음을 포함합니다.

- **관리형 서비스:** AWS가 인프라 프로비저닝, 패치, 유지보수를 처리합니다.
- **유연성:** 영구 데스크톱(각 사용자가 자신의 데스크톱을 가짐)과 풀링된 데스크톱(공유 사용 사례용)을 모두 지원합니다.
- **확장성:** AWS Management Console, CLI, 또는 API를 사용해 한 대에서 수천 대의 데스크톱까지 신속하게 확장합니다.

## 2. 핵심 기능

- **다중 OS 지원:**
    - **Windows 데스크톱:** 필요한 경우 Windows 10/11을 위한 BYOL(Bring Your Own License) 옵션 포함.
    - **Amazon Linux 데스크톱:** 영구 홈 디렉터리를 갖춘 Linux 사용자를 위해 최적화됨.

- **영구 스토리지:**
    - 각 WorkSpace는 시스템(루트) 볼륨과 사용자 볼륨이라는 두 개의 볼륨과 함께 제공됩니다.
    - 사용자 데이터의 스냅샷이 자동으로 촬영되어 데이터 복구와 지속성을 보장합니다.

- **유연한 청구 모델:**
    - **AlwaysOn:** 지속적인 가용성을 위한 고정 월별 가격 정책.
    - **AutoStop:** 비활성 상태 후 자동으로 데스크톱을 중지하는 시간별 계량, 비용을 절감합니다.

- **안전한 접근:**
    - **암호화:** (HTTPS와 AES 암호화된 PCoIP 세션을 사용한) 전송 중 암호화와 AWS KMS를 통한 저장 중 암호화를 지원합니다.
    - **접근 제어:** (AD Connector, AWS Managed Microsoft AD, 또는 Simple AD를 통해) AWS Directory Service와 통합되며 MFA와 IP 접근 제어 그룹을 지원합니다.
    - **신뢰할 수 있는 장치:** 선택적으로 클라이언트 장치 인증서를 기반으로 데스크톱 접근을 제한할 수 있습니다.

- **클라이언트 지원:**
    - Windows, macOS, Linux, iPad, Android, Chromebook, 심지어 웹 브라우저를 통해서도 네이티브 WorkSpaces 클라이언트를 사용할 수 있습니다.

## 3. 아키텍처와 배포

- **Virtual Private Cloud(VPC):**
    - WorkSpaces는 고가용성과 내결함성을 보장하기 위해 (서로 다른 가용 영역에 걸쳐) 최소 두 개의 서브넷으로 구성된 Amazon VPC 내에서 실행됩니다.
    - 고객은 보안 그룹과 라우팅을 포함한 네트워크 설정에 대한 완전한 제어권을 가집니다.

- **디렉터리 서비스 통합:**
    - **AD Connector:** 기존 온프레미스 Active Directory로 인증 요청을 프록시합니다.
    - **AWS Managed Microsoft AD/Simple AD:** 사용자와 정책을 관리하기 위한 클라우드 관리형 디렉터리 서비스를 제공합니다.

- **스트리밍 프로토콜:**
    - WorkSpaces는 네트워크 조건에 따라 데스크톱 렌더링을 최적화하는 적응형 스트리밍 프로토콜(Windows용 PCoIP와 Linux용 Amazon DCV)을 사용합니다.
    - 프로토콜은 이상적이지 않은 네트워크에서도 고품질 사용자 경험을 전달하도록 설계되었습니다.

- **자동화와 관리:**
    - AWS CLI, API, CloudFormation을 사용해 프로비저닝과 관리를 자동화합니다.
    - 셀프 서비스 포털을 통해 최종 사용자가 WorkSpace 재시작이나 재구축 같은 일상적인 태스크를 수행할 수 있게 할 수 있습니다.

## 4. 사용 사례와 이점

- **원격 근무와 BYOD:**
    - 직원이 어떤 위치나 장치에서든 안전하게 일관된 데스크톱 환경에 접근할 수 있게 해줍니다.
- **엔터프라이즈 확장성:**
    - 상당한 자본 지출 없이 가상 데스크톱 배포를 신속하게 확장합니다.
- **비용 효율성:**
    - 사용한 만큼 지불하는 가격 정책 모델과 자동 중지 옵션은 데스크톱이 유휴 상태일 때 비용을 줄이는 데 도움을 줍니다.
- **향상된 보안:**
    - 견고한 보안 제어, 암호화, 규정 준수 기능을 갖춘 데스크톱의 중앙화된 관리.

## 5. 결론

Amazon WorkSpaces는 AWS의 글로벌 인프라 위에 구축된 고도로 안전하고, 확장 가능하고, 유연한 가상 데스크톱 솔루션을 제공합니다. 공식 모범 사례와 포괄적인 문서를 활용함으로써 조직은 전일제 원격 근무자부터 태스크별 풀링된 환경까지 다양한 사용자 요구를 지원하는 비용 효율적이고 복원력 있는 클라우드 데스크톱을 배포할 수 있습니다.

더 자세한 내용은 [공식 자료](https://docs.aws.amazon.com/workspaces/)를 참고하세요.
