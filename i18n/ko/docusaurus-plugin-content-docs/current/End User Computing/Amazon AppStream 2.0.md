# Amazon AppStream 2.0

## 1. 소개

**Amazon AppStream 2.0**은 소프트웨어를 다시 작성하지 않고도 어떤 장치에서든 사용자에게 데스크톱 애플리케이션을 전달할 수 있게 해주는 완전관리형 애플리케이션 스트리밍 서비스입니다. 예를 들어 회사가 일반적으로 강력한 Windows PC가 필요한 고급 사진 편집 애플리케이션을 사용한다고 상상해보세요. 모든 직원의 컴퓨터에 이 소프트웨어를 설치하고 업데이트하는 대신, 사진 편집기가 사전 설치된 AppStream 2.0 이미지를 만듭니다. 그런 다음 그 이미지를 실행하는 스트리밍 인스턴스 플릿을 설정합니다.

직원이 사진을 편집해야 할 때 웹 브라우저나 전용 AppStream 2.0 클라이언트를 통해 로그인하기만 하면 됩니다. 사진 편집 애플리케이션을 실행하는 스트리밍 인스턴스가 클라우드에서 시작됩니다. 모든 무거운 처리가 AWS에서 일어남에도 불구하고 직원은 마치 자신의 컴퓨터에 설치된 것처럼 애플리케이션과 상호 작용합니다. 이 접근 방식은 하드웨어 비용을 절감할 뿐만 아니라 업데이트를 중앙화하고 데이터를 클라우드에 보관함으로써 보안을 개선합니다.

## 2. 핵심 개념과 아키텍처

AppStream 2.0의 아키텍처는 몇 가지 핵심 구성 요소를 중심으로 구축됩니다.

- **이미지**: 운영체제(Windows Server나 Amazon Linux 2)와 애플리케이션을 포함하는 사전 구성된 템플릿입니다. 생성되면 이미지는 리전 내에서 복사되거나 공유될 수 있습니다.
    
- **Image Builder**: 애플리케이션을 설치, 테스트, 구성하기 위해 시작하는 가상 머신입니다. 준비되면 이를 사용해 최종 이미지를 만듭니다.
    
- **플릿**: 선택한 이미지를 실행하는 스트리밍 인스턴스(EC2 인스턴스) 그룹입니다. 각 사용자의 세션은 전용 인스턴스에서 실행됩니다. 성능과 비용 사이의 균형을 맞추기 위해 플릿은 Always-On, On-Demand, 또는 Elastic 같은 다른 모드로 구성될 수 있습니다.
    
- **스택**: 플릿을 사용자 접근 정책 및 영구 스토리지 구성과 결합합니다. 스택은 사용자가 애플리케이션을 스트리밍할 때 실제로 연결하는 대상입니다.
    
- **스트리밍 인스턴스**: 사용자의 세션에 프로비저닝되는 개별 인스턴스입니다. 세션이 종료된 후 인스턴스는 종료되어, 사용자 데이터가 장치에 지속되지 않도록 보장합니다.

## 3. 플릿 자동 확장

AppStream 2.0은 여러 플릿 유형을 지원합니다.
    
- **Always-On** 플릿은 항상 실행되어 즉각적인 접근을 제공하지만 지속적인 요금이 발생합니다.
- **On-Demand** 플릿은 사용자가 연결할 때 시작되며 활성 세션에 대해서만 요금이 청구되고 유휴 상태일 때는 명목상의 중지 요금이 부과됩니다.
- **Elastic** 플릿은 초 단위 청구로 앱 블록(VHD)에서의 애플리케이션 스트리밍을 지원합니다.

예약된 확장, 단계별 확장, 또는 목표 추적 같은 확장 정책은 실시간 사용량과 CloudWatch 지표(용량 활용률과 용량 부족 오류 같은)를 기반으로 플릿 용량을 자동으로 조정합니다.

## 4. 클라이언트 접근과 스트리밍 경험

- **브라우저 기반 접근**:
    AppStream 2.0은 어떤 HTML5 지원 웹 브라우저를 통해서든 직접 스트리밍을 지원해, 추가적인 소프트웨어 설치가 필요 없으므로 접근을 단순화합니다.
    
- **네이티브 클라이언트**:
    (최대 4K까지) 다중 모니터 지원, (3D 마우스, 웹캠 같은) USB 장치 리디렉션, 로컬 드라이브와 프린터 리디렉션, 개선된 키보드 단축키 지원 같은 향상된 기능을 위해 AWS는 Windows(그리고 macOS)를 위한 전용 AppStream 2.0 클라이언트를 제공합니다.

- **스트리밍 프로토콜**:
    기본 스트리밍은 Amazon DCV로 구동되며, 원활하고 반응성 있는 사용자 경험을 전달하기 위해 실시간으로 네트워크 조건에 맞게 조정됩니다.
