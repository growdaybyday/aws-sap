# Amazon CodeGuru

## 1. 소개

Amazon CodeGuru는 코드 품질을 개선하고 애플리케이션 성능을 최적화하는 데 도움을 주는 AI 기반 개발자 도구입니다. 머신 러닝과 자동화된 추론을 결합해 소스 코드와 런타임 동작을 분석함으로써 이를 수행합니다. 본질적으로 CodeGuru는 두 가지 주요 서비스로 구성됩니다.

- **Amazon CodeGuru Reviewer** – 이 서비스는 (일반적으로 풀 리퀘스트나 전체 저장소 스캔의 일부로) 코드를 분석한 다음 버그를 수정하고, 코드 품질을 개선하고, 잠재적인 보안 취약점을 해결하기 위한 실행 가능한 권장 사항을 제공함으로써 코드 리뷰를 자동화합니다.
- **Amazon CodeGuru Profiler** – 이 서비스는 실행 중인 애플리케이션을 지속적으로 프로파일링해, (성능 병목 현상을 일으키는 것 같은) "가장 비용이 많이 드는" 코드 라인을 식별하고 애플리케이션 성능을 최적화하고 컴퓨팅 비용을 줄이는 방법에 대한 지침을 제공합니다.

또한 정적 분석을 통해 코드의 보안 문제를 탐지하는 데 특화된 **CodeGuru Security**(Reviewer 서비스를 기반으로 구축됨)의 측면도 있으며, AWS 보안 모범 사례로 훈련된 고급 ML 모델을 사용합니다.

## 2. Amazon CodeGuru Reviewer

**하는 일:**

- 풀 리퀘스트를 통해 제출되거나 저장소 스캔을 통해 제출된 코드 변경 사항을 분석합니다.
- 찾기 어려운 버그를 탐지하고, 코딩 모범 사례로부터의 편차를 식별하고, 보안 취약점을 강조합니다.
- (오픈소스와 내부 Amazon 코드베이스 모두에서) 수백만 건의 코드 리뷰로 훈련된 머신 러닝 모델을 사용합니다.

**작동 방식:**

- 저장소가 (GitHub, AWS CodeCommit, Bitbucket, GitLab과의 통합을 통해) CodeGuru Reviewer와 연결되면 코드 변경이 발생할 때 서비스가 자동으로 리뷰를 시작합니다.
- 서비스는 안전하게 저장소를 일시적이고 샌드박스화된 컨테이너(종종 VM 수준 격리를 갖춘 AWS ECS Fargate 인스턴스)로 복제해 분석을 수행합니다.
- 분석이 완료되면 풀 리퀘스트에 인라인 댓글로 권장 사항을 반환하고 코드 리뷰 이력을 저장합니다.

## 3. Amazon CodeGuru Profiler

**하는 일:**

- 프로덕션에서 애플리케이션의 성능을 지속적으로 모니터링합니다.
- 코드의 어떤 부분이 가장 많은 CPU를 소비하거나 가장 많은 시간이 걸리는지 식별합니다(일반적으로 플레임 그래프를 통해 시각화됨).
- 지연 시간과 컴퓨팅 비용 모두를 줄이는 데 도움이 되는 비효율적인 코드 경로 최적화 방법에 대한 권장 사항을 제공합니다.

**작동 방식:**

- 경량 프로파일링 에이전트가 (Amazon EC2, Amazon ECS/EKS 같은 컨테이너 서비스, AWS Lambda, 또는 심지어 온프레미스에서든) 애플리케이션 내에서 실행됩니다.
- 에이전트는 (일반적으로 5분마다) 주기적으로 성능 데이터를 샘플링하고 안전하게 CodeGuru Profiler 서비스로 전송합니다.
- 수집된 데이터는 집계되어 플레임 그래프와 상세한 성능 지표를 표시하는 대화형 콘솔을 통해 구체적인 최적화 권장 사항과 함께 제시됩니다.

## 4. Amazon CodeGuru Security

**하는 일:**

- 원래는 CodeGuru Reviewer의 구성 요소였지만, CodeGuru Security는 이제 정적 애플리케이션 보안 테스트(SAST)에 전념하는 재설계된 서비스로 자리매김하고 있습니다.
- 머신 러닝과 프로그램 분석을 모두 활용해 하드코딩된 자격 증명, 인젝션 결함, OWASP Top Ten과 CWE Top 25 같은 표준으로 정의된 다른 문제 같은 보안 취약점을 찾기 위해 코드를 스캔합니다.

**핵심 기능:**

- **고정밀 탐지:** 고급 ML 모델과 수백 개의 탐지기를 사용해 오탐(false positive)을 줄입니다.
- **자동화된 개선:** 잠재적인 인라인 코드 수정과 함께 상세하고 실행 가능한 권장 사항을 제공합니다.
- **개발자 워크플로와의 통합:** CI/CD 파이프라인에 통합될 수 있으며, 여러 언어와 저장소 유형을 지원합니다.

## 5. 통합과 워크플로

**저장소와 CI/CD 통합:**

- CodeGuru 서비스는 GitHub, GitHub Enterprise, AWS CodeCommit, Bitbucket, GitLab 같은 코드 저장소와 직접 통합될 수 있습니다.
- 지속적 통합 파이프라인과도 원활하게 작동해, 풀 리퀘스트에서 자동으로 코드 리뷰를 트리거하거나 전체 저장소 스캔을 실행할 수 있습니다.
- 또한 Visual Studio Code, JetBrains IDE, (JupyterLab, Amazon SageMaker Studio 같은) 노트북 플랫폼 같은 환경을 위한 IDE 통합과 플러그인도 사용할 수 있습니다.
