# AWS IoT Services

## 1. 소개

사물 인터넷(IoT)은 수십억 개의 장치를 연결해, 조직이 방대한 양의 데이터를 수집하고, 통찰을 얻고, 실시간 작업을 수행할 수 있게 해줄 것을 약속합니다. IoT 기술이 진화하면서 이러한 장치를 안전하게 관리하고 데이터를 활용하는 과제는 기하급수적으로 커집니다. Amazon Web Services(AWS)는 어떤 규모의 IoT 플릿이든 연결, 보호, 분석, 관리하도록 설계된 완전관리형 IoT 서비스 모음으로 이러한 과제를 해결합니다.

이 장에서는 AWS IoT 1-Click, AWS IoT Core, AWS IoT Device Defender, AWS IoT Device Management, AWS IoT Events, AWS IoT Greengrass, AWS IoT SiteWise 같은 여러 핵심 AWS IoT 서비스를 탐구합니다. 각 서비스는 간단한 장치 트리거 작업과 견고한 클라우드-장치 연결부터 장치 보안 보장과 대규모 산업 센서 데이터 수집까지 IoT 인프라 내의 특정 요구를 충족합니다.

## 2. AWS IoT 1-Click

![iot-1click](@site/docs/Internet%20of%20Things/_assets/iot-1click.png)

AWS IoT 1-Click은 단순함을 위해 설계되었습니다. 커스텀 펌웨어 개발 없이 단일 작업으로 AWS Lambda 함수를 트리거할 수 있는 다양한 "즉시 사용 가능한" 장치를 조직이 사용할 수 있게 해줍니다.

일반적인 사용 사례는 다음을 포함합니다.

- 버튼 한 번 누름으로 기술 지원 팀에 알리기.
- 원격지의 자산 추적하기.
- 장치가 활성화되면 자동으로 상품이나 서비스 보충하기.

AWS IoT 1-Click 장치는 최소한의 설정만 필요하므로 신속하게 배포될 수 있습니다. 장치는 자동으로 AWS에 안전하게 연결되어, 펌웨어를 프로그래밍하거나 커스터마이징하는 것과 관련된 시간과 비용을 없애줍니다. 또한 AWS IoT 1-Click은 장치를 그룹화하고 모니터링하기 쉽게 만들어주는 간단한 장치 관리 기능을 제공합니다. 단순히 장치(또는 장치 그룹)를 Lambda 함수와 연결하기만 하면 버튼이 눌렸을 때 원하는 작업을 정의하고 실행할 수 있습니다. 이 서비스는 장치 상태와 활동을 추적하기 위한 사전 구축된 보고서도 제공합니다.

## 2. AWS IoT Core

![iot-core](@site/docs/Internet%20of%20Things/_assets/iot-core.png)

AWS IoT Core는 종종 AWS 기반 IoT 솔루션의 핵심입니다. 수십억 개의 IoT 장치와 AWS 백엔드 애플리케이션 간, 또는 장치 간에 메시지를 안전하게 라우팅하는 관리형 클라우드 서비스입니다.
### 핵심 이점

- **안전한 통신:** AWS IoT Core는 인증과 종단 간 암호화를 제공해, 데이터가 안전하게 전송되도록 보장합니다.
- **확장성:** 방대한 수의 장치를 지원하고 수조 건의 메시지를 신뢰성 있게 처리할 수 있습니다.
- **원활한 통합:** IoT 데이터는 AWS Lambda, Amazon Kinesis, Amazon S3, Amazon SageMaker, Amazon DynamoDB 등 다른 AWS 서비스로 라우팅될 수 있습니다.
- **장치 통신:** 장치가 연결되어 있지 않을 때도 서비스는 클라우드에서 논리적인 "트윈"을 유지해, 애플리케이션이 장치 상태를 지속적으로 추적하고 업데이트할 수 있게 해줍니다.

AWS IoT Core를 사용하면 백엔드 서버나 전문화된 네트워킹 인프라를 관리하지 않고도 강력한 IoT 애플리케이션을 구축할 수 있습니다. 이는 비즈니스 로직과 장치 동작에 집중을 유지하는 데 도움을 줍니다.

## 3. AWS IoT Device Defender

![iot-device-defender](@site/docs/Internet%20of%20Things/_assets/iot-device-defender.png)

조직이 더 많은 장치를 연결하면서 각 엔드포인트의 보안을 보장하는 것이 무엇보다 중요해집니다. AWS IoT Device Defender는 IoT 구성을 지속적으로 감사하고 보안 이상 징후에 대해 장치 활동을 모니터링하는 완전관리형 서비스입니다.

### 3.1. 지속적 감사

- **구성 검사:** 보안 모범 사례가 준수되는지 확인합니다 — 예를 들어 장치 인증서가 여러 장치 간에 공유되지 않도록 보장하고, 취소된 인증서가 연결을 허용하지 않도록 확인합니다.
- **알림:** AWS IoT Device Defender가 격차를 발견할 때마다 팀이 잠재적인 취약점을 신속하게 해결할 수 있도록 알림을 보냅니다.

### 3.2. 동작 모니터링

- **실시간 이상 탐지:** 네트워크 트래픽과 장치 지표를 검사함으로써 AWS IoT Device Defender는 알려진 기준선에서 벗어나는 행동(예: 아웃바운드 트래픽의 비정상적인 급증)을 식별합니다.
- **통합과 개선:** 자동으로 지표를 수집하기 위해 AWS IoT Greengrass와 FreeRTOS와 통합됩니다. 알림은 AWS IoT 콘솔, Amazon CloudWatch, Amazon SNS에서 볼 수 있습니다. 사고가 탐지되면 AWS IoT Device Management를 사용해 보안 수정이나 다른 완화 조치를 롤아웃할 수 있습니다.

## 4. AWS IoT Device Management

![iot-device-management](@site/docs/Internet%20of%20Things/_assets/iot-device-management.png)

규모에 맞게 IoT 장치를 관리하는 것은 새 장치 온보딩, 각 장치의 상태 추적, 펌웨어 업데이트를 포함합니다. AWS IoT Device Management는 수천 대 또는 심지어 수백만 대에 달할 수 있는 플릿을 위해 이러한 작업을 단순화합니다.

### 4.1. 핵심 기능

1. **안전한 온보딩:** 개별적으로 또는 대량으로 장치를 등록하고 각각에 대해 안전한 신원과 접근 정책을 구성합니다.
2. **조직화와 모니터링:** 장치를 논리적 그룹으로 조직화하고 상태를 지속적으로 모니터링해, 문제 해결과 운영 감독을 용이하게 합니다.
3. **원격 관리:** 원격으로 장치 상태를 쿼리하고 펌웨어와 소프트웨어에 대한 무선(OTA) 업데이트를 푸시해, 장치가 최신 상태이고 안전하게 유지되도록 보장합니다.
4. **확장성:** 장치 유형과 운영체제에 구애받지 않으므로 작은 마이크로컨트롤러부터 복잡한 자동차 시스템까지 하나의 우산 아래에서 다양한 장치를 관리할 수 있습니다.

이러한 일상적인 태스크를 자동화함으로써 AWS IoT Device Management는 운영 오버헤드를 크게 줄여, 팀이 지루한 장치 유지보수 대신 혁신에 집중할 수 있게 해줍니다.

## 5. AWS IoT Events

![iot-events](@site/docs/Internet%20of%20Things/_assets/iot-events.png)

많은 IoT 사용 사례는 온도 변동, 생산 라인 고장, 또는 무단 침입 같은 변화하는 조건을 실시간으로 탐지하고 대응해야 할 필요를 포함합니다. AWS IoT Events는 커스텀 코딩 솔루션의 복잡함 없이 이벤트 기반 애플리케이션을 구축하기 위한 완전관리형 서비스입니다.

### 5.1. 작동 방식

1. **이벤트 탐지:** AWS IoT Events는 다양한 IoT 센서와 애플리케이션의 데이터를 모니터링해, 정의된 패턴이나 이상 징후(예: 멈춘 벨트나 비정상적인 모터 속도)를 찾습니다.
2. **논리적 표현식:** 각 상황이나 임계값에 대한 로직을 정의하기 위해 간단한 "if-then-else" 규칙을 설정해, 트리거를 쉽게 만들 수 있습니다.
3. **알림과 작업:** 정의된 이벤트가 발생하면 AWS IoT Events는 자동으로 알림이나 커스텀 작업을 시작할 수 있습니다. 이는 서비스 기술자에게 메시지 전송, 이벤트 로깅, 또는 심지어 다른 AWS 서비스 트리거를 포함할 수 있습니다.

문제에 대한 조기 탐지와 자동 대응을 제공함으로써 AWS IoT Events는 비용이 많이 드는 다운타임을 최소화하고 운영 효율성을 높이는 데 도움을 줍니다.

## 6. AWS IoT Greengrass

![iot-greengrass](@site/docs/Internet%20of%20Things/_assets/iot-greengrass.png)

연결이 간헐적이거나 제한적인 위치에서 운영되는 IoT 장치의 경우 AWS IoT Greengrass는 AWS 컴퓨팅과 머신 러닝의 힘을 엣지로 가져옵니다. Greengrass를 사용하면 장치는 지속적인 클라우드 연결 없이도 계속 운영 가능한 상태로 로컬에서 데이터에 대해 작업할 수 있습니다.

### 6.1. 핵심 역량

- **AWS Lambda를 사용한 로컬 컴퓨팅:** 연결된 장치에서 직접 AWS Lambda 함수를 실행해 실시간으로 센서 데이터를 처리할 수 있습니다.
- **엣지에서의 머신 러닝:** Greengrass 장치는 데이터를 클라우드로 보낼 필요 없이 예측을 생성하기 위해 머신 러닝 모델을 실행할 수 있습니다.
- **안전한 통신:** 장치가 로컬 네트워크에서 서로 연결되든 AWS 클라우드에 연결되든 데이터를 암호화하고 보호할 수 있습니다.
- **오프라인 운영:** Greengrass는 장치 데이터와 상태를 로컬에서 유지하며, 연결이 다시 확립되면 클라우드와 동기화합니다.

또한 Greengrass는 일반적인 서드파티 애플리케이션, 온프레미스 소프트웨어, 다른 AWS 서비스와의 통합을 단순화하는 **커넥터**를 지원합니다. 이 기능은 장치 기능을 확장하고 새로운 배포를 가속화합니다.


:::tip

AWS Snowball 장치는 주로 데이터 전송을 위해 설계되었으며 지속적인 로컬 실시간 추론을 위한 것이 아닙니다. Snowball에서 지속적인 추론을 배포하는 것은 최적이거나 의도된 사용 사례가 아닙니다. 반면 AWS IoT Greengrass는 ML 모델 실행 같은 클라우드 기능을 엣지로 확장하기 위해 정확히 설계되었습니다.

:::


## 7. AWS IoT SiteWise

![iot-sitewise](@site/docs/Internet%20of%20Things/_assets/iot-sitewise.png)

산업 시설은 센서와 기계로부터 방대한 양의 데이터를 생성합니다. 종종 이 데이터는 온프레미스 시스템에 갇혀 있으며 분석하려면 전문화된 전문 지식이 필요합니다. AWS IoT SiteWise는 대규모 모니터링과 분석을 위해 산업 데이터를 수집, 저장, 조직화하기 쉽게 만들어줌으로써 이 과제를 간소화합니다.

### 7.1. 사용 사례

- **예방적 유지보수:** 거의 실시간으로 기계 데이터를 분석함으로써 팀은 비용이 많이 드는 고장으로 확대되기 전에 문제를 식별할 수 있습니다.
- **운영 최적화:** 여러 산업 현장에서 지표를 수집하는 것은 효율성을 개선하고 생산 격차를 줄이는 데 도움을 줍니다.
- **중앙화된 데이터 관리:** SiteWise의 소프트웨어 게이트웨이는 온프레미스 데이터 서버에 자동으로 연결해 산업 센서 데이터를 수집하고 분석을 위해 AWS 클라우드로 보냅니다.

데이터가 SiteWise에 들어오면 물리적 자산과 프로세스를 모델링하고, (전체 장비 효율성 같은) 성능 지표를 정의하고, 즉시 사용 가능한 웹 애플리케이션에서 통찰을 시각화할 수 있습니다. 이는 커스텀 사내 소프트웨어 솔루션의 필요성을 없애 가치 실현 시간을 줄여줍니다.

## 8. 결론

AWS의 포괄적인 IoT 포트폴리오는 온보딩, 인증, 메시징, 저장, 분석, 실시간 이벤트 처리를 포함해 연결된 장치의 전체 라이프사이클을 다룹니다. AWS IoT 1-Click으로 간단한 작업을 시작하는 것부터 AWS IoT Greengrass로 복잡한 엣지 기반 머신 러닝 모델을 구축하는 것까지, 이 서비스들은 안전하고, 확장 가능하고, 비용 효율적인 IoT 솔루션을 위한 구성 요소를 제공합니다.

AWS IoT Core는 장치와 애플리케이션 간의 메시지 트래픽을 오케스트레이션하며 중심에 있습니다. AWS IoT Device Defender와 AWS IoT Device Management 같은 긴밀하게 통합된 서비스는 플릿이 안전하고 최신 상태를 유지하도록 보장하며, AWS IoT Events와 AWS IoT SiteWise는 데이터를 실시간으로 탐지하고, 대응하고, 분석하는 강력한 방법을 제공합니다. 이러한 관리형 IoT 서비스를 사용함으로써 조직은 인프라 관리의 복잡함에 얽매이는 대신 혁신과 결과에 집중할 수 있습니다.

이 서비스들이 함께 AWS가 단순한 센서 네트워크부터 복잡한 산업 운영까지 모든 것을 처리할 수 있는 고급 IoT 생태계를 만들기 위한 유연하고 견고한 프레임워크를 어떻게 제공하는지 보여줍니다.
